# G2停用细化：已接通通话有限收尾

## 实际问题

停用细化第1项：账号或本租户成员被停用时，已经接通的电话如何处理？建议立即禁止停用范围内的新操作，仅允许完成当前通话及必要话后保存，随后结束该范围的使用。本租户停用仍不影响其他租户；后台任务下一项单独确认，具体电话平台能力由研发核验。

## 用户实际答复

允许当前通话收尾（推荐）

## 确认范围

仅停用范围内已接通的当前通话及必要话后允许收尾，不扩大一般访问；后台任务不由本项决定。

本记录不是G2/G3整批批准，不证明生产或供应商已经支持。
