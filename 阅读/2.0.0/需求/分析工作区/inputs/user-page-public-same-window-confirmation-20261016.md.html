# PAGE-Q03 公共管理同窗口打开与返回实际确认

记录时间：2026-10-16T13:15:17+08:00

原问题：

页面设计第3项：点击“公共管理”后，是否在当前窗口进入管理区域，并提供“返回工作区”入口，返回时恢复原页面和筛选？推荐同窗口处理，电话和未保存内容沿已确认规则保护；单独开标签页则需额外处理多标签的权限及电话状态一致性。

实际用户答复：

> 同窗口进入并返回（推荐）

确认范围：在当前窗口的主内容区进入公共管理，提供返回工作区入口；返回时恢复原工作区页面和筛选，刷新业务数据并校验实际权限。电话与普通未保存内容沿已确认规则保护；本版不新增跨区常驻电话控件。未确认公共管理自身的默认管理页记忆方式或其他角色具体默认页；不改变仅公共管理身份的登录首个有权页规则，不关闭12问题，不批准整体页面/G3/开发交付。
