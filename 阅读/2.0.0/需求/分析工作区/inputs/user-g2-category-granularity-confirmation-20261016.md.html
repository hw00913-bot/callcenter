# G2公共分类关联粒度确认

## 实际问题

公共分类细化：是否按“本租户的具体 AI 业务场景”关联公共分类？例如销售回访、售后满意度回访可以分别选择本租户的不同公共分类；另一种方案是同租户所有“回访”统一归同一分类。两种都沿用原“标签管理 → 场景配置”入口，保留 AI 原类型、标签和供应商配置，本项只确认关联粒度。

## 用户实际答复

按本租户具体业务场景关联（推荐）

## 确认范围

当前租户的具体AI业务场景关联当前租户公共分类；同类型不同场景允许不同公共归类。沿原标签管理→场景配置入口维护，保留AI类型、标签、供应商参数和原专业权限。本项不新增类型默认加场景覆盖的混合规则，不证明实际ID已贯通或已有API支持，也不是G2/G3整批批准。
