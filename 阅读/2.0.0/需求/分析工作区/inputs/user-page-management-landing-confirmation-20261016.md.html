# PAGE-Q02 仅公共管理身份的登录落点实际确认

记录时间：2026-10-16T13:11:41+08:00

原问题：

页面设计第2项：账号没有 AI 外呼／云呼叫使用权限，但有公共管理权限时，登录后是否直接打开按菜单顺序排在最前的有权公共管理页？另一种是在现有入口提示区列出有权管理页，由用户选择。两种均不新增首页，也不授予工作区权限。

实际用户答复：

> 直接进入首个有权管理页（推荐）

确认范围：当前账号没有AI外呼/云呼叫使用权，但有公共管理权限时，登录后直接进入按菜单顺序首个有权公共管理页。不新增首页或入口选择页，不因此获得业务工作区权限。有业务工作区权限者继续按原首次/上次工作区规则。具体其他角色默认页、公共管理打开/返回交互仍待评审；12问题不因此全部关闭，不批准G3或开发交付。
