# 实施任务索引

[返回交接入口](README.md)

56个业务实施任务包覆盖完整当前产品；任务按可验收的职责分组，不是56个按钮或新增功能。每个LOCAL恰好有一个主实施任务，任务CHECK与本版产品规范逐项一致；相对上版的规则变更和验收修订保留溯源。

开发负责补目标仓库、实际模块/文件/物理接口及测试命令。空allowed_files不授代码写入权；本文逻辑依赖不增加用户操作门槛，也不代表共享真实文件已允许并行修改。

## 责任边界

- 开发负责人：选择工程上下文，指定实际实现人员并绑定生产模块、文件、接口和数据。
- 实现人员：逐LOCAL落实规则与异常，承接原CHECK，提交实现和验证证据。
- 测试负责人：组织逐任务及跨任务批次验收，区分Mock/契约/真实服务结果。
- 产品与业务/运营责任人：核对产品行为和实际操作结果；业务变化返回产品规格。
- 交接检查：仅检查当前证据和状态，不代任何责任人签署批准。
