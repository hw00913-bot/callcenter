# 页面权限与数据范围

[返回阅读入口](README.md)

五种生产角色：超级管理员、租户总部管理员、租户总部运营、租户门店管理员、租户门店运营。坐席是本人电话能力，不是第六种生产角色。以下表与同源局部动作、字段权限及页面无权状态配套阅读。
