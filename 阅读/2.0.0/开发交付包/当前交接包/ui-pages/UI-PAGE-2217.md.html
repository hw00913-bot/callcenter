## 页面状态

- normal：分机在当前合法企业／租户范围内唯一关联原呼叫账号，系统账号映射另办；号码不能因纯数字外观随意转整数。

- loading：首次加载显示当前模块/对象读取中，依赖此结果的动作暂不可用；刷新保留当前已应用筛选和已确认资料并标正在更新，响应只回当前准确对象/范围。

- empty：无分机显示有权维护入口；缺呼叫账号显示资源未准备而非自动造分机。

- error：分机重复、账号作用域错误、被引用／在通话中、结果待核时保原映射，禁止覆盖同名其他租户分机。

- no_permission：仅平台或当前租户资源资格；运营不维护他人分机。

- submitting：提交中固定当前准确对象和输入，不接受同一动作重复发送；真正成功后更新当前值/列表，失败保草稿，未知保准确同次请求并显示核对入口。

## 交互与反馈

### UI-ACT-2077

触发：用户点击/提交“原分机允许的维护操作”

行为：触发“原分机允许的维护操作”时按当前准确对象与操作资格办理。按下列独立动作入口的业务规则逐项办理：查询和查看分机；创建、编辑或按允许动作保存分机；删除可删除的分机。同一页面入口不代替独立操作核权，具体字段、失败和结果见本页对应独立交互。

局部逻辑：LOCAL-PLAT-RESOURCE-EXTENSION-QUERY, LOCAL-PLAT-RESOURCE-EXTENSION-SAVE, LOCAL-PLAT-RESOURCE-EXTENSION-DELETE

测试：CHECK-PLAT-RESOURCE-EXTENSION-DELETE, CHECK-PLAT-RESOURCE-EXTENSION-QUERY, CHECK-PLAT-RESOURCE-EXTENSION-SAVE

### UI-ACT-2077-PLAT-RESOURCE-EXTENSION-DELETE

触发：有原删除权者对准确分机确认删除

行为：展示准确对象并最终检查原默认/预置/引用/在用保护；只删除本对象允许的目录记录，不清任务/通话/账务或其他资源；只有确认成功刷新，失败/未知保可核对状态。可观察结果：仅准确可删分机确认删除；原不提供删除能力的变体不得被通用入口新增。无权/字段不合法/对象失效/修订冲突时：明确显示本次拒绝原因，保留可继续的输入和已确认原值，不作变更；提交失败或结果未知时：失败保留原确认值；未知显示待核并按同请求核对，不重复提交或假报成功

局部逻辑：LOCAL-PLAT-RESOURCE-EXTENSION-DELETE

测试：CHECK-PLAT-RESOURCE-EXTENSION-DELETE

### UI-ACT-2077-PLAT-RESOURCE-EXTENSION-QUERY

触发：在原分机页查询或查看准确对象

行为：按当前enterprise有权对象过滤，读取准确nativeId及用途；详情只读且敏感字段按权展示；列表更新时间倒序后分页。可观察结果：有权分机当前目录与状态可读，读权不授写/导入/监管。无权/字段不合法/对象失效/修订冲突时：明确显示本次拒绝原因，保留可继续的输入和已确认原值，不作变更；提交失败或结果未知时：失败保留原确认值；未知显示待核并按同请求核对，不重复提交或假报成功

局部逻辑：LOCAL-PLAT-RESOURCE-EXTENSION-QUERY

测试：CHECK-PLAT-RESOURCE-EXTENSION-QUERY

### UI-ACT-2077-PLAT-RESOURCE-EXTENSION-SAVE

触发：有原分机对应操作权者新增/编辑/导入/启停或配置后明确保存

行为：按准确动作变体逐字段校验；导入保选中候选，启停保原状态约束；最终复核scope/修订/引用/在用状态，不能因原页面有入口忽略动作权；分别保存明确本地结果和外部受理/终态；失败保输入、未知先核对。可观察结果：准确分机允许配置确认保存；不假报供应商生效或静默改其他资源。无权/字段不合法/对象失效/修订冲突时：明确显示本次拒绝原因，保留可继续的输入和已确认原值，不作变更；提交失败或结果未知时：失败保留原确认值；未知显示待核并按同请求核对，不重复提交或假报成功

局部逻辑：LOCAL-PLAT-RESOURCE-EXTENSION-SAVE

辅助说明：与对应已受理或已确认变更关联；敏感凭据不记录明文；未知结果记录未知，不伪造成功审计

显示条件：具本字段读取资格且本页对应列表/详情/表单区域展开时显示；无对象读取权时隐藏值，按本页无权状态处理。

编辑条件：此页只读，显示系统/外部已确认事实或配置摘要；读取资格不授修改权限，另有明确维护入口时再次核其动作权。

必填提示：本页只读，不显示输入必填星号；业务必需条件由相应办理动作按同源字段规格校验。

校验时机：此处无用户输入校验；取值时核对准确对象、范围与真实可用状态，缺失/未知与空结果分开。

错误文案：只读字段无需输入校验；来源无法确认时显示“未取得/待核”及恢复入口，不用0、空值或首项伪造。

展示格式：对象/动作/操作人/时间/请求/前后值/结果；缺失显示“未取得/未填写”，合法0、false和空集合分别按真实值显示，不互换。
