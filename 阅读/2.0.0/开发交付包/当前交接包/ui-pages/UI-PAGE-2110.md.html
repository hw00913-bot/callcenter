## 页面状态

- normal：场景使用准确当前租户和业务分类，创建／修改不产生AI标签维护权；业务执行可选择已有场景，其可用性与标签维护页面权限分离。

- loading：首次加载显示当前模块/对象读取中，依赖此结果的动作暂不可用；刷新保留当前已应用筛选和已确认资料并标正在更新，响应只回当前准确对象/范围。

- empty：本租户无场景显示新增入口或无配置权说明；资源目录未就绪不当成场景为空。

- error：名称／资源／分类缺失或不兼容、配置变更／待核、保存失败时保表单并提示重读；不能用租户名称猜场景所有权。

- no_permission：总部和门店运营已确认可维护本租户有权业务场景；专业配置超管和管理员沿对应资格，标签映射仍独立禁权。

- submitting：提交中固定当前准确对象和输入，不接受同一动作重复发送；真正成功后更新当前值/列表，失败保草稿，未知保准确同次请求并显示核对入口。

## 交互与反馈

### UI-ACT-2042

触发：用户点击/提交“原业务场景查询与已有配置操作”

行为：触发“原业务场景查询与已有配置操作”时按当前准确对象与操作资格办理。按下列独立动作入口的业务规则逐项办理：创建或编辑AI业务场景与场景类型；删除未被引用的AI专业场景／类型；查询AI场景及原类型。同一页面入口不代替独立操作核权，具体字段、失败和结果见本页对应独立交互。

局部逻辑：LOCAL-PLAT-AI-SCENE-SAVE, LOCAL-PLAT-AI-SCENE-DELETE, LOCAL-PLAT-AI-SCENE-QUERY

### UI-PLAT-2110-AI-CATEGORY-BIND

触发：AI标签管理→场景配置显式选择分类并保存

行为：按具体执行场景稳定ID关联分类，保留原AI新/冷类型和供应商参数；分类只作业务引用，不自动绑定流转模板；实际路由来自分类路由配置；重新校验分类/品牌/当前修订，禁止同名或首项兜底；准确场景业务分类引用保存，未扩大品牌数据或AI专业能力；明确显示本次拒绝原因，保留可继续的输入和已确认原值，不作变更；失败保留原确认值；未知显示待核并按同请求核对，不重复提交或假报成功

局部逻辑：LOCAL-PLAT-AI-CATEGORY-BIND

测试：CHECK-PLAT-AI-CATEGORY-BIND

### UI-ACT-2042-PLAT-AI-SCENE-DELETE

触发：原专业入口点击删除并确认

行为：显示准确场景/类型，不删除关联业务分类；检查原专业引用与当前修订；未知拒绝删除；保留已受理任务/通话/业务快照。可观察结果：只删除原允许的准确专业对象，不清除任务结果。无权/字段不合法/对象失效/修订冲突时：明确显示本次拒绝原因，保留可继续的输入和已确认原值，不作变更；提交失败或结果未知时：失败保留原确认值；未知显示待核并按同请求核对，不重复提交或假报成功

局部逻辑：LOCAL-PLAT-AI-SCENE-DELETE

测试：CHECK-PLAT-AI-SCENE-DELETE

显示条件：具本字段读取资格且本页对应列表/详情/表单区域展开时显示；无对象读取权时隐藏值，按本页无权状态处理。
