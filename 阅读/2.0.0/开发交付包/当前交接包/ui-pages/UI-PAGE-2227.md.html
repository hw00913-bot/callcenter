- 业务概览：实际分类、客户当前值、当前负责租户／跟进人、节点及工作状态

## 页面状态

- normal：运行按实际绑定分类的冻结有效方案执行，参考分类只作编排来源。实际拨打／接听人正式填写，管理员不能代其他接听者写结果；系统归档不伪造新人工字段确认。每次新跟进读最新当前值，保存原basis与内容快照。

- loading：首次加载显示当前模块/对象读取中，依赖此结果的动作暂不可用；刷新保留当前已应用筛选和已确认资料并标正在更新，响应只回当前准确对象/范围。

- empty：无准确业务或无权对象不是普通空态；有业务但无跟进／拨打时分别显示尚无实际事实，不能把受理算拨打。

- error：在途／重试／未知执行、来源事实冲突、CAS值变化、条件缺失或配置不可能时显示明确阻塞与下一步；未命中保当前节点，未知不走后序或默认。保存／转交待核沿原请求核对，不能重复办理。

- no_permission：有权本租户办理和只读监管／转出截止资料分开；准确接听人的最小填写表单不开放全档案；转交仅同品牌总部↔门店，无意向指定门店仅当前总部管理员。

- submitting：提交中固定当前准确对象和输入，不接受同一动作重复发送；真正成功后更新当前值/列表，失败保草稿，未知保准确同次请求并显示核对入口。
