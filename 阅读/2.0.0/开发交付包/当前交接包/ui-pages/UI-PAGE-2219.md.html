## 页面状态

- normal：准确呼叫账号与业务租户映射经平台资源资格维护；AI模块单独开通不强制Cloud账号，Cloud开通须核其必要资源。

- loading：首次加载显示当前模块/对象读取中，依赖此结果的动作暂不可用；刷新保留当前已应用筛选和已确认资料并标正在更新，响应只回当前准确对象/范围。

- empty：无呼叫账号显示有权创建／关联入口；目录未知不猜首个账号。

- error：企业／账号归属不唯一、区域资源不可用、引用保护或结果未知时阻动作，不用账号显示名猜关联。

- no_permission：仅明确平台资源权；四种租户角色不提供新增／维护账号入口。

- submitting：提交中固定当前准确对象和输入，不接受同一动作重复发送；真正成功后更新当前值/列表，失败保草稿，未知保准确同次请求并显示核对入口。
