## 页面状态

- normal：日期与星期模式分开，开始不晚于结束；时间条件的优先级影响调用解释，页面列表仍按普通更新时间规则。运行中或暂停任务引用的条件不得直接改／删。

- loading：首次加载显示当前模块/对象读取中，依赖此结果的动作暂不可用；刷新保留当前已应用筛选和已确认资料并标正在更新，响应只回当前准确对象/范围。

- empty：无条件显示新增入口；无匹配筛选显示调整条件，不推断当前没有执行限制。

- error：日期／时间／优先级无效或引用中不允许动作时显示明确原因，保草稿；改原条件失败不自动建新条件。

- no_permission：平台或本租户资源管理员；超管租户筛选仍受明确资源范围，运营不维护。

- submitting：提交中固定当前准确对象和输入，不接受同一动作重复发送；真正成功后更新当前值/列表，失败保草稿，未知保准确同次请求并显示核对入口。

## 字段呈现

### [FIELD-PLAT-AUDIT](../field-specs.md#FIELD-PLAT-AUDIT) — 变更审计

组件：UI-COMP-READONLY

辅助说明：与对应已受理或已确认变更关联；敏感凭据不记录明文；未知结果记录未知，不伪造成功审计

显示条件：具本字段读取资格且本页对应列表/详情/表单区域展开时显示；无对象读取权时隐藏值，按本页无权状态处理。

编辑条件：此页只读，显示系统/外部已确认事实或配置摘要；读取资格不授修改权限，另有明确维护入口时再次核其动作权。

必填提示：本页只读，不显示输入必填星号；业务必需条件由相应办理动作按同源字段规格校验。

校验时机：此处无用户输入校验；取值时核对准确对象、范围与真实可用状态，缺失/未知与空结果分开。

错误文案：只读字段无需输入校验；来源无法确认时显示“未取得/待核”及恢复入口，不用0、空值或首项伪造。

展示格式：对象/动作/操作人/时间/请求/前后值/结果；缺失显示“未取得/未填写”，合法0、false和空集合分别按真实值显示，不互换。

### [FIELD-PLAT-OP-STATE](../field-specs.md#FIELD-PLAT-OP-STATE) — 操作结果状态

组件：UI-COMP-READONLY

辅助说明：accepted/pending不是成功；只有准确请求与对象确认终态才success；失败保留已确认旧值；未知不显示已完成或盲重试

显示条件：不作为独立用户输入显示；用于准确同次上下文、并发/快照或权威结果控制。必要时在已授权详情/证据区以可读摘要表达，禁止普通列表暴露内部/敏感值。

编辑条件：用户不可编辑；由对应局部逻辑按准确已确认来源维护。

必填提示：系统控制字段，不显示输入必填星号。

校验时机：不进行用户输入校验；进入/提交/回读结果时按对应局部逻辑重验准确范围、身份、修订及同次状态。

错误文案：若内部依据缺失/失效，显示对应动作无法确认的具体原因，保原值并停止本次提交；不能要求用户手填控制值。

展示格式：editing/submitting/pending/success/failure/unknown；缺失显示“未取得/未填写”，合法0、false和空集合分别按真实值显示，不互换。

### [FIELD-PLAT-QUERY](../field-specs.md#FIELD-PLAT-QUERY) — 查询条件

组件：UI-COMP-FILTER

辅助说明：输入筛选与已应用筛选分开，查询/重置后读取当前有权结果。

显示条件：具本字段读取资格且本页对应列表/详情/表单区域展开时显示；无对象读取权时隐藏值，按本页无权状态处理。

编辑条件：本页动作和字段写入资格同时成立、对应对象状态允许、草稿未提交且无未知请求时可编辑；五角色中具有该对象读取资格者；当前租户/独立平台授权范围内

必填提示：选填筛选不显示*；所选日期合法性在查询时校验。

校验时机：输入/选择变化即时提示格式和依赖；失焦提示本字段；最终提交重新校验全部必填、跨字段、对象范围及修订，动态上下文变化使原确认失效。

错误文案：“查询筛选”不满足要求：筛选范围取有权交集；不可通过全选扩权；失败保留当前筛选，空结果与失败分开；列表先按更新时间倒序再分页；定位当前字段并保输入，禁止静默代填。

展示格式：标签在控件上方，查询按钮底线对齐，不把未应用输入误作导出条件。
