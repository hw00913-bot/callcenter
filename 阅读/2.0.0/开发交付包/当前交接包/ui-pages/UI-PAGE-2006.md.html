辅助说明：当前新方案所有有出口节点必须有且仅有一个末位ELSE，前序IF/ELSEIF按优先级首命中；ELSE不带条件，未知事实继续PENDING且不得进入后续或兜底。

显示条件：具本字段读取资格且本页对应列表/详情/表单区域展开时显示；无对象读取权时隐藏值，按本页无权状态处理。

必填提示：本页只读，不显示输入必填星号；业务必需条件由相应办理动作按同源字段规格校验。

校验时机：此处无用户输入校验；取值时核对准确对象、范围与真实可用状态，缺失/未知与空结果分开。

错误文案：只读字段无需输入校验；来源无法确认时显示“未取得/待核”及恢复入口，不用0、空值或首项伪造。

展示格式：IF/ELSEIF/ELSE对应有序条件路径／默认路径；缺失显示“未取得/未填写”，合法0、false和空集合分别按真实值显示，不互换。
