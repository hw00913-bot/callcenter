## 页面状态

- normal：IMPORT／FOLLOWUP为两套独立字段，同名也不合并；导入业务编码必填且同品牌同用途唯一，数据必填由分类另设。字段维护不自动加入分类，不新增格式配置。接口字段明确依赖和单多选，不用于逻辑条件。

- loading：首次加载显示当前模块/对象读取中，依赖此结果的动作暂不可用；刷新保留当前已应用筛选和已确认资料并标正在更新，响应只回当前准确对象/范围。

- empty：无此用途字段显示新建入口；取数目录未准备显示待核，不当空接口可用。

- error：用途／类型／业务编码重复或引用锁定、接口参数／依赖循环、停用选项失配时定位并保草稿；同名不自动猜配字段或参数。

- no_permission：有权超管／品牌配置管理员维护，运营仅在业务表单使用所需字段；专业原目录只在准确本租户原表单域可读，不做v2旧台账迁移。

- submitting：提交中固定当前准确对象和输入，不接受同一动作重复发送；真正成功后更新当前值/列表，失败保草稿，未知保准确同次请求并显示核对入口。

组件：UI-COMP-READONLY

辅助说明：起本轮时读取最新当前值并捕获当时定义；正式内容保存后封存。

显示条件：具本字段读取资格且本页对应列表/详情/表单区域展开时显示；无对象读取权时隐藏值，按本页无权状态处理。
