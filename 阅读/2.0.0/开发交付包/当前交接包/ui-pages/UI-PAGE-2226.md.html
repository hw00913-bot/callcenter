## 页面状态

- normal：只按当前权限投影已有线索业务；自定义线索域和冷线索沿同品牌统一编码，手机号只做联系关联，不用来合并业务。

- loading：首次加载显示当前模块/对象读取中，依赖此结果的动作暂不可用；刷新保留当前已应用筛选和已确认资料并标正在更新，响应只回当前准确对象/范围。

- empty：无有权线索显示当前范围空态，返回客户档案／导入批次与业务名单；不能把无权伪装普通空结果。

- error：范围、编码／来源或投影截止不能准确核定时显示待核，不从其他租户或最新接收方资料补历史。

- no_permission：当前负责／管理员职责、实际本方历史截止、超管监管分别投影；只读身份不出现分配／推进操作。

- submitting：提交中固定当前准确对象和输入，不接受同一动作重复发送；真正成功后更新当前值/列表，失败保草稿，未知保准确同次请求并显示核对入口。
