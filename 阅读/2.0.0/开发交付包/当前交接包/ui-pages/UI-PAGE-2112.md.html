## 页面状态

- normal：充值管理菜单属于超管；其他四角色从服务查看入口只读账户及充值流水。办理前明确准确账户、产品／服务参数、金额或分钟及原因，成功后同源回读；未知同请求核对不重复资金动作。

- loading：首次加载显示当前模块/对象读取中，依赖此结果的动作暂不可用；刷新保留当前已应用筛选和已确认资料并标正在更新，响应只回当前准确对象/范围。

- empty：可靠无流水显示暂无；没有已关联AI账户显示待关联且不允许办理，不造默认账户。

- error：余额／分钟／服务数据未知、资格失效、请求失败或待核时保输入和流水真实状态；不以HTTP成功／受理冒充服务最终生效。

- no_permission：套餐／试用／话费包／手调／结果核对／服务汇总导出仅超管专业资格；其余四角色只读本租户账户／流水。

- submitting：提交中固定当前准确对象和输入，不接受同一动作重复发送；真正成功后更新当前值/列表，失败保草稿，未知保准确同次请求并显示核对入口。
