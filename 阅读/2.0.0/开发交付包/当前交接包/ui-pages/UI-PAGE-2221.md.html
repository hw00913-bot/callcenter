## 页面状态

- normal：通话记录核对只处理准确来源和既有核对动作，原始通话事实不能被核对操作随意改写；不新增异常种类或跨租户补造结果。

- loading：首次加载显示当前模块/对象读取中，依赖此结果的动作暂不可用；刷新保留当前已应用筛选和已确认资料并标正在更新，响应只回当前准确对象/范围。

- empty：可靠查询无待核记录显示暂无；无法读取原证据显示待核资料缺失，不当已处理。

- error：来源不唯一、证据冲突、失权或核对结果未知时留原记录和请求，不新造结束／接通事实。

- no_permission：本租户管理员已确认可使用查询／明细及已有操作；运营无此维护入口，超管按资源异常管理范围。

## 交互与反馈

### UI-ACT-2081

触发：用户点击/提交“查询及核对原异常”

行为：触发“查询及核对原异常”时按当前准确对象与操作资格办理。仅当前有权企业异常集；详情准确callId展示已知事实及核对trace；重新核对按本条请求读取可靠事实，追加trace/审计；有新证据仅补通话事实；无证据保持待处理，不重拨、不改业务跟进或自动推进。可观察结果：本条异常已明确解决或仍待处理，核对结果不污染其他通话/业务。无权/字段不合法/对象失效/修订冲突时：明确显示本次拒绝原因，保留可继续的输入和已确认原值，不作变更；提交失败或结果未知时：失败保留原确认值；未知显示待核并按同请求核对，不重复提交或假报成功

局部逻辑：LOCAL-PLAT-CALL-RECONCILE

测试：CHECK-PLAT-CALL-RECONCILE

### [FIELD-PLAT-AUDIT](../field-specs.md#FIELD-PLAT-AUDIT) — 变更审计

组件：UI-COMP-READONLY

辅助说明：与对应已受理或已确认变更关联；敏感凭据不记录明文；未知结果记录未知，不伪造成功审计

显示条件：具本字段读取资格且本页对应列表/详情/表单区域展开时显示；无对象读取权时隐藏值，按本页无权状态处理。

编辑条件：此页只读，显示系统/外部已确认事实或配置摘要；读取资格不授修改权限，另有明确维护入口时再次核其动作权。

必填提示：本页只读，不显示输入必填星号；业务必需条件由相应办理动作按同源字段规格校验。

校验时机：此处无用户输入校验；取值时核对准确对象、范围与真实可用状态，缺失/未知与空结果分开。

错误文案：只读字段无需输入校验；来源无法确认时显示“未取得/待核”及恢复入口，不用0、空值或首项伪造。

展示格式：对象/动作/操作人/时间/请求/前后值/结果；缺失显示“未取得/未填写”，合法0、false和空集合分别按真实值显示，不互换。

### [FIELD-PLAT-REQUEST](../field-specs.md#FIELD-PLAT-REQUEST) — 操作请求标识

辅助说明：同一用户提交/同一业务目的重试沿用同一请求标识；结果未知先核对原请求，不能生成新请求重复结算/开通/禁呼

显示条件：不作为独立用户输入显示；用于准确同次上下文、并发/快照或权威结果控制。必要时在已授权详情/证据区以可读摘要表达，禁止普通列表暴露内部/敏感值。

编辑条件：用户不可编辑；由对应局部逻辑按准确已确认来源维护。

必填提示：系统控制字段，不显示输入必填星号。

校验时机：不进行用户输入校验；进入/提交/回读结果时按对应局部逻辑重验准确范围、身份、修订及同次状态。

错误文案：若内部依据缺失/失效，显示对应动作无法确认的具体原因，保原值并停止本次提交；不能要求用户手填控制值。

展示格式：UTF-8文本；保留稳定标识原值；缺失显示“未取得/未填写”，合法0、false和空集合分别按真实值显示，不互换。
