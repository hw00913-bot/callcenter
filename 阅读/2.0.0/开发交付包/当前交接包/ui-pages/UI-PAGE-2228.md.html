辅助说明：模板AI呼叫节点直接显示AI呼叫任务，任务先于对应场景；候选仍按原实际执行tenant、分类、供应商/平台、任务状态和对象权筛选。选择准确任务后仅唯一明确sceneId或专业任务关联带出场景，多匹配/冲突/缺证不选首项；可明确暂不指定、后续分配，清本租户任务及场景默认并保其他tenant映射，执行前有效具体任务/场景准入不变。 冷打开已选AI的节点或切换AI时，在合法tenant/category和原ADMIN+task.assign资格下每editor/node/tenant/category自动读取一次目录；异步前后重核编辑器、方式、范围与权限，旧回调不落新草稿。失败明确且不因重绘循环，原刷新按钮允许重试；选择方式/任务和目录完成重绘保右侧配置区滚动，异步返回前读取当前草稿，不丢未提交输入。 无执行tenant、范围不一致、无参照分类或无任务安排权时仍显示禁用AI任务入口及准确原因，不把顶部已选tenant误称未切换，不授SUPER或运营新task.assign权。模板品牌配置权不授其他租户私有资源，原人工MANUAL/SPECIFIC_SEAT、PRED仅任务、五档及已捕获运行快照保持。

显示条件：具本字段读取资格且本页对应列表/详情/表单区域展开时显示；无对象读取权时隐藏值，按本页无权状态处理。

编辑条件：仅当前实际执行租户ADMIN及原task.assign资格、准确参照分类和可编辑当前草稿；其他情形禁用并说明，不新授SUPER/运营资格。

必填提示：按方式及分配模式条件必填：人工MANUAL可空，SPECIFIC_SEAT才需seat；AI任务+scene，PRED仅任务，无独立责任人。

校验时机：输入/选择变化即时提示格式和依赖；失焦提示本字段；最终提交重新校验全部必填、跨字段、对象范围及修订，动态上下文变化使原确认失效。

错误文案：保原输入并显示准确目标/等级/范围失效原因；重新核验，不首项代填。

展示格式：[{tenantId,method?,resourceId,accountId,aiSceneId?}]；tenantId唯一

错误文案：保原输入并显示准确目标/等级/范围失效原因；重新核验，不首项代填。
