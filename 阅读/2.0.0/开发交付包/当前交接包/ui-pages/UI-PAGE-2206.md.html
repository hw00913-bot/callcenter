## 页面状态

- normal：IVR按其语音流程和资源办理，不用预外呼人工接听资格代替；每次新外呼核同一联系限制，任务本身的原状态机控制允许动作。

- loading：首次加载显示当前模块/对象读取中，依赖此结果的动作暂不可用；刷新保留当前已应用筛选和已确认资料并标正在更新，响应只回当前准确对象/范围。

- empty：无任务／无客户／无结果分区空态，保已保存任务；未配置语音流程显示配置待补。

- error：语音流程无权／失效、任务控制不适用、名单或远端结果未知时阻动作并保准确任务上下文，不能混写预外呼结果。

- no_permission：当前租户任务管理／资源及对象资格成立才可写；只读监管不提供控制按钮。

- submitting：提交中固定当前准确对象和输入，不接受同一动作重复发送；真正成功后更新当前值/列表，失败保草稿，未知保准确同次请求并显示核对入口。
