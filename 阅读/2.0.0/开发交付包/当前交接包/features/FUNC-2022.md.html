# 人工明确拒联成功保存后自动入库 · FUNC\-2022

**DRAFT — 供讨论与补充，尚未完成本阶段交接**

[返回功能目录](README.md) · [返回开发包入口](../README.md)

## 本功能做什么

实际处理人成功保存明确拒联话后后，同请求幂等加入本租户长期公共禁呼；失败/未知不得虚报整体完成。

来源业务域：业务&amp;客户；来源业务模块：未提供。

本页是同一份规划的功能阅读视图，仅整理已声明的关联，不增加业务规则，也不代表本功能已通过完整性核验。

## 局部逻辑

- [保存人工明确拒联并入库 · LOCAL\-PLAT\-BAN\-HUMAN](../local-logic/LOCAL-PLAT-BAN-HUMAN.md)

本局部说明只声明关联当前功能，以下内容直接取自同一份规划。

### 触发与前置条件

触发：实际接听人成功保存明确客户拒绝联系处理结果

- 准确当前租户来源通话及实际处理权

### 处理步骤

1. **LOCAL\-PLAT\-BAN\-HUMAN\-S1**：未保存仅选择不生效；保存校验成功后以准确来源幂等创建拒联记录

2. **LOCAL\-PLAT\-BAN\-HUMAN\-S2**：保留callId/规范号码/人/时间/原因，长期限制四类外呼

3. **LOCAL\-PLAT\-BAN\-HUMAN\-S3**：话后与入库有失败/未知时报告待完成并恢复同请求，不显示整体成功

### 分支与异常

- **LOCAL\-PLAT\-BAN\-HUMAN\-B1**：当前提、字段及对象修订校验通过且结果明确成功，人工拒联成功保存后本租户长期禁呼，无需管理员二次确认；正常呼入不拦截。

- **LOCAL\-PLAT\-BAN\-HUMAN\-B2**：当无权/字段不合法/对象失效/修订冲突，明确显示本次拒绝原因，保留可继续的输入和已确认原值，不作变更。

- **LOCAL\-PLAT\-BAN\-HUMAN\-B3**：当提交失败或结果未知，失败保留原确认值；未知显示待核并按同请求核对，不重复提交或假报成功。

### 完成后的状态

- 人工拒联成功保存后本租户长期禁呼，无需管理员二次确认；正常呼入不拦截

- [原客户任务保存人工跟进结果 · LOCAL\-PLAT\-PHONE\-AFTERCALL](../local-logic/LOCAL-PLAT-PHONE-AFTERCALL.md)
