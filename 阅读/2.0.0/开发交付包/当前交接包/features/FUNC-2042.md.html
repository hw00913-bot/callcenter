# 删除当前未被使用的模板定义 · FUNC\-2042

**DRAFT — 供讨论与补充，尚未完成本阶段交接**

[返回功能目录](README.md) · [返回开发包入口](../README.md)

## 本功能做什么

当前分类仍绑定或配置操作待核则阻删；否则在对象/品牌/并发依据一致时移除当前定义，不建旧模板归档兼容索引，已开始run靠完整planSnapshot继续办理。

来源业务域：业务&amp;客户；来源业务模块：未提供。

## 局部逻辑

- [移除当前未使用模板定义 · LOCAL\-FLOW\-TEMPLATE\-DELETE](../local-logic/LOCAL-FLOW-TEMPLATE-DELETE.md)

本局部说明只声明关联当前功能，以下内容直接取自同一份规划。

### 触发与前置条件

触发：在准确模板删除预检后确认

- 当前品牌及配置管理资格真实有效
- 提交来源与当前上下文一致

### 处理步骤

1. **STEP\-FLOW\-TEMPLATE\-DELETE\-1**：只核当前实际分类绑定与未核配置，读取前后使用指纹

2. **STEP\-FLOW\-TEMPLATE\-DELETE\-2**：准确对象和并发依据一致时移除当前定义，记录本次请求结果

### 分支与异常

- **BRANCH\-FLOW\-TEMPLATE\-DELETE\-1**：当当前类别仍绑定或同模板配置待核，阻删并说明实际使用/核对入口；分类当前只支持更换路由模板，无解绑按钮。

- **BRANCH\-FLOW\-TEMPLATE\-DELETE\-2**：当仅当前run捕获依赖且没有当前绑定，可以删除定义，run完整快照仍可继续。

- **BRANCH\-FLOW\-TEMPLATE\-DELETE\-3**：当结果unknown，保原requestId核对，不重复删除。

### 完成后的状态

- 不维护旧模板归档兼容索引，不损已捕获业务事实
