# 保存本轮跟进、准确通话事实并唯一归档 · FUNC\-2032

**DRAFT — 供讨论与补充，尚未完成本阶段交接**

[返回功能目录](README.md) · [返回开发包入口](../README.md)

## 本功能做什么

按准确实际办理/接听人保存本次内容、真实通话及定义/值快照，正常条件满足唯一归档。受控缺失废弃保未完成且与正常archive分开；可靠旧弃结清不永久阻后继DIRECT，但不贡献完成数或绕真实unknown/冲突。原受理迟到事实归原ID入账，内容更正/当前值按原规则。

来源业务域：业务&amp;客户；来源业务模块：未提供。

本页是同一份规划的功能阅读视图，仅整理已声明的关联，不增加业务规则，也不代表本功能已通过完整性核验。

- [登记准确执行和通话回执 · LOCAL\-FLOW\-CALL\-FACTS](../local-logic/LOCAL-FLOW-CALL-FACTS.md)

本局部说明只声明关联当前功能，以下内容直接取自同一份规划。

### 触发与前置条件

触发：外部执行事实或本地明确模拟事件到达

- 原执行段/尝试身份可唯一关联
- 事实来源授权与原tenant/method一致
- 停止请求不等真实停止；只登记原受理请求的可靠事实，不以入账授权新调用/重呼

### 处理步骤

1. **STEP\-FLOW\-CALL\-FACTS\-1**：按准确record/run/stage/nodeRun/followup/attempt归原事实，不凭号码或当前指针

2. **STEP\-FLOW\-CALL\-FACTS\-2**：区分受理/排队/实际dial/接通/实际人工/重试收敛；新派发准入与入站事实分开；ACTIVE/ABANDONING原已受理且未可靠关闭的准确seg/attempt迟到拨打/接通/终态按原ID归账去重计数，不因非ACTIVE误标dialed=false/0或假冲突；不授新派发、不挂新run/当前身份、不提前释放。已闭段未知新attempt仍原EXECUTION\_CLOSED/冲突规则。

3. **STEP\-FLOW\-CALL\-FACTS\-3**：标签事实只匹配实际sceneSnapshot七元组及合法命中子集，NONE准确空也是已知

4. **STEP\-FLOW\-CALL\-FACTS\-4**：DIRECT沿准确record/owner/followup/attempt和实际办理人处理，同样保本人填写、正式快照、当前值权限及迟到隔离；无run/node不构造假模板身份。TEMPLATE仍核原准确run/node。

### 分支与异常

- **BRANCH\-FLOW\-CALL\-FACTS\-1**：当同事件同内容重复，读原结果，不重复拨打、接通、跟进计数。

- **BRANCH\-FLOW\-CALL\-FACTS\-2**：当相反终态/身份或其他scene回调，保原事实，拒或冲突待核，不复活已结束通话。

- **BRANCH\-FLOW\-CALL\-FACTS\-3**：当迟到原段准确信息，只补原段，不改新run/currentowner/已封内容。

- **BRANCH\-FLOW\-CALL\-FACTS\-ANSWER\-PROOF**：当预外呼仅登记坐席接听、客户接通未知或明确未接通，或同call出现相反明确接通回执，未具同次真实客户接通和准确接听账号证据时不赋人工填写；未知不完成归档，明确未接通可系统事实归档；相反明确回执保原事实并标待核，阻止继续办理。。

### 完成后的状态

- 普通AI可记录本轮实际新标签版本，不能用run旧catalog误拒准确可选标签事实
- 新派发准入与入站事实分开；ACTIVE/ABANDONING原已受理且未可靠关闭的准确seg/attempt迟到拨打/接通/终态按原ID归账去重计数，不因非ACTIVE误标dialed=false/0或假冲突；不授新派发、不挂新run/当前身份、不提前释放。已闭段未知新attempt仍原EXECUTION\_CLOSED/冲突规则。

- [实际办理人按原段表单查询并选择接口结果 · LOCAL\-FLOW\-INTERFACE\-QUERY](../local-logic/LOCAL-FLOW-INTERFACE-QUERY.md)

### 触发与前置条件

触发：实际拨打/接听人从准确原段填写表单查询或选择接口结果

- 本租户本账号有该准确原段待填写资格；不要求品牌字段/分类配置管理权
- 原段已结束尚未contentSaved，所需接口在原段basis中允许显示
- 当前本租户获该接口独立取数授权，能力启用且必要上游值准确可核

### 处理步骤

1. **STEP\-FLOW\-INTERFACE\-QUERY\-1**：从本次basis读取接口定义及选中方式，不把保存时的新分类字段拼入原表单

2. **STEP\-FLOW\-INTERFACE\-QUERY\-2**：独立查询不带依赖；关联查询读取唯一上游字段明确属性并逐参数映射，按本租户能力授权查询

3. **STEP\-FLOW\-INTERFACE\-QUERY\-3**：本人明确选择合法单/多选返回对象，仅更新原段草稿；正式内容另按SAVE\-CONTENT确认

### 分支与异常

- **BRANCH\-FLOW\-INTERFACE\-QUERY\-1**：当只有管理员/责任人身份但不是该原段实际办理/接听人，拒取该段表单，不能借配置权代填。

- **BRANCH\-FLOW\-INTERFACE\-QUERY\-2**：当接口未获本租户取数授权/已停用、上游缺值或参数映射不明，保草稿并明确字段/能力/参数原因，不取首项、不跨租户补结果。

- **BRANCH\-FLOW\-INTERFACE\-QUERY\-3**：当实际本人无字段配置权但原段及能力取数资格均满足，允许本次查询与明确选择，仍不能修改接口定义或分类。

- **BRANCH\-FLOW\-INTERFACE\-QUERY\-4**：当查询及选择成功，只写草稿，不生成正式确认、当前有效值或流转证据。
