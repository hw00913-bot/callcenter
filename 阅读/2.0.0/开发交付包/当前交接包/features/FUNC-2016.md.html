# 创建品牌共用业务分类与字段基础 · FUNC\-2016

**DRAFT — 供讨论与补充，尚未完成本阶段交接**

[返回功能目录](README.md) · [返回开发包入口](../README.md)

## 本功能做什么

在有权品牌维护独立IMPORT/FOLLOWUP字段库及分类双Tab，明确业务域、字段与入口必填；分类显式allowDirectFollowup控制直接跟进可选，缺省false；保存基础不绑定模板或起呼。

来源业务域：业务&amp;客户；来源业务模块：未提供。

本页是同一份规划的功能阅读视图，仅整理已声明的关联，不增加业务规则，也不代表本功能已通过完整性核验。

## 推荐阅读顺序

1. 看下面的相关页面，确认用户从哪里进入。
2. 阅读局部逻辑，再按需打开字段定义。
3. 对照本功能验收，查看实施任务及其前置依赖。

[全局逻辑](../global-logic.md)和[通用 UI 规范](../ui-spec.md)供核对共同规则；无需每次从头通读。

## 局部逻辑

- [新建品牌独立用途字段 · LOCAL\-FLOW\-FIELD\-CREATE](../local-logic/LOCAL-FLOW-FIELD-CREATE.md)

本局部说明只声明关联当前功能，以下内容直接取自同一份规划。

### 触发与前置条件

触发：从业务字段或分类Tab新建字段

- 当前品牌及配置管理资格真实有效
- 提交来源与当前上下文一致

### 处理步骤

1. **STEP\-FLOW\-FIELD\-CREATE\-1**：明确品牌、IMPORT/FOLLOWUP用途及当前类型，生成独立稳定ID

2. **STEP\-FLOW\-FIELD\-CREATE\-2**：校名称/编码唯一、选项和引用能力；IMPORT必有编码且无接口类型

### 分支与异常

- **BRANCH\-FLOW\-FIELD\-CREATE\-1**：当合法新定义，保存字段库，提示尚未加入分类；不自动产生业务或分类引用。

- **BRANCH\-FLOW\-FIELD\-CREATE\-2**：当用途/编码/选项不合法或当前无权，保输入并拒绝，不生成半条字段。

### 完成后的状态

- 字段可被同品牌同用途分类显式添加

- [配置接口填写字段定义与依赖 · LOCAL\-FLOW\-INTERFACE\-FIELD](../local-logic/LOCAL-FLOW-INTERFACE-FIELD.md)

**共用说明，尚未按功能细分步骤。** 该说明同时包含其他功能；其中全部步骤、分支和字段不能直接当成本功能专属逻辑。

- [新增分类基础与双字段Tab · LOCAL\-FLOW\-CATEGORY\-CREATE](../local-logic/LOCAL-FLOW-CATEGORY-CREATE.md)

本局部说明只声明关联当前功能，以下内容直接取自同一份规划。

### 触发与前置条件

触发：在业务分类基础表单保存

- 当前品牌及配置管理资格真实有效
- 提交来源与当前上下文一致

### 处理步骤

1. **STEP\-FLOW\-CATEGORY\-CREATE\-1**：校名称、编码列名、业务域和两用途字段；显式保存允许直接跟进开关，缺省false

2. **STEP\-FLOW\-CATEGORY\-CREATE\-2**：同次保存BASE、字段及allowDirectFollowup，不提交ROUTE；配置开关不重写既有业务模式

### 分支与异常

- **BRANCH\-FLOW\-CATEGORY\-CREATE\-1**：当类型/用途错配、依赖不满足或已用业务域被改，保输入拒绝，不动原基础及路由。

- **BRANCH\-FLOW\-CATEGORY\-CREATE\-2**：当合法基础及字段配置，基础成功，尚未绑定路由可保存，提示独立路由入口。

- **BRANCH\-FLOW\-CATEGORY\-CREATE\-DIRECT**：当开关缺失、false或读取未知，新DIRECT导入和新增直接执行安排不可用；原受理执行及必要本人填写、归档保准确收尾。。

### 完成后的状态

- 新跟进读最新定义，已开run/正式内容保持原貌

## 本功能验收

- **AC\-2038**：有品牌配置权的超管及租户管理员维护同品牌分类与两类独立字段库，普通运营只按权限选择；配置权不扩大业务数据权。

- **AC\-2039**：同一品牌提供新线索、冷线索、督办、服务、回访、售后类、活动类七预置分类；新/冷线索属LEAD，其他默认ORDINARY；自定义显式业务域。

- **AC\-2040**：新增或配置业务分类不新增供应商执行能力；场景、接口与电话资源仍需专业授权且准确匹配。

- **AC\-2102**：配置人员只能在获权品牌内维护分类、字段与模板；共享配置不授全品牌业务或录音访问。

- **AC\-2103**：分类稳定身份、业务域及编码名称明确，导入/填写两个Tab分别维护同用途有序字段、显示及对应入口必填。

- **AC\-2105**：条件按IMPORT/FOLLOWUP稳定fieldId或准确通话/AI上下文取值，不设单一标签来源，不按同名或首字段替代。

- **AC\-2135**：分类BASE、独立ROUTE、模板字段参考互不覆盖；实际绑定按所用稳定ID/用途/类型/选项/AI上下文校验，新跟进取最新资料而正式/运行快照不追改，未操作/缺失/明确清空分开。
