# 工作资料与维护入口

对外阅读：[当前交接包](../当前交接包/README.md)。开发日常按其中功能/任务索引阅读即可。

本目录供维护：

- `fragments/`：可编辑产品逻辑、字段、UI与原专业能力资料。
- `续接输入/`：当前规范化来源，保留稳定业务ID。
- `规划工作区/`：当前plan、来源快照和具名内容复核。
- `交接检查/`：当前规则、源指纹、任务覆盖、包和原型门禁结果。
- 生成脚本与日期复核记录：重建当前包及必要来源追溯；旧目录名在日期记录中表示当时位置，参照[重定位与清理记录](目录整理记录-20261031.json)，不要求被替代整包存在。

维护命令（在本目录执行）：

```sh
python3 维护交接.py check
python3 维护交接.py export
```

导出仅更新固定的当前DRAFT，临时目录用后清除；正式确认快照或未回写源的手工修改会阻止覆盖。原型或规范发生变化时，应先更新规范来源、刷新工作区并实际复核，维护脚本不会自动代签内容/业务/运营/工程批准。工程七项、真实接口/物理文件和命令仍由开发负责。
