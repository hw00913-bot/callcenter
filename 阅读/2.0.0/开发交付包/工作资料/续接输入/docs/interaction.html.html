生产口径与适用条件
N1 生产角色仅有本页五种生产角色。坐席是关联到当前租户账号的电话作业能力，租户管理员或运营均可按需关联，不作为权限角色。AI与云呼叫为业务模块；未明确的权限细项仍标待确认，不从原型预设身份推定。
N2 平台管理与业务选择超级管理员的组织与权限、接入管理全局读取，不受顶部品牌或业务租户过滤。业务、客户、呼叫和报表继续使用当前业务租户；相同品牌不自动共享业务数据或成员。
N3 账号与成员一个账号可在不同租户具有分别授权的成员关系；当前租户成员按总部/门店管理员或运营角色取得权限，并可按需关联本人电话坐席。全局账号资料和启停影响所有租户，成员角色、功能权限、坐席关联及成员启停按明确租户管理。总部/门店管理员只维护本租户成员，新增成员先明确目标租户。
N4 业务职责与流转租户管理员按本租户有权职责管理；运营还按分配、办理关系及有权历史读取。执行、转交、推进逐项核对职责、节点、版本和前段条件；转出后不自动查看下游当前资料。无意向门店时，同次指定门店并转交仅当前总部租户管理员可办理。
N5 坐席能力与电话作业坐席为管理员或运营账号在当前租户可选关联的电话能力，不改变角色及业务数据范围。租户运营的呼入接听能力以是否关联有效本人坐席为准；关联后仍满足原模块、成员、资源及在线状态条件。呼入接听与规则管理分别授权。未关联仍可使用原有非电话管理/运营功能；关联不扩大报表、客户、录音、明文及导出权限。退出、切换租户或业务域无需先完成通话、话后记录或电话状态核对，也不强制先退出电话坐席；普通未保存编辑仍按原有保存检查处理。
N6 财务功能授权五种生产角色均可按各自范围只读查看AI服务账户及充值流水；总部/门店管理员与运营也有本租户AI计费统计及原明细查看权限。已确认办理试用/年包/话费包、手工调账/核对同次服务结果、服务汇总导出三项仅超级管理员有权限，其余四种角色无权限；AI充值办理管理入口同属超管。各操作仍核原有权账户、产品、状态及数据范围。服务汇总导出沿当前分钟与服务信息口径，查看账户或流水不授办理及汇总导出权。
N7 资源功能授权总部/门店管理员已确认有本租户呼入规则查看、新增及编辑、通话记录核对，以及有权操作审计导出权限。配置维护不要求本人关联坐席；本人呼入接听另按有效坐席与原电话状态判断，运营关联坐席不授规则维护。平台和租户资源仍按原对象及状态管理，不因这些权限取得其他租户资源写入权。
N8 敏感内容已确认五种生产角色均可读取有权号码明文、读取/播放有权通话录音；总部/门店运营可导出有权云呼叫报表，总部/门店管理员可导出本租户有权操作审计。数据仍限各自原有权租户与对象；其他导出类型按对应矩阵项，坐席关联不另增范围。
N9 统一黑名单及原来源权限超级管理员仅按原有权范围只读查看，不具备黑名单维护权限。黑名单只有一个管理页面，保留原AI分组、号码、期限与同步结构，不再设置两类名单页签。客户拒联保留为分组内的准确来源，原有效范围和长期有效规则继续适用，正常呼入按原规则处理；本人电话作业成功保存明确拒联后关联同一分组，AI拒联仍须从有权来源人工核实。分组配置可增加天润云呼叫同步目标，按原同步授权、天润账号和支持的呼叫范围办理，回执未核定不显示已生效。运营保留原AI名单操作权；客户拒联来源的新增沿原独立授权，解除仍仅有管辖权的租户管理员填写原因，同号其他来源分别保留。
N10 分类与配置总部/门店运营已确认有本租户AI业务场景权限，无AI标签配置及供应商标签映射维护能力。使用已有标签和查看业务结果不等于维护标签配置。业务分类、共享字段、模板仍按有权品牌及配置授权维护，不因同品牌取得其他租户业务；原删除引用及历史保护保持。
N11 停用与收尾超级管理员管理全局账号停用；总部/门店管理员仅停用本租户成员。停用范围内禁止新操作，已接通电话及必要话后可有限收尾；此前已受理的租户任务按原条件继续，不自动转交。
N12 适用条件与待确认相应业务功能需模块已开通、功能已授权且对象/状态允许；电话作业另需本人坐席。平台管理不强绑无关业务成员或双模块资格。待确认项不是已授予，不凭本表开放权限；本次仅整理生产角色和既有规则，未重新定义未明确细项。
