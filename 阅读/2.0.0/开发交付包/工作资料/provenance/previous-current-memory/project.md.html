## 范围

- AI生产身份基准下的统一账号、多租户合法登录及租户独立模块/成员授权

- 工作台、业务中心、客户中心、呼叫中心、报表中心、系统管理六入口；无新增首页，复用原页面交互与电话边界

- 公共账号/租户/名单与品牌档案及唯一总部多门店关系，公共拒联拦AI/人工/预外呼/IVR

- 新模型品牌共用业务分类与原字段/取数接口承接；分类基础和路由独立保存，AI具体场景保持专业关联

- 固定分类/字段、独立路由及单模板版本的业务记录，分类导入/批次/同台账/详情，原租户内分配和有权监管

- 空节点逐个配置与明确起点、模板独立只读详情及未引用保护删除；人员启动和推进，路径ALL/ANY、通话状态及逐字段多选条件三态

- 同品牌线索串行培育及总部/门店多轮接续，意向门店定向和无意向仅总部ADMIN同次指派

- 存量保留原查询/处理，不自动迁移或按手机号/同名分类合并；本方线索入站及既有出站回传责任保持

- 通过入口归位、可靠关联跳转和原作业回看形成现有业务/客户/呼叫链路，不新增业务场景、独立客户业务域或重复维护对象。

- 整条记录最近执行段串行及原未保存人工段有权首次补录；转交成功清旧执行安排，原批次多选分配同次原子保存。

- 保留原字段/取数接口字典、接口单/多选、多源属性参数、人工结果二态和原完成回传及原有权联系历史；AI标签来源作用域保留，本版AI标签仅整合配置、映射和结果展示；不新增AI标准标签向业务字段写入及由此新增自动流转。原供应商池/场景映射/标准关联、原始及映射结果保留，未匹配保原值且不回退首项；既有业务字段条件、人工保存和其他原有流转不变。仅限本版，不作未来永久限制。

## 主要数据对象

- **品牌**：表达业务租户的品牌归属，归属不授予跨租户访问

- **业务租户**：两个工作区共同的业务隔离范围，基础身份以AI生产承接

- **登录账号**：系统认证主体，状态可全局停用

- **租户成员关系**：表达同一账号在某租户的访问状态及权限边界，生产承载方式待核

- **租户模块开通**：表达该租户可使用AI/云呼叫中的哪些模块

- **工作区操作授权**：表达成员在某已开通模块可执行的业务操作

- **电话坐席**：人工电话执行身份及在线状态，由云呼叫专业模块管理

- **供应商账号与执行资源**：机器人、线路、外呼组、队列、IVR流程等按所属模块原规则维护

- **公共业务分类**：新模型品牌共用分类BASE稳定身份及基础/原字段显示顺序必填与取数配置；与ROUTE独立保存，无单一标签来源指定。原目录ID和原授权保留，不按同名合并。

- **公共及专项名单**：以当前租户为隔离边界，保留原来源、范围、期限及同步/解除状态

- **品牌线索**：同品牌线索编码跨媒体/门店唯一；作为通用业务记录的线索类特例，不能借不同分类放宽，不与手机号档案归并。

- **接续轮次**：每次明确转交成功，归属和新增轮次一致落地，沿用同一线索编码。

- **培育执行段**：整条记录内串行的AI/预外呼/人工执行段，分别确认受理/结束/保存/不再呼叫。原租户/轮次/节点和表单版本固定，换owner/round不豁免最近段保存门槛。

- **转交办理记录与历史截止**：同次请求先核对未知，不重复建轮；已转出方只看转出前实际发生历史，再接收按当前身份。

- **分类路由配置**：已有分类独立可识别ROUTE版本，只关联一个有效模板精确保存版本，立即只读展示起点/节点/路径条件，逐规则核分类字段和选项兼容；不改基础/接口。

- **流转模板保存版本**：同品牌可复用的不可变保存版本，含明确起点、节点及edge条件；创建/修改形成新版本，独立详情只读，删除仅限全部当前/历史/待核引用均可靠为空的模板，不发布。

- **模板节点与路径条件**：新建无预设节点，逐个空白配置并选起点；固定节点职责/方式及合法edge，条件逐rule.fieldId/optionId，仅作人员选择准入，不自动运行。

- **通用业务记录**：非线索按品牌+分类+业务编码唯一，保存稳定记录身份、当前负责租户、批次和历史；重复不覆盖归属或产生副本。

- **记录模板实例及配置快照**：新数据固定分类/全部显示多选字段定义、ROUTE和单模板/edge条件及起点，记录当前节点；后改配置不追改，不创建或迁移存量实例。

- **门店编码映射**：在原品牌—门店租户关联维护稳定字符串业务编码，品牌内唯一且保留前导零；不是门店名或供应商enterpriseId。

- **转交目标依据**：客户原意向/映射版本或无意向ADMIN人工指派事件；人工目标不写回客户意向，门店目标与坐席任务分配独立。

- **记录有效标签及条件依据**：各业务多选fieldId分别保存有效optionIds、定义/值版本及原轮/段来源；当前owner本轮最近结束通话单独关联。未提供保留、显式[]仅清该字段，旧段不盖新值；本版AI标签仅整合配置、映射和结果展示；不新增AI标准标签向业务字段写入及由此新增自动流转。原供应商池/场景映射/标准关联、原始及映射结果保留，未匹配保原值且不回退首项；既有业务字段条件、人工保存和其他原有流转不变。仅限本版，不作未来永久限制。

## 核心用户路径
1. 登录并解析合法账号/租户/模块/操作范围，按原意图进入及恢复工作位置。
2. 分类基础与字段、独立单模板及路由、导入预览、批次/台账、分配、人工选择执行与结果保存，按条件由人推进。
3. 品牌总部/门店按准确意向映射或当前总部管理员同次指定转交，保整记录串行与原段首次补录。
4. 电话作业、话后与联系历史回看，拒联入库/四方式禁呼/原专项及单来源解除。
5. 原AI和云呼叫专业任务、配置、通话记录及报表按原资格使用，业务目录和内部编辑器无重复主维护。
