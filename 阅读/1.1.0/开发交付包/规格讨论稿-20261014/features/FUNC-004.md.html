# FUNC-004 接收外呼线索并按方式分流

状态：沿用旧FUNC编号的当前讨论投影，正式S7待重验；实际实现需查页面差异。

**优先级**：P0 · 最高。仅外部应用接口导入及双方式分流升P0；预外呼指定原供应商taskId，人工外呼坐席工号选填。该功能共享的手工CSV上传、粘贴和编辑不整体提级。

应用接口先校验准确应用/租户和本应用回调配置，再按明确外呼方式分流；无应用来源的原手工导入保持任务内流程。 API请求新增可复用业务批次号，原手工CSV不新增必填字段。 SRC124新增六个选填客户资料，逐行保存，原导入界面选填后置。 请求级businessType必填，按验真租户启用稳定码校验并逐条保存。

**business_object**：本次有效线索记录；预测分支为单号批次，人工分支为指定坐席分配记录

**primary_action**：接收外呼线索并按方式分流

**触发**：共享外部接口接收有效新业务请求或技术重传，或原手工导入弹窗确认当前有效名单

**completion_result**：应用接口先校验准确应用/租户和本应用回调配置，再按明确外呼方式分流；无应用来源的原手工导入保持任务内流程。
