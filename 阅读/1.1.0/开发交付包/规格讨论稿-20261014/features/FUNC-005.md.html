# FUNC-005 自动提交导入批次

状态：沿用旧FUNC编号的当前讨论投影，正式S7待重验；实际实现需查页面差异。

**优先级**：P0 · 必要依赖。预测接口导入所需首次自动提交、真实接收结果/53关联、原客户与请求保存及数据隔离；不将后续失败自动/人工补提交、手工CSV编辑、失败下载和号码删除整体提级。

仅预外呼方式：对已保存的有效初始线索按原任务及保存priority自动发起单号导入，保存本次实际fileId及明确受理/拒绝/未知证据；未知保持同次尝试不盲重发，受理不等于已呼叫。

## 操作边界

**business_object**：预外呼方式已保存的单号初始导入记录

**primary_action**：自动提交导入批次

**触发**：预外呼方式下，共享接口或原手工有效初始记录保存后，满足当前预外呼任务和准确记录提交守卫

**completion_result**：仅预外呼方式：对已保存的有效初始线索按原任务及保存priority自动发起单号导入，保存本次实际fileId及明确受理/拒绝/未知证据；未知保持同次尝试不盲重发，受理不等于已呼叫。

**included_scope**

1. 本功能仅用于既有预外呼任务范围；人工外呼走独立分配/跟进草案，不套用预测批次和供应商fileId。

2. 以本条引用的当前验收正文和本包局部逻辑定义为准；原S7功能定义已失效，不继承旧门禁。

**excluded_scope**

1. 真实供应商未核能力和业务系统内部实现不作为已实现承诺；新增人工分配/跟进目标在候选操作中单列。

**source_status**：19个旧功能ID沿用以便追溯，当前语义为开发讨论建议，需S7重新确认
