PredictiveCallCdrDetail数据类型定义：
字段 | 类型 | 描述 |
mainUniqueId | String | 主外呼通话记录唯一标识 |
uniqueId | String | 通话从通道记录唯一标识 |
calleeNumber | String | 呼叫的号码，可能是座席也可能是普通电话 |
agentName | String | 座席名称 |
cno | String | 座席工号，如2000 |
startTime | Long | 电话进入系统时间，时间戳，精确到s，如1480904471 |
answerTime | Long | 系统接听时间，时间戳，精确到s，如1480904471 |
endTime | Long | 电话结束时间，时间戳，精确到s，如1480904471 |
totalDuration | Int | 总通话时长秒数，单位是s |
mainCallType | String | 主通话记录来电类型 呼入 |
callType | String | 呼叫类型 转移 |
status | String | 外呼结果， 如座席接听 |
endReason | Int | 结束原因,接听之后的挂机原因 1000:主通道挂机 1001:非主通道挂机 1002:被强拆 |
sipCause | Int | SIP响应码：200 ~ 699 |
RecordFile | RecordFile | 通话记录录音数组，json格式 |
taskId | Int | 任务id |
taskFileId | Int | 任务文件id |
tsiFile | String | 号码状态识别录音文件名 |
displayNumber | String | 座席侧真实外显号码，当使用AXB场景进行外呼时，座席侧的真实外显号码为虚拟号 |
