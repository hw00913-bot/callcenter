# SRC-120 · 所有接入应用回调

## 用户实际答复

针对“应用没有填写回调地址时，DCC线索导入如何处理”：

> 现在修改，所有接入应用都要回调给业务系统

随后针对“所有接入应用都需要回调后，回调地址未配置时如何处理接口导入？这项规则将统一适用于DCC、天网等业务系统”：

> 先配置回调地址才允许导入（推荐）

## 取代关系与证据边界

本次明确取代此前天网仅平台查看、只有DCC结果回传的范围；DCC、天网及其他接入应用业务系统都需要回调。应用回调地址未配置时不得接口导入。界面手工导入不因此凭空具有外部接收系统。SRC-118的一对一、共享应用和外呼方式决定继续有效。

同租户共享应用采用共同地址分发还是按来源维护地址，仍在询问；未将任一方案写成已确认。生产报文、ACK、地址变更与积压结果处置仍须设计和核验。本答复不是G1/G2/G3或生产调用批准。
