# v1.1.0 需求与原型对齐审阅稿

本次按用户SRC-087五项修改及SRC-088完整回归/对齐指令修订，范围为：17项独立业务功能 / 62条验收 / 21条规则 / 5个场景 / 8条时序 / 5个页面 / 20个有效页面操作。

应用接入：应用列表、新增、详情、修改、删除为独立业务操作，显示和复制密钥属于查看明细；日常页面只围绕获取接入密钥用于后台租户token，保留超管及必要租户边界，移除技术交换演示。原FUNC-001保留修改，新增FUNC-018查询、019创建、020详情、021删除；后台FUNC-002身份交换保留，不再生成日常操作按钮。

主子批/本次priority/requestId：保留SRC-084～086全部已确认语义，不作新业务变更。每有效新业务行独立record/batch；true新主，false/未传有主新子挂最近主，无主首主；旧请求返原root/编号不重交。平台无每日衰减、自然日状态查询、旧priority强制继承。

原型本轮实际合成运行回归证据在 prototype/memory/verification-evidence/，真实接口仍partial/missing。生产密钥算法/存储/CRUD端点/token时效撤销与供应商重复接收、在途行为仍待核；当前合成立即失效、60字/重名等演示实现细节不升级为生产事实。
