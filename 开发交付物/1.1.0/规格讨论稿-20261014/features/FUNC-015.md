# FUNC-015 查询任务业务记录

状态：沿用旧FUNC编号的当前讨论投影，正式S7待重验；实际实现需查页面差异。

**优先级**：P0 · 必要依赖。仅既有预外呼任务范围内的接口导入记录、准确客观状态及关联详情查看；人工客户/通话/跟进详情由DRAFT-OP-FOLLOWUP承接，不套用预测标识。手工CSV、下载、删除和报表不整体提级。

返回本地导入、普通call/SIP、失败处理、秒挂三态和指定删除结果及精确关联/预算状态；未知如实展示，查询不隐式执行。 显示客户原导入的意向门店/车系编码与名称及Smartcode；缺值不猜配。 按原记录展示业务类型名称并保留编码；不从其他同号客户推断。

## 操作边界

**business_object**：当前授权原任务业务记录

**primary_action**：查询任务业务记录

**触发**：进入/刷新原任务记录并按原记录分类查看

**completion_result**：返回本地导入、普通call/SIP、失败处理、秒挂三态和指定删除结果及精确关联/预算状态；未知如实展示，查询不隐式执行。

**included_scope**

1. 本功能仅用于既有预外呼任务范围；人工外呼走独立分配/跟进草案，不套用预测批次和供应商fileId。

2. 以本条引用的当前验收正文和本包局部逻辑定义为准；原S7功能定义已失效，不继承旧门禁。

**excluded_scope**

1. 真实供应商未核能力和业务系统内部实现不作为已实现承诺；新增人工分配/跟进目标在候选操作中单列。

**source_status**：19个旧功能ID沿用以便追溯，当前语义为开发讨论建议，需S7重新确认
