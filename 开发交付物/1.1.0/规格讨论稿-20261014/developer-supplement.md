## 本轮最高优先级（P0）

三项并列最高优先级，先安排方案确认、开发与验收。按依赖推进，不把P0理解为已实现或门禁豁免。

| 优先级 | 范围 | 必须交付的行为 |
| --- | --- | --- |
| P0 | 应用接入 | 应用列表、新增、详情、修改、删除，应用与租户多对多关联、密钥与指定租户身份获取、每个应用回调地址保存。 |
| P0 | 导入客户接口 | DCC、天网等应用接口导入共用能力；明确外呼方式。预外呼必传原供应商任务ID taskId并核归属，按任务坐席组；人工外呼指定有效坐席工号agentWorkNo进入待联系。校验回调配置、逐行结果、请求去重及身份隔离。 新API导入请求必带业务批次号，同app/tenant可多次导入复用；与requestId去重、平台主子批和供应商fileId分离。 六个选填客户资料字段逐行保存，不删除leadCode/phone/priority，业务接口展开字段清单。 请求级businessType必填且按验真租户启用码校验，逐条保存，幂等含类型。 |
| P0 | 外呼未接通填单 | 人工拨号后、预外呼坐席振铃时即可填写原跟进表单；未接通结束保留内容并选择通话状态保存。号码状态沿API-327完整20描述/16编码，712拒接；人工状态与线路结果分别保存。 通话结束且处理结果为已完成沟通并可靠保存后，将本次通话和本次已保存业务信息快照回调原业务系统，携原业务批次号。 已填选填业务字段及选项的业务编码一并快照回传，不只传显示名称。 原导入意向门店/车系编码与名称、Smartcode及留资时间在现有表单和详情显示，完成快照携本次来源原值。 适用每次结果/进度及完成沟通回调携原业务类型码。 |

**实施顺序**

1. 应用接入与租户身份/回调配置先提供接口导入前提；同一P0内可并行开发工作台填单。
2. 分别验收预外呼taskId路由和人工agentWorkNo分配，再串联已约定的结果回调。
3. 联验未接通选择状态、保存/恢复与继续跟进依赖；正式实施和上线前仍按原证据要求核验。
4. 按原app/tenant/record/call固化完成沟通快照，再独立交付与确认；验证批次可复用、重传不重复、保存失败不发、跨应用不串及晚到话单版本方案。

其他v1.1.0功能保留原范围和原优先级；本轮不删除、延期或统一改为P1。混合功能/验收仅指定的接口或填单部分升P0。

## 当前可以组织的设计评审

1. 应用多租户关系和显式tenant身份，逐次授权与跨租户拒绝；应用各自callback配置及版本

2. 外呼方式分流：人工有效工号映射、保存分配幂等；预测沿任务组/原有批次

3. 跟进草稿、未接人工状态、处理结果和真实证据分离，条件必填与恢复

4. 继续跟进保当前坐席待联系，预测转人工后与原任务自动重呼排他及精确溯源

5. 预测失败120秒/四元组额外2次、持久预占及UNKNOWN恢复；精准删除

6. 全应用原app/tenant结果回调、版本/ACK/补送和变更地址积压处理

7. 失败下载固定快照、写入完成与后端条件清理

8. 业务批次号持久关联、完整请求幂等比较；本次跟进可靠保存与完成事件快照的一致提交、同call/保存版本去重，原app回调路由与ACK/晚到话单版本提案。需要明确字段与接收契约后实施。

9. 完成回调保留已填写业务字段与选项业务编码（多选全量），绑定保存时配置；缺码资料待完善，历史编码与补全版本方案先审，不改变本地保存成功事实。

10. 六个逐行来源字段的存储、完整内容幂等、人工/预测来源到本call映射、只读页面与完成事件快照；正式名称/长度及历史兼容需工程细化，不根据示例冻结字典。

11. 请求级业务类型的租户启用码校验、内容幂等顺序、原码与名称逐条固化、类型表单归属及两类回调原快照；完整人工方式、真实工程存储与回调待实现。

## 七类工程输入

| 类别 | 开发方需提供 |
| --- | --- |
| 仓库与脚手架 | 仓库、分支、当前提交、可重复构建/启动方式；静态原型不能代替后端仓库。 |
| 技术栈 | 前后端框架、运行时、版本与团队标准。 |
| 服务边界 | 应用身份、接收、调度、供应商适配、事件、回传、下载与授权落点。 |
| 数据 | 记录/主子/attempt/预算/结果版本/快照的持久实体、约束、事务和迁移；旧数据未知先隔离核实。 |
| 接口 | 本方正式报文与鉴权/错误语义，各接入应用结果版本与ACK协议，AliCti目标版本配置及精确映射。 |
| 编码规范 | 团队规则及可定位版本，错误处理、日志脱敏、迁移与兼容规范。 |
| 验证 | 承接104条CHECK，填写真实框架/命令和测试环境；补并发/崩溃/未知/权限/删除/下载/回传验证。 |

## 实施前与实施后

供应商关键规则、业务系统正式契约和下载技术可行性先核实；工程原子保存、并发计次及恢复实现证据开发后、上线前补齐。逐项责任和依赖见[待核清单](open-items.md)。局部浏览器保存验证不等同生产后端删除安全性。
