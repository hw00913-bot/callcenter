## 关键对象与最小复用关系

新模型：品牌 → 品牌共用分类基础/字段版本 → 独立单模板路由版本 → 固定模板及节点/路径条件 → 新业务记录及配置快照 → 当前实例节点。各条件直接引用分类已有多选fieldId/optionId，无单独标签来源指定；旧目录及历史按原ID处理，不按同名或手机号合并。

责任租户、租户内分配、轮次、执行段、固定模板节点、意向门店和路径判定分别管理。新模板机制只对新数据；合法转交成功才切归属并接续新轮、清旧执行安排。备用及接续切换已退役，历史不追改。

配置、监管及AI财务/服务/资源资格分别按原权核定，不强制业务成员或双模块，不授代处理。实际外呼启动按对应模块/成员/资源及公共禁呼核验。

## 必要异常和关键准入

- 启动下一方式检查整条记录最近段结束且结果保存，换owner/round不豁免；仅整条记录从未有段才无前段。转交只核执行结束且不再呼叫等原准入，不一律要求前段结果先存。
- 各规则按自身业务字段已保存值、来源和定义/值版本作ALL/ANY三值判定；缺值与读取/来源待核分别处理。多条路径匹配由人选择，预览不代替提交重核，不自动推进、呼叫或转交。
- 总部有意向只到唯一有效映射门店；无意向保同记录待指派，仅当前HQ ADMIN同次补选并确认；映射异常不按名称或首店猜测，门店只回唯一同品牌总部。
- 分类基础与独立路由分别保存并核原版本。单模板/逐字段条件不兼容时保原关联标需复核，只阻新模板新数据；不阻原AI已关联场景按原规则建任务或旧数据原处理。
- 原批次多选分配逐行复核，任一行失败全批不写。转交成功清旧安排，接收方按本租户资格另行分配，不自动起呼。
- 原已结束未保存人工段可由原有权人员首次补录，锁原租户/轮次/段/固定表单，不读下游字段、不改新owner或覆盖当前值；已保存结果不重写，停用仍限已确认收尾。
- 独立模板详情只读精确版本；保护删除仅在无当前/历史分类、记录/批次及待核引用时按权办理。新建空节点、明确起点、局部更新及条件草稿沿原交互。

## 本版AI标签配置与结果边界

原供应商标签池、场景启用及映射按原supplierId/tenantType/标签scene身份和权限保留，标签场景不等于具体执行场景或品牌分类；推荐、名称及首项不当业务事实。SRC-2096已选择本版仅整合配置、映射和结果展示，不新增AI标准标签向业务字段写入或由此新增自动流转；不误删原字段条件/人工保存/其他既有流转，不作未来永久禁令。未匹配保原始结果，不首项兜底。

非本期范围：客户主档/生命周期/统一待办、公海或自动回收、模板发布、自动调度/推进、门店直接互转/任意改派、历史初始化、新增各轮回传及其他分类开放入站。非线索分类仍限租户内节点；旧IVR任务保留，未新增为模板节点方式。源partial/missing及前序正式基底限制保留，不继承源风险接受。
