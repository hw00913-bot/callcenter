# 业务术语

| 术语 | 含义 | 事实状态 |
|---|---|---|
| 品牌 | 关联总部/门店业务租户的基础归属 | 已确认；不授予共享数据权限 |
| 业务租户 | 两工作区共用的业务隔离范围，以AI生产稳定身份承接 | 已确认方向；实际标识待核 |
| 系统账号 | 登录身份，可能在多个租户获得授权 | 统一登录目标已确认；生产成员结构待核 |
| 租户成员 | 一个账号在某租户的访问及授权关系 | v2分层要求；非生产已验证实体 |
| 电话坐席 | 云呼叫内承担电话操作的执行身份/在线状态 | 不等同登录账号，配置仍归专业模块 |
| 供应商账号/机器人 | 模块执行所用资源及外部身份 | 不因统一账号而合并 |
| 公共业务分类 | 当前租户两个工作区共用的业务目录 | 不覆盖AI供应商类型或云呼叫businessType历史值 |
| AI场景配置 | 原“标签管理→场景配置”中维护的分类/标签配置入口 | 用户已说明入口；与具体执行场景的关系待生产核验 |
| 公共明确拒联 | 客户明确拒绝联系形成的长期公共禁呼 | 四种外呼拦截，正常呼入保留 |
| 专项名单 | 意向保护/内部保护等沿原范围及期限的限制 | 不自动升级为公共永久禁呼 |
| restrict tel | 云呼叫供应商外呼失败原因之一 | 不等同客户拒联或公共禁呼命中 |
| 本版v2.0.0 | 原暂称v1.1.1的整合方案 | 与当前独立v1.1.1业务数据接口版本分开 |
