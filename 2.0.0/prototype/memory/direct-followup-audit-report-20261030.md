# 直接跟进与模板流转：本轮审计与验证

用户确认方案已落实到当前原型及代码，两个办理方式共用业务台账与稳定业务身份。分类的“允许直接跟进”默认关闭，管理员明确开启后，导入可整批选择直接跟进；AI须选场景。基础导入必填、类型、映射、唯一性仍严格，模板校验失败不自动降级。

直接跟进使用独立周期，不创建模板运行或流程节点；支持分配、明确本地模拟起呼、实际本人填写、资料快照、归档、完成与再次跟进。原业务可以明确启用当前分类流程，先核验原执行、待核和必要归档已收敛，再补齐当前资料与入口；旧通话和快照不改，旧事实不能完成新CALL，旧直接入口不能与新运行并行起呼。

本轮实施及完成后交叉审计已修复：

- 直接跟进的资料快照夹带分类模板绑定。
- 无真实人工通话时误开放填写；进一步发现并修复预外呼“坐席接听”被误认为“客户接通”的P2，填写与归档按同次通话真实客户接通和准确本人判定，矛盾终态保原事实并待核。
- 分类撤销直接权限后的队列入口遗漏。
- 启用流程弹窗遇到并发新增字段时，表单未刷新；现按稳定字段身份保输入并重新预检。
- 再次直接跟进后旧结论不显示；现从不可变办理事件读取原结论及说明。
