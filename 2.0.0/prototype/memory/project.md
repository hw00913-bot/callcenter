## 产品目标

原址离线重建统一入口及业务与客户闭环，保留43个FUNC、134个AC、43个当前PAGE与222项专业能力。分类显式决定是否开放直接跟进；整批可明确选择直接跟进或按模板流转，保持业务、跟进和通话事实完整。

## 目标用户

平台超级管理员、租户管理员、业务运营、业务跟进人和只读查看者；本人坐席能力按原专业资格单独授权。

## 核心用户路径

合法身份进入当前租户→配置品牌字段/分类及直接跟进开关→整批明确办理模式→严格导入→分配跟进人→实际呼叫→本人填写与唯一归档。DIRECT无run/节点，只在同租户继续跟进；TEMPLATE按当前捕获方案明确推进或合法转交。DIRECT明确完成周期结论后可显式选择下一次方式建立新直接周期并重新分人。DIRECT后续启用流程先验证当前路由/必需资料及全部旧执行、必要归档收敛，再于原业务显式建立新run，不重复导入。

## 主要数据对象

账号、租户、品牌、成员授权、独立用途字段、业务分类（allowDirectFollowup缺省false）、字段参考模板、实际路由、导入批次（整批handlingMode）、业务（DIRECT另含directMethod）、独立直接周期（directCycleId/directCycles、状态及结论）、真实模板运行/节点、跟进段、通话尝试、内容快照、联系限制、当前更正及审计。DIRECT不伪造run、节点或模板方案；原AI／Cloud专业对象保持。

## 交付方式

本目录index.html为原址静态离线入口；当前memory和规范JSON提供产品事实，独立产品规格包用于评审及工程对齐。冻结启动计划、workflow和审批保持原记录；真实工程契约、供应商与生产授权须独立补证。

## 范围

五区导航：坐席工作台、业务&客户、呼叫中心、报表中心、系统管理。品牌共享配置与租户业务资料范围分开；统一账号、五生产角色、模块授权及本人电话能力分别判定。

分类导入/填写双Tab及IMPORT/FOLLOWUP字段库保持；DIRECT仅放宽路由附加资料，基础必填/类型/映射/唯一性保留，AI场景必选。分配仅安排本租户跟进人，场景在同一安排入口明确，不改owner或自动起呼。

TEMPLATE实际路由与参考分类分开；开始、转交、呼叫、结束固定。已开始run沿原流程完成或废弃；新run封当前明确有效方案。

两模式均以真实实际办理/接听人填写，跟进捕获最新实际分类及有效值并封快照；当前更正、跟进归档、流程推进和业务结论分开。全部旧直接执行与必要归档收敛后才可启用新run；旧事实不得完成新节点。

原AI、Cloud、IVR、资源、财务、报表、录音和专业客户任务保持独立对象与权限。不做旧v2流转数据迁移，但今后真实运行、跟进、通话和审计完整保留。
