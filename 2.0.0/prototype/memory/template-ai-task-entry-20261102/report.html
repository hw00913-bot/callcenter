原因与修复

原任务控件为默认执行对象且需先选场景才列任务；未知执行租户会整块隐藏。冷打开目录无自动读取，切换方式/任务重绘又将配置区滚回顶部。

  • AI呼叫任务明确置于对应场景前，按原目录过滤后可直接选择
  • 仅准确唯一task/scene/供应商/平台绑定自动带出场景；多匹配/冲突不首项猜测
  • 明确暂不指定、后续分配；不削弱执行前有效任务/场景校验
  • 无权或范围不符显示禁用控件及准确原因，不新增SUPER或运营task.assign权
  • 冷打开AI节点一次自动读取，前后校验editor/tenant/category/method/权限，失败明确且不自动循环
  • 选择任务与目录完成重绘保配置区滚动及当前草稿输入
