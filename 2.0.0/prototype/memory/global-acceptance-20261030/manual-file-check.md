# 直接双击的最小人工核验

file自动验收未执行，沿既有工具边界保留。本轮S8/final结果的范围是静态资源/本地模型及获准HTTP浏览器。

1. 在当前项目目录双击prototype/index.html，确认登录页和图标可见，无需启动服务。
2. 使用页面内演示工具选择现有演示账号，在有权租户进入原合法业务页；确认五入口按角色显示。
3. 切换业务流程、时序、关联系统和版本视图，再回原型，确认保持同一外层页面且内页不重复导航。版本清单读取项目内memory/public的已注册公开投影。
4. 在独立演示环境核分类、两办理模式及一条合成名单的预检；原用户数据保持。

只将实际观察结果计入file验证；任何读写或资源异常保留现场反馈，不清缓存/数据，也不凭HTTP结果补写通过。真实接口、通话和账务不在此人工核验中执行。
