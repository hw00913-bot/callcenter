运营怎样使用

业务&客户
业务分类 → 流转规则模板 → 分类路由 → 业务台账中的导入与分配。按已确认规则由人员启动、推进和转交；在同一区域查看客户联系、维护联系限制。入口合并不改变独立权限、数据范围与电话离开保护。
呼叫中心
配置 AI、人工、预外呼、IVR 和呼入所需的专业资源；执行、记录与供应商配置沿用原模块。
坐席工作台、报表与系统管理
分别承载坐席作业、原有统计、品牌租户及成员权限。品牌关联本身不授予跨租户数据访问权。
