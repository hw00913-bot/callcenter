## FIELD-PLAT-REPORT-DATA 报表指标与明细

[基本规则](field-specs.md#FIELD-PLAT-REPORT-DATA)

| 子键 | 具体规则 |
|---|---|
| reportKind | type=string；required=True；rule=Cloud七类及AI-call/AI-billing/AI-lead明确区分；不以同名字段跨报表共享分母 |
| appliedFilters | type=object；required=True；rule=与本次统计结果同次固定的有权筛选，见FIELD-PLAT-QUERY |
| scope | type=object；required=True；rule=准确账号/租户/enterprise/平台读权交集 |
| summary/rows | type=object/array；required=True；rule=按以下report_variants字段解释；可靠空结果rows=[]，读取失败不是空集 |
| quality | type=object；required=True；rule=缺失时间/号码/归属/首重呼/时长样本分别计量展示；不静默填0 |
| detailLinks | type=array；required=False；rule=准确row key和callId/taskId/customerId，仅明示已实现入口可进入，目标读权再次检查 |

### overview

粒度：当前有权tenant+enterprise；按呼叫方式行

归期：已结束话单开始时间归期，缺失只用可核实接通/结束时间；时间全缺不计周期并显示质量计数

| 列键 | 含义 | 类型／单位 | 计算和空值 |
|---|---|---|---|
| type | 呼叫方式 | string／枚举 | 人工/预外呼/IVR/呼入 |
| total | 呼叫量 | number／次 | 周期内已结束的呼叫尝试；重呼另算一次 |
| connected | 客户接通 | number／次 | 有明确客户接通证据 |
| unanswered | 客户未接通 | number／次 | 有明确未接通证据 |
| pending | 结果尚未明确 | number／次 | 证据不足，不能当未接通 |
| rate | 接通率 | number／% | connected/(connected+unanswered)×100，一位小数；分母0为— |
| firstCount | 首呼量 | number／次 | 完整可见历史或明确attemptNumber=1证据；不因筛选周期重算 |
| firstRate | 首呼接通率 | number／% | 首呼接通/首呼已确认结果量，一位小数；unknown首重呼不入分母 |
| repeatCount | 重呼量 | number／次 | 明确attemptNumber>1或同任务有已知更早尝试 |
| duration | 双方时长 | number／秒 | 接口双方bridgeSeconds有效非负样本合计，自动纯IVR不适用 |
| customerSeconds | 客户接听时长 | number／秒 | 仅预测/自动接口明确客户时长，其他方式不补算 |

summary_extra：customers按tenant+enterprise+规范号码去重，号码未识别另计，不以callId伪造客户；durationSamples为已接通且适用且时长可确认样本，0秒有效；durationMissing不当0；avgSeconds=有效双方时长合计/有效时长样本数；无有效样本—；显示最多一位小数秒；attemptUnknown单列，不默认首呼

drill：方式行/指标/时间桶→同筛选准确callId；录音/文本按对象读权

### leads

粒度：仅当前有权范围内，同品牌同稳定线索编码聚合；无编码行各自保留，不按手机号合并不同编码

归期：以线索首次导入日期筛选，再显示这些线索截至当前累计联系及最新业务填写；不是历史状态快照

| 列键 | 含义 | 类型／单位 | 计算和空值 |
|---|---|---|---|
| code | 线索编码 | string／文本 | 前导零保留 |
| name | 客户 | string／文本 | 称呼及关联规范号码 |
| followupStatus | 跟进状态 | string／枚举 | 原待继续跟进/已完成及原未分配状态 |
| callCount | 呼叫次数 | number／次 | 关联的明确呼叫尝试数 |
| connectedCount | 接通次数 | number／次 | 至少客户接通的准确通话次数 |
| lastContactAt | 最近联系 | string／时间戳 | 该线索最后联系时间 |
| intentionLevel | 意向等级 | string／枚举 | 最近一次已填写意向值，未填为空不首项 |
| plannedVisitAt | 计划到店 | string／日期时间 | 计划到店时间与门店，不表示已实际到店 |

summary_extra：leadCount为筛选线索条数；assigned至少一关联名单分配；contacted至少一次呼叫尝试；connected为至少一次确认客户接通的线索数；pendingFollowup未标记跟进完成；contacted/leadCount联系覆盖率与connected/leadCount线索接通率，一位小数；分母0为—；completed只指原跟进完成，不指成交；visitIntended/testDriveIntended取最近已填有意向，不等实际到店/试驾；intentionRecorded为已填写意向条数，plannedVisit为已计划到店条数，missingCode另列

drill：准确聚合key→仅其授权业务记录id/任务id/callId；原始多记录不合并业务身份

### customers

粒度：导入批次行；每批每条客户名单计1条

归期：按导入批次日期选择，显示截至当前分配/跟进累计状态

| 列键 | 含义 | 类型／单位 | 计算和空值 |
|---|---|---|---|
| name | 导入批次 | string／文本 | 准确batchId名称 |
| businessType | 业务类型 | string／枚举 | 导入当时业务类型 |
| total | 名单量 | number／条 | 本批客户行数 |
| assigned | 已分配 | number／条 | 已分配人工坐席或专业任务 |
| unassigned | 待分配 | number／条 | 没有坐席也没有任务 |
| contacted | 已联系 | number／条 | 具有呼叫尝试，不要求接通 |
| followup | 待继续跟进 | number／条 | 原跟进状态待继续跟进 |
| completed | 跟进完成 | number／条 | 原人工已完成，不表示成交 |

summary_extra：同号不同批次分别计名单；distinctCustomers按当前tenant+规范号码去重另显；不把旧专业坐席/任务分配解释成新四节点导入分配目标

drill：批次行/状态指标→该范围原客户名单id及当前归属状态，不增加准确批次导出能力

归期：任务创建/计划/启动日期在周期内或周期内有通话；周期通话与累计供应商/平台名单并列不可混算

|---|---|---|---|
| name | 任务名称 | string／文本 | taskId对应名称 |
| callType | 任务类型 | string／枚举 | 预外呼/IVR |
| status | 当前状态 | string／枚举 | 准确任务确认态 |
| supplierTotal | 累计号码 | number／条 | 供应商任务报表总号码，不按本周期裁剪 |
| supplierCalled | 累计呼叫 | number／次 | 供应商任务累计呼叫次数含重呼 |

| completed | 平台已处理名单 | number／条 | 平台累计已处理客户行数，不代表接通 |
| finishRate | 平台处理率 | number／% | 平台累计已处理/平台累计名单，不是供应商进度 |
| loaded | 周期呼叫量 | number／次 | 本周期已加载的已结束尝试 |
| connected | 客户接通 | number／次 | 周期确认接通 |

### inbound

粒度：每个已结束呼入callId一行

归期：按已结束呼入开始时间，缺失仅可靠接通/结束时间；正常呼入不因公共拒联排除

| 列键 | 含义 | 类型／单位 | 计算和空值 |
|---|---|---|---|
| id | 通话编号 | string／标识 | 准确callId |
| tenant | 所属租户 | string／文本 | 当前授权tenant |
| agent | 首呼坐席 | string／文本 | 接口首呼目标，不代表流转后全部实际接听人 |
| result | 客户结果 | string／枚举 | 客户接通IVR不等于人工接通 |
| humanResult | 人工结果 | string／枚举 | 双方接通才确认人工通话 |
| queueResult | 排队结果 | string／枚举 | 官方队列中放弃/溢出，不自行推排队超时 |

summary_extra：呼入量已结束呼入次数；人工接通率仅人工已确认结果分母；首队列平均等待=可靠首次排队秒数和/首次排队有效样本数，无样本—；queueAbandoned/queueOverflow须系统应答且官方相应队列结果；不可只看短时长猜测

### AI-call

粒度：当前有权AI租户，日期+具体场景+平台行；保外呼统计/客户统计两tab

归期：原AI呼叫时间筛选，场景与平台独立；不混Cloud已确认结果分母

| 列键 | 含义 | 类型／单位 | 计算和空值 |
|---|---|---|---|
| date | 呼叫时间 | string／日期 | 原统计归期 |
| sceneName | 场景名称 | string／文本 | 准确原场景 |
| platformName | 智能平台 | string／文本 | 准确供应商平台 |
| dialTotal | 拨打总次数 | number／次 | 原拨打次数 |
| rosterTotal | 呼叫名单总数 | number／条 | 原本行名单/客户基数 |
| connectedTotal | 接通总数 | number／次 | 原统计确认接通数 |
| missedTotal | 未接通总数 | number／次 | 原统计确认未接通数 |
| connectedRate | 接通率 | number／% | 当前renderer connectedTotal/rosterTotal×100，两位小数 |
| touchRate | 触达率 | number／% | 当前renderer (connectedTotal+missedTotal)/dialTotal×100，两位小数；保原AI口径不替换Cloud公式 |
| duration | 累计通话时长 | string／人类可读时长 | 源值如23分15秒/1小时12分8秒；不得当分钟数直接做账务 |

summary_extra：明确分母=0时原AI显示0.00%；源字段缺失/未知不假装为已确认0；客户tab展示date/scene/platform/rosterTotal客户总数/connectedTotal有效通话客户数/duration累计时长；客户平均通话时长当前renderer仅—，本版未提供计算能力，不编造均值；原列设置/导出若仅有界面但未实现，明确不可用，不生成假文件

drill：原AI通话统计为行展示；无已实现明细动作时不由表格自行新增通话查询权

### AI-billing

粒度：当前有权AI租户，计费日期区间+平台+计费类型；下钻模型，再到准确通话

归期：计费日期筛选独立于服务汇总8列导出及公共租户列表筛选

| 列键 | 含义 | 类型／单位 | 计算和空值 |
|---|---|---|---|
| dateFrom/dateTo | 计费日期 | string／日期区间 | 原计费统计归期 |
| tenantName | 租户名称 | string／文本 | 准确AI服务租户显示 |
| platformName | 智能平台 | string／文本 | 原供应商平台 |
| billingType | 计费类型 | string／枚举 | 原按分钟收费；按账号收费不在此统计 |

detail_columns：模型层：计费日期/租户/平台/模型类型/计费时长分钟；通话层：规范用户号码/通话开始结束时间/原通话时长/逐通计费分钟/场景名称
