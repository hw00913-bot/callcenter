## 页面状态

- normal：按准确有权AI账户展示分钟及服务快照；详情查看独立于超级管理员套餐办理，不因无充值管理菜单取消本租户只读入口。

- loading：首次加载显示当前模块/对象读取中，依赖此结果的动作暂不可用；刷新保留当前已应用筛选和已确认资料并标正在更新，响应只回当前准确对象/范围。

- empty：没有已关联账户显示待关联／不可读取原因；可靠查询确无流水显示暂无，不把缺数补成0。

- error：账户身份不明、分钟字段未知、范围变更或取数失败时显示待核并阻导出／办理，不回退到其他租户数据。

- no_permission：五角色可按各自有权账户只读；购买／手调仅超管专业财务权，租户角色不出现办理按钮。

- submitting：提交中固定当前准确对象和输入，不接受同一动作重复发送；真正成功后更新当前值/列表，失败保草稿，未知保准确同次请求并显示核对入口。

展示格式：标签在控件上方，查询按钮底线对齐，不把未应用输入误作导出条件。
