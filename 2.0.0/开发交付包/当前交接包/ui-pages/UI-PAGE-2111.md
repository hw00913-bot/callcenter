## 页面状态

- normal：标签场景目录、标签供应商目录、标签定义、供应商映射和具体执行场景分类关联分别保存。标签场景不等于AI业务类型或具体AI执行场景；稳定ID、租户、供应商、场景和修订共同确定条件含义，使用场景不取得标签维护权，不向业务填写字段隐式写值。

- loading：首次加载显示当前模块/对象读取中，依赖此结果的动作暂不可用；刷新保留当前已应用筛选和已确认资料并标正在更新，响应只回当前准确对象/范围。

- empty：无标签集合／映射时显示对应空态及允许维护入口；缺准确上下文显示需选择，不自动取第一套标签。

- error：映射冲突、标签停用、上下文修订变化、无权或读取失败保原配置；不把未知标签当明确无标签。

- no_permission：运营无标签及供应商映射维护权限；已有场景使用／结果读取不授维护权，有权超管／本租户管理员另核专业配置范围。

- submitting：提交中固定当前准确对象和输入，不接受同一动作重复发送；真正成功后更新当前值/列表，失败保草稿，未知保准确同次请求并显示核对入口。
