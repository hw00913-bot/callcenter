## 页面状态

- normal：按租户和可靠号码关联当前有权业务；同号码可聚合阅读，不合并业务编码、归属或字段实体。各业务展示实际分类、当前值、当次快照与已转出截止资料。

- loading：首次加载显示当前模块/对象读取中，依赖此结果的动作暂不可用；刷新保留当前已应用筛选和已确认资料并标正在更新，响应只回当前准确对象/范围。

- empty：无客户／业务展示当前范围无记录；有联系人但没有业务时明确两类信息，不造空业务或自动建运行。

- error：关联范围、号码或来源不能唯一核定时提示待核，不按姓名／跨租户同号猜配；查询失败保筛选及上次可信状态。

- no_permission：管理员、运营和监管只读取自己有权客户／业务；实际接听者的最小填写入口不因此取得整个客户档案。

- submitting：提交中固定当前准确对象和输入，不接受同一动作重复发送；真正成功后更新当前值/列表，失败保草稿，未知保准确同次请求并显示核对入口。
