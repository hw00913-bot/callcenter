## 页面状态

- normal：应用创建成功生成稳定身份与密钥；密钥不在列表或提示中泄露，详情和复制只给明确权限。删除成功后该应用不能继续获取新token，按引用／对象守卫执行。

- loading：首次加载显示当前模块/对象读取中，依赖此结果的动作暂不可用；刷新保留当前已应用筛选和已确认资料并标正在更新，响应只回当前准确对象/范围。

- empty：无应用显示新增指引；无查询匹配显示调整条件；无授权租户不擅自授全部租户。

- error：名称／回调／授权租户错误、失权或创建／删除失败时保表单／原记录；读取失败不当空列表。

- no_permission：只有全局接入应用维护资格的超管；租户角色不因业务菜单可见获得密钥和应用写权。

- submitting：提交中固定当前准确对象和输入，不接受同一动作重复发送；真正成功后更新当前值/列表，失败保草稿，未知保准确同次请求并显示核对入口。

### [FIELD-PLAT-API-PAYLOAD](../field-specs.md#FIELD-PLAT-API-PAYLOAD) — 业务系统导入内容

组件：UI-COMP-FORM

辅助说明：同应用授权租户/enterprise/当前目录必需字段及重复标识校验；重复同业务请求幂等；冲突内容不覆盖已有业务；不能手机号合并

显示条件：具本字段读取资格且本页对应列表/详情/表单区域展开时显示；无对象读取权时隐藏值，按本页无权状态处理。

编辑条件：本页动作和字段写入资格同时成立、对应对象状态允许、草稿未提交且无未知请求时可编辑；已鉴权且具有该租户接入权的外部业务系统

必填提示：满足“提交该实体的新建或修改时必填”时在可编辑控件标签显示*；只读展示不显示输入必填。

校验时机：输入/选择变化即时提示格式和依赖；失焦提示本字段；最终提交重新校验全部必填、跨字段、对象范围及修订，动态上下文变化使原确认失效。

错误文案：“业务系统导入内容”不满足要求：同应用授权租户/enterprise/当前目录必需字段及重复标识校验；重复同业务请求幂等；冲突内容不覆盖已有业务；不能手机号合并；定位当前字段并保输入，禁止静默代填。

展示格式：appId+准确授权tenant+稳定业务ID+规范号码+目录必需值；缺失显示“未取得/未填写”，合法0、false和空集合分别按真实值显示，不互换。

### [FIELD-PLAT-API-RESULT](../field-specs.md#FIELD-PLAT-API-RESULT) — 业务结果回传

组件：UI-COMP-READONLY

辅助说明：完成业务保存成功后回传当前准确结果；失败保留待回传；重试同请求幂等；超时不当成功，不重拨或重写跟进

显示条件：具本字段读取资格且本页对应列表/详情/表单区域展开时显示；无对象读取权时隐藏值，按本页无权状态处理。

编辑条件：此页只读，显示系统/外部已确认事实或配置摘要；读取资格不授修改权限，另有明确维护入口时再次核其动作权。

必填提示：本页只读，不显示输入必填星号；业务必需条件由相应办理动作按同源字段规格校验。

校验时机：此处无用户输入校验；取值时核对准确对象、范围与真实可用状态，缺失/未知与空结果分开。

错误文案：只读字段无需输入校验；来源无法确认时显示“未取得/待核”及恢复入口，不用0、空值或首项伪造。

展示格式：准确原业务/通话ID、原人工结果、回传请求及受理/终态；缺失显示“未取得/未填写”，合法0、false和空集合分别按真实值显示，不互换。
