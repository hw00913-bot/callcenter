## 页面状态

- normal：池类型区分中继群组／号码群组；清单保存是完整替换，清空须明确确认；被任务引用或在用默认池不能删除。

- loading：首次加载显示当前模块/对象读取中，依赖此结果的动作暂不可用；刷新保留当前已应用筛选和已确认资料并标正在更新，响应只回当前准确对象/范围。

- empty：无号码池显示新增入口；池内没有号码显示0个，前提为可靠完整读取。

- error：数量／号码值不合法、默认池／执行任务引用、并发或外部保存未知时保原清单，不能用空列表覆盖未读出的号码。

- no_permission：平台管理范围／本租户资源管理员维护，运营只能在有权任务中选择可用池。

- submitting：提交中固定当前准确对象和输入，不接受同一动作重复发送；真正成功后更新当前值/列表，失败保草稿，未知保准确同次请求并显示核对入口。

### UI-ACT-2076-PLAT-RESOURCE-NUMBERPOOL-DELETE

触发：有原删除权者对准确号码池确认删除

行为：展示准确对象并最终检查原默认/预置/引用/在用保护；只删除本对象允许的目录记录，不清任务/通话/账务或其他资源；只有确认成功刷新，失败/未知保可核对状态。可观察结果：仅准确可删号码池确认删除；原不提供删除能力的变体不得被通用入口新增。无权/字段不合法/对象失效/修订冲突时：明确显示本次拒绝原因，保留可继续的输入和已确认原值，不作变更；提交失败或结果未知时：失败保留原确认值；未知显示待核并按同请求核对，不重复提交或假报成功

局部逻辑：LOCAL-PLAT-RESOURCE-NUMBERPOOL-DELETE

测试：CHECK-PLAT-RESOURCE-NUMBERPOOL-DELETE
