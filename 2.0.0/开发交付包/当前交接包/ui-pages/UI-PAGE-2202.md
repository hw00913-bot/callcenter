## 页面状态

- normal：本人有效坐席可上线、切换允许状态、人工外呼、接听呼入／预外呼并完成必要话后；客户拒联须在本次准确通话正式保存后入库。监管置忙／置闲／离线逐个核目标。本轮跟进开始读取最新字段定义及当前有效值并捕获，正式保存使用本轮已展示定义，不临时换schema或吸收未展示值。

- loading：电话资源/连接初始化显示准确准备步骤；本地点击不置在线，回执待核时保持原准确电话现场和禁止重复动作。

- empty：无本人有效坐席时显示未关联／不可作业及原因；没有当前通话时显示待机，不编造客户或拨打计数。

- error：坐席资源无唯一映射、号码限制命中、在途状态不明、保存失败保持现场与原输入；未知受理不假报完成也不重复拨打。

- no_permission：电话使用需当前租户模块、成员、本人坐席及作业权；超管可监管时也不能替他人保存话后或拨号。

- submitting：提交中固定当前准确对象和输入，不接受同一动作重复发送；真正成功后更新当前值/列表，失败保草稿，未知保准确同次请求并显示核对入口。
