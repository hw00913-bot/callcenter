## 页面状态

- normal：账号身份、租户成员、模块角色和电话坐席能力分别表达。管理员只能维护本租户成员／可授权限，超管全局动作也核对象；成员停用和账号停用不混写。

- loading：首次加载显示当前模块/对象读取中，依赖此结果的动作暂不可用；刷新保留当前已应用筛选和已确认资料并标正在更新，响应只回当前准确对象/范围。

- empty：无账号／成员显示有权创建或关联入口；当前模块未开通显示不可授原因，不自动开通。

- error：同名／手机号不能代稳定身份合并；重复、越权授予、资源关联不唯一、并发或保存未知保持输入／原权限，只有明确成功刷新真实范围。

- no_permission：运营无账号维护；全局编辑／停用／删除需超管相应资格，本租户管理员不能因成员管理权编辑全局身份。

- submitting：提交中固定当前准确对象和输入，不接受同一动作重复发送；真正成功后更新当前值/列表，失败保草稿，未知保准确同次请求并显示核对入口。
