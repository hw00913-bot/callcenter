## 页面状态

- normal：场景使用准确当前租户和业务分类，创建／修改不产生AI标签维护权；业务执行可选择已有场景，其可用性与标签维护页面权限分离。 主场景只保原添加字段唯一入口→来源二选一→独立选择/配置弹窗→子确认入父草稿→主场景明确保存。下方有效必填按准确参数唯一映射、供应商必填及所引用当前分类字段合并；CUSTOM只取自身要求，失效/重复/未读显示待核，上方供应商原模板仍保raw。空AI责任人不画旧责任行，历史明确人员仍原名保留。 取消/放弃后关闭动画期间立即重开场景时，仅清除已获授权标记closing的旧层再初始化，活动未保存层拒绝重复打开；延时关闭只删除捕获的旧层，有新层不解锁其背景滚动，旧异步字段返回按sequence/owner不能覆盖新草稿。取消不保存、不删除原映射或误报新表单脏状态。

- loading：首次加载显示当前模块/对象读取中，依赖此结果的动作暂不可用；刷新保留当前已应用筛选和已确认资料并标正在更新，响应只回当前准确对象/范围。

- empty：本租户无场景显示新增入口或无配置权说明；资源目录未就绪不当成场景为空。

- error：名称／资源／分类缺失或不兼容、配置变更／待核、保存失败时保表单并提示重读；不能用租户名称猜场景所有权。

- no_permission：总部和门店运营已确认可维护本租户有权业务场景；专业配置超管和管理员沿对应资格，标签映射仍独立禁权。

- submitting：提交中固定当前准确对象和输入，不接受同一动作重复发送；真正成功后更新当前值/列表，失败保草稿，未知保准确同次请求并显示核对入口。
