## 页面状态

- normal：同一黑名单页面维护原分组和号码结构，不拆公共禁呼与AI专项双Tab。客户拒联来源与其他限制来源分别保留；解除一条不使其他来源失效。天润等供应商同步不以受理等于生效。

- loading：首次加载显示当前模块/对象读取中，依赖此结果的动作暂不可用；刷新保留当前已应用筛选和已确认资料并标正在更新，响应只回当前准确对象/范围。

- empty：分组无号码与查询无结果显示准确空态及有权新增入口；未知供应商读取不当空名单。

- error：号码格式、范围／期限、重复来源、来源解除资格、同步失败与未知分别提示；保持原来源审计，不能因一次删除本地行假报远端解除。

- no_permission：超管仅在原范围只读查看，无分组、号码、同步和来源解除写权；租户运营按本租户黑名单能力维护，客户拒联解除仅本租户管理员及原因。

- submitting：提交中固定当前准确对象和输入，不接受同一动作重复发送；真正成功后更新当前值/列表，失败保草稿，未知保准确同次请求并显示核对入口。
