## 页面状态

- normal：租户管理员和运营可看本租户计费统计及明细；服务汇总CSV由超管独立财务导出资格提供，按当前统一分钟及服务快照8列，不推算独立余额。

- loading：首次加载显示当前模块/对象读取中，依赖此结果的动作暂不可用；刷新保留当前已应用筛选和已确认资料并标正在更新，响应只回当前准确对象/范围。

- empty：可靠零计量显示真实零；账户映射或字段未知显示待核并禁导出，不生成空CSV兜底。

- error：账户／范围不唯一、数字缺失、快照变动或生成失败显示原因；导出失败不触发充值／资金操作。

- no_permission：五角色按有权账户／统计范围查看；套餐办理／手调／服务汇总导出与普通统计查看分开，四租户角色无充值和手调。

- submitting：提交中固定当前准确对象和输入，不接受同一动作重复发送；真正成功后更新当前值/列表，失败保草稿，未知保准确同次请求并显示核对入口。
