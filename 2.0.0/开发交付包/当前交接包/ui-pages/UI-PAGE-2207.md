## 页面状态

- normal：管理员查看／维护本租户呼入规则不要求本人有坐席；接听来电则另核本人坐席、在线状态和作业权。公共外呼禁呼不阻正常呼入。

- loading：首次加载显示当前模块/对象读取中，依赖此结果的动作暂不可用；刷新保留当前已应用筛选和已确认资料并标正在更新，响应只回当前准确对象/范围。

- empty：无规则显示有权新增；无可用接听资源显示不可配置原因而非任取资源。

- error：条件／优先级／去向失效或不在本租户、并发变化、保存未知时保草稿并阻重复；规则读取失败不表示没有规则。

- no_permission：总部／门店管理员可本租户查询、新增、编辑；运营接听能力不授规则维护权，平台配置超管需独立资源资格。

- submitting：提交中固定当前准确对象和输入，不接受同一动作重复发送；真正成功后更新当前值/列表，失败保草稿，未知保准确同次请求并显示核对入口。

### UI-ACT-2065

触发：用户点击/提交“查询与维护原呼入服务规则”

行为：触发“查询与维护原呼入服务规则”时按当前准确对象与操作资格办理。查询/只读详情无保存；写动作校验唯一优先级、条件和有效呼入目标；创建名称选填且创建后只读；优先级唯一正整数；原目标仅1语音导航/2联系电话/3分机，校验对应真实资源；编辑比较修订，只有已停用且无待核可删除；运营实际接听仍检查本人有效坐席；公共禁呼不拒正常呼入。可观察结果：准确呼入规则配置与同步结果分别确认，失败/未知保输入及核对路径。无权/字段不合法/对象失效/修订冲突时：明确显示本次拒绝原因，保留可继续的输入和已确认原值，不作变更；提交失败或结果未知时：失败保留原确认值；未知显示待核并按同请求核对，不重复提交或假报成功
