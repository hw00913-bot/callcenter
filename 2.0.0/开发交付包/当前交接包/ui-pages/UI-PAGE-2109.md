## 页面状态

- normal：查看原线索和结果不新建／合并业务；标签使用不授标签维护。回访沿本租户准确线索／场景和原可执行条件办理，不覆盖原已知结果。

- loading：首次加载显示当前模块/对象读取中，依赖此结果的动作暂不可用；刷新保留当前已应用筛选和已确认资料并标正在更新，响应只回当前准确对象/范围。

- empty：无记录显示有权范围空态；没有可用回访上下文显示不可办原因，不猜场景／客户。

- error：标签映射、线索来源或执行状态未知时保原记录并阻新提交；回访受理不等拨打／完成。

- no_permission：按模块与原记录／回访功能资格，超管有权查看不代理租户执行；标签修改按已有允许范围，不授配置权。

- submitting：提交中固定当前准确对象和输入，不接受同一动作重复发送；真正成功后更新当前值/列表，失败保草稿，未知保准确同次请求并显示核对入口。

显示条件：不作为独立用户输入显示；用于准确同次上下文、并发/快照或权威结果控制。必要时在已授权详情/证据区以可读摘要表达，禁止普通列表暴露内部/敏感值。

编辑条件：用户不可编辑；由对应局部逻辑按准确已确认来源维护。

必填提示：系统控制字段，不显示输入必填星号。

校验时机：不进行用户输入校验；进入/提交/回读结果时按对应局部逻辑重验准确范围、身份、修订及同次状态。

错误文案：若内部依据缺失/失效，显示对应动作无法确认的具体原因，保原值并停止本次提交；不能要求用户手填控制值。

展示格式：不透明修订标记，按原对象比较；缺失显示“未取得/未填写”，合法0、false和空集合分别按真实值显示，不互换。
