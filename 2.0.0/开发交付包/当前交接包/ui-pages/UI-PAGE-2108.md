## 页面状态

- normal：通话事实沿准确供应商与账户身份显示，原始code／label和映射状态分开；有权录音播放暂停拖动按读权，不要求页面可编辑。AI拒联只能由有权人核实准确通话后确认。

- loading：首次加载显示当前模块/对象读取中，依赖此结果的动作暂不可用；刷新保留当前已应用筛选和已确认资料并标正在更新，响应只回当前准确对象/范围。

- empty：可靠查询无话单显示暂无；没有录音／转写分别显示未提供，不能以空录音猜未拨打或未接通。

- error：状态未映射、录音不可用、文本加载失败、来源业务无权时局部说明；读取失败不归零／不改通话结果。

- no_permission：五角色按有权通话范围查看号码明文及录音；拒联新增另核来源／新增权，超管不得确认新增黑名单。

- submitting：提交中固定当前准确对象和输入，不接受同一动作重复发送；真正成功后更新当前值/列表，失败保草稿，未知保准确同次请求并显示核对入口。

## 交互与反馈

### UI-ACT-2038

触发：用户点击/提交“查询原通话记录/详情”

行为：触发“查询原通话记录/详情”时按当前准确对象与操作资格办理。AI与Cloud按平台/租户/企业/任务分别筛选；详情准确callId读权，号码按原明文权展示；录音入口按读权；AI原始/映射标签与人工跟进结果分开显示。可观察结果：显示准确授权通话事实、录音可用性及标签，不改人工跟进或路由。无权/字段不合法/对象失效/修订冲突时：明确显示本次拒绝原因，保留可继续的输入和已确认原值，不作变更；提交失败或结果未知时：失败保留原确认值；未知显示待核并按同请求核对，不重复提交或假报成功

局部逻辑：LOCAL-PLAT-CALL-QUERY

测试：CHECK-PLAT-CALL-QUERY
