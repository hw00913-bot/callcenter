## 页面状态

- normal：业务分类列表提供导入名单并锁定准确分类；原导入与分配改为导入批次，以批次结果/详情为主。独立业务名单保工作队列、原单条/同组批量手动分配及明确发起；主菜单打开/刷新不带临时批次过滤，准确批次详情和recordId详情各保自身上下文，账号/租户/撤权重新核验。

- loading：台账加载与文件读取分别标状态；新文件解析期间禁检查/提交旧名单，仅当前最新请求可更新当前草稿。

- empty：没有业务显示可导入或调整筛选；没有选中项禁用批量动作；尚未提供导入资料时中性提示参与分流字段，不提前报红。

- error：基础、映射、唯一性错误均具体到行；TEMPLATE路由资料不足提示修正，不自动降级DIRECT。DIRECT分类未允许、未选方式或AI缺场景均阻确认。模式/方式/场景变化使旧预览失效，失败保草稿，未知同请求核对。

- no_permission：超管只读监管；本租户管理员按导入／分配动作授权维护，运营不显示可办理的导入／分配入口，但可对有权同组AI／预外呼业务明确起呼。

- submitting：提交中固定当前准确对象和输入，不接受同一动作重复发送；真正成功后更新当前值/列表，失败保草稿，未知保准确同次请求并显示核对入口。
