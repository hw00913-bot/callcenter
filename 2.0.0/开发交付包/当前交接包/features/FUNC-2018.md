## 本功能做什么

仍有专业用途的原目录能力保留准确专业身份，禁止新选/新关联，已有场景与受理任务按专业规则完成；不恢复已取消旧v2历史台账兼容。

来源业务域：呼叫中心；来源业务模块：未提供。

本页是同一份规划的功能阅读视图，仅整理已声明的关联，不增加业务规则，也不代表本功能已通过完整性核验。

## 局部逻辑

- [停用专业目录分类 · LOCAL\-PLAT\-AI\-CATEGORY\-STOP](../local-logic/LOCAL-PLAT-AI-CATEGORY-STOP.md)

本局部说明只声明关联当前功能，以下内容直接取自同一份规划。

### 触发与前置条件

触发：在仍保留的原专业目录入口停用准确分类

- 有该专业域当前租户分类管理权；对象身份明确

### 处理步骤

1. **LOCAL\-PLAT\-AI\-CATEGORY\-STOP\-S1**：区分当前品牌分类治理和仍有专业用途的原目录身份，不能引入旧v2迁移台账

2. **LOCAL\-PLAT\-AI\-CATEGORY\-STOP\-S2**：停止本专业分类新选择/新关联；已有准确关联场景及已受理任务按专业执行规则完成

### 分支与异常

- **LOCAL\-PLAT\-AI\-CATEGORY\-STOP\-B1**：当前提、字段及对象修订校验通过且结果明确成功，专业分类停止新选；不物理删除、不自动解除AI场景或改业务路由。

- **LOCAL\-PLAT\-AI\-CATEGORY\-STOP\-B2**：当无权/字段不合法/对象失效/修订冲突，明确显示本次拒绝原因，保留可继续的输入和已确认原值，不作变更。

- **LOCAL\-PLAT\-AI\-CATEGORY\-STOP\-B3**：当提交失败或结果未知，失败保留原确认值；未知显示待核并按同请求核对，不重复提交或假报成功。

### 完成后的状态

- 专业分类停止新选；不物理删除、不自动解除AI场景或改业务路由
