## 本功能做什么

有权修改最新模板配置，保规则身份与输入；配置待核先核同请求，业务执行待核不冻结独立配置维护，已开始run沿自身捕获方案。 修改CALL默认安排仅影响新运行，其他租户映射保留且本租户不可越权修改；已受理执行快照不追改。

来源业务域：业务&amp;客户；来源业务模块：未提供。

### 处理步骤

1. **STEP\-FLOW\-TEMPLATE\-EDIT\-1**：选择字段参考分类读最新字段，唯一开始锚点与组件确定类型

2. **STEP\-FLOW\-TEMPLATE\-EDIT\-2**：编排条件优先的入口/路径和单方式CALL，当前END固定正常结束CLOSE；当前草稿可未选目标但不形成业务边

### 分支与异常

- **BRANCH\-FLOW\-TEMPLATE\-EDIT\-1**：当单模板配置请求尚待核、条件不合法或并发已变，保当前草稿并阻非法保存；字段/来源或不兼容类型/基数变化清不适用值，兼容operator保值，不再额外待应用确认。

- **BRANCH\-FLOW\-TEMPLATE\-EDIT\-2**：当合法明确保存，更新当前定义，不自动绑定任何分类、不起呼；已开run不追改。

- **LOCAL\-FLOW\-TEMPLATE\-EDIT\-DRAFT\-FIRST**：当条件已填但目标未选，或选择/拖线构成循环，空目标仅留编辑草稿不生成虚连线；循环选择即时拒绝并保原目标；保存缺项/绕过仍拒绝并统一浅红定位。

### 完成后的状态

- 业务执行待核不无必要冻结独立模板编辑，配置待核仍核原请求

## 本功能验收

- **AC\-2109**：新模板自带唯一开始锚点，拖入转交/呼叫/结束即定类型和默认名称；首个业务节点及合法有序入口明确，不再空白节点二次选类型。

- **AC\-2110**：新run捕获完整有效plan并按实际分类记录，模板后续编辑/删除不追改已开run；导入成功定位即已开始。

- **AC\-2111**：同品牌模板/实际分类字段与业务域兼容；CALL不隐式换owner，OTHER先转交，不允许普通业务或门店直转越权。

- **AC\-2112**：条件支持独立IMPORT，AI状态/标签与人工/预外呼状态/填写；转交精确上游来源，条件配置不授自动呼叫/推进权。 按准确入口固定TASK/DIRECT或CATEGORY/TEMPLATE；DIRECT仍严守基础必填、类型、映射和唯一性，仅豁免路由附加资料，且不建run/node。

- **AC\-2113**：组ALL/ANY明确且已知时计算，标量IN/NOT\_IN每行多个值，EQ/NE/大小比较单值；多选及AI标签包含任一/全部，空值独立。 TASK DIRECT由任务带入方式与必要场景，CATEGORY按首路径及分组确定方式/场景；仅旧无TASK来源历史的合法启用流程不重复导入。

- **AC\-2114**：规则字段/选项/类型/作用域合法才可保存；未知不反向放行，逗号保文本，空白行忽略。普通交互保已有输入、比较值、滚动/展开；改变定义不静默丢值。

- **AC\-2139**：所有有出口的当前新配置须有且仅有一个末位ELSE；IF/ELSE IF按优先级首命中，明确不匹配才到兜底，未知继续PENDING。保存/新导入/重开/启用均校验，不依赖DIRECT绕开分流。

- **AC\-2142**：节点按命名→条件→下一节点→继续条件编辑，末位轻量“其他情况”；未选目标可留编辑草稿但不产生业务连线，保存仍逐项拒绝缺项并定位。

- **AC\-2143**：条件修改直接进入当前草稿，不再显示待应用三按钮；兼容operator保值，字段/来源或不兼容类型/基数变化清不适用比较值，空判断清值。目标选择/拖线拒环并保原草稿，保存仍防绕过。

- **AC\-2145**：线索域转交组件允许CURRENT本租户分支；命中后保持owner、run及tenant阶段，不新建跨租户截止/轮次，不清原安排与封存结果，并重核后继CALL资格。OTHER仍执行原意向锚定和跨租户保护；CURRENT不冒充OTHER，拒伪造目标或过期令牌。

- **AC\-2146**：普通及START比较值提示“多个值请换行填写/每行一个值”，保持IN/NOT\_IN类型含义；报错节点/START/提示区统一浅红，切换节点保留定位，编辑该节点清当前标记，保存重新判断，不改变原校验。

- **AC\-2153**：CALL配置默认等级及按实际承接tenant的默认任务/坐席/场景；仅修改本有权tenant映射且保其他tenant原值，导入可明确覆盖；方式切换重核不兼容目标，已开运行和快照不追改。

- **AC\-2155**：TEMPLATE与DIRECT人工均提供MANUAL人工分配（默认）和SPECIFIC\_SEAT指定坐席；前者可无seat先保存模板/导入待分配，后者才必选本租户有效seat。后继新人工节点MANUAL明确待分配，不继承前seat；SPECIFIC\_SEAT才可按本节点及原同tenant/method/有效资源规则沿用或确认。旧快照无策略按原解释，不迁移；原单条/批量分配可随后落实seat，实际拨打仅对应本人。

- **AC\-2156**：预外呼只必选具体任务，坐席/队列/策略沿任务；AI仍必选任务和适配scene。模板默认、导入和分配均无独立责任跟进人选择，不因缺少该值阻合法任务安排/发起，也不伪填当前actor为负责人。
