## 本功能做什么

入口位于当前预外呼任务详情客户名单，按准确taskId与当前筛选授权明细生成文件；不改成导入批次导出。

来源业务域：呼叫中心；来源业务模块：未提供。

## 局部逻辑

- [导出当前专业任务客户明细 · LOCAL\-PLAT\-EXPORT\-CUSTOMERS](../local-logic/LOCAL-PLAT-EXPORT-CUSTOMERS.md)

本局部说明只声明关联当前功能，以下内容直接取自同一份规划。

### 触发与前置条件

触发：当前预外呼任务详情的客户名单点击导出

- 该任务客户明细导出权，准确taskId上下文

### 处理步骤

1. **LOCAL\-PLAT\-EXPORT\-CUSTOMERS\-S1**：仅取当前taskId下授权且当前筛选客户明细，保持原字段

2. **LOCAL\-PLAT\-EXPORT\-CUSTOMERS\-S2**：非导入批次导出；无任务/无数据/生成失败清晰提示

3. **LOCAL\-PLAT\-EXPORT\-CUSTOMERS\-S3**：敏感号码按原导出资格，不借列表读权扩权

### 分支与异常

- **LOCAL\-PLAT\-EXPORT\-CUSTOMERS\-B1**：当前提、字段及对象修订校验通过且结果明确成功，下载当前专业任务客户明细，不导出其他任务或所有批次。

- **LOCAL\-PLAT\-EXPORT\-CUSTOMERS\-B2**：当无权/字段不合法/对象失效/修订冲突，明确显示本次拒绝原因，保留可继续的输入和已确认原值，不作变更。

- **LOCAL\-PLAT\-EXPORT\-CUSTOMERS\-B3**：当提交失败或结果未知，失败保留原确认值；未知显示待核并按同请求核对，不重复提交或假报成功。

### 完成后的状态

- 下载当前专业任务客户明细，不导出其他任务或所有批次
