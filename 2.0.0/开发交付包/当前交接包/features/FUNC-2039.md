## 本功能做什么

查询模式、批次、队列和下一步；DIRECT显示同租户待安排/起呼/结果/本人填写/待核及再次跟进，允许有权人经独立预检显式启用流程。 列表和详情展示具体目标与五档等级；待执行视图按资源内等级与入队先后，普通历史列表仍更新时间倒序，长期等待可提示。

来源业务域：业务&amp;客户；来源业务模块：未提供。

本页是同一份规划的功能阅读视图，仅整理已声明的关联，不增加业务规则，也不代表本功能已通过完整性核验。

本局部说明只声明关联当前功能，以下内容直接取自同一份规划。

### 触发与前置条件

触发：进入导入批次与业务名单／业务列表并筛选队列

- 当前身份及租户范围可核

### 处理步骤

1. **STEP\-FLOW\-QUERY\-1**：从同权威账本按当前/截止历史/管理监管资格投影，不用品牌配置权扩范围

2. **STEP\-FLOW\-QUERY\-2**：算工作状态、下一步和阻塞原因，先更新时间倒序全量过滤再分页

3. **STEP\-FLOW\-QUERY\-3**：入口按钮按行实际动作资格，普通运营可起呼但不导入/分配

4. **STEP\-FLOW\-QUERY\-4**：按准确身份展示模式与方式；DIRECT无当前run/节点显示“直接跟进”，保完整有权跟进/通话/快照及当前资料更正入口，不显示可办理模板转交或推进。；列表/详情展示mode、具体任务/坐席及等级；待执行视图以资源内等级降序、入队时间和稳定序号升序推荐，普通历史查询仍更新时间倒序；长期等待提示处理。 业务分类列表提供导入名单并锁定准确分类；原旧导入菜单改为导入批次，业务名单保独立，业务名单保独立，业务名单保独立，业务名单保独立，业务名单保独立，以批次结果/详情为主。独立业务名单保工作队列、原单条/同组批量手动分配及明确发起；主菜单打开/刷新不带临时批次过滤，准确批次详情和recordId详情各保自身上下文，账号/租户/撤权重新核验。 原专业名单直接在原列表展示：保姓名、电话、批次、原操作与原统计，新业务按准确recordId只读回链；旧原生行缺业务编码/业务分类/五档执行优先级/导入入口四项时直接留空，不单列历史名单、不按手机号补链。统一业务数/办理状态不冒充供应商受理、真实拨打、接通或话单数。 业务分类列表提供导入名单并锁定准确分类；原导入与分配改为导入批次，以批次结果/详情为主。独立业务名单保工作队列、原单条/同组批量手动分配及明确发起；主菜单打开/刷新不带临时批次过滤，准确批次详情和recordId详情各保自身上下文，账号/租户/撤权重新核验。

### 分支与异常

- **BRANCH\-FLOW\-QUERY\-1**：当确定空记录，显示空态及有权下一步，不假造条数。

- **BRANCH\-FLOW\-QUERY\-2**：当范围或读取失败，显示错误/无权而非空成功。

- **BRANCH\-FLOW\-QUERY\-3**：当当前记录可办，队列可定位待转交/待安排/待起呼/待结果/待填写/待流转/条件未满足/待核等。

### 完成后的状态

- 读取不改变业务更新时间或状态
