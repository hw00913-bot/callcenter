[返回功能目录](README.md) · [返回开发包入口](../README.md)

## 本功能做什么

明确发起同租户DIRECT或TEMPLATE当前CALL的AI/人工/预外呼，重核准确资源/场景、本人资格、串行和联系限制。人工待分配不先起呼，AI/PRED无独立责任人要求；同组AI/预外呼按五档/FIFO统一总序逐条核验及反馈，不抢占在途。直接周期完成后显式下一方式建立新周期，旧事实保持。

来源业务域：业务&amp;客户；来源业务模块：未提供。

本页是同一份规划的功能阅读视图，仅整理已声明的关联，不增加业务规则，也不代表本功能已通过完整性核验。

### 分支与异常

- **BRANCH\-FLOW\-START\-1**：当资格/资源/场景/频次失败，无新执行段，保原安排并准确原因。

- **BRANCH\-FLOW\-START\-2**：当明确受理，执行中但calls可为空，等待真实事实。

- **BRANCH\-FLOW\-START\-3**：当受理结果未知，持同请求核对，不再起第二次。

- **LOCAL\-FLOW\-START\-END\-ORIGIN**：当当前周期恰为可靠END来源的首MANUAL，record/owner/origin directCycleId与当前cycle准确一致，历史END证明与当前周期例外分开：只有同record/owner/来源directCycleId的首MANUAL当前周期可豁免旧allowDirect标志；TASK的resume新周期须当前准确任务/场景/渠道有效，旧无TASK历史按原准入，旧来源只保历史。。
