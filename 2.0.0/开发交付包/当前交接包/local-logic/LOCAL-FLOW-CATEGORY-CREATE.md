## 分支与异常

### BRANCH-FLOW-CATEGORY-CREATE-1

条件：类型/用途错配、依赖不满足或已用业务域被改

结果：保输入拒绝，不动原基础及路由

涉及字段：FIELD-FLOW-CATEGORY-ID, FIELD-FLOW-BRAND-ID, FIELD-FLOW-CATEGORY-LABEL, FIELD-FLOW-CODE-LABEL, FIELD-FLOW-BUSINESS-FAMILY, FIELD-FLOW-CATEGORY-IMPORT-REFS, FIELD-FLOW-CATEGORY-FOLLOWUP-REFS, FIELD-FLOW-CATEGORY-REVISION

验证：CHECK-FLOW-CATEGORY-CREATE

### BRANCH-FLOW-CATEGORY-CREATE-2

条件：合法基础及字段配置

结果：基础成功，尚未绑定路由可保存，提示独立路由入口

涉及字段：FIELD-FLOW-CATEGORY-ID, FIELD-FLOW-BRAND-ID, FIELD-FLOW-CATEGORY-LABEL, FIELD-FLOW-CODE-LABEL, FIELD-FLOW-BUSINESS-FAMILY, FIELD-FLOW-CATEGORY-IMPORT-REFS, FIELD-FLOW-CATEGORY-FOLLOWUP-REFS, FIELD-FLOW-CATEGORY-REVISION

验证：CHECK-FLOW-CATEGORY-CREATE

### BRANCH-FLOW-CATEGORY-CREATE-DIRECT

条件：开关缺失、false或读取未知

结果：新DIRECT导入和新增直接执行安排不可用；原受理执行及必要本人填写、归档保准确收尾。

涉及字段：FIELD-FLOW-ALLOW-DIRECT-FOLLOWUP

验证：CHECK-FLOW-CATEGORY-CREATE
