# 平台与原专业能力产品语义复核

复核对象为本轮产品规格片段 `fragments/platform.json`，结合当前原型代码、`prototype/docs/decisions.md`、`prototype/docs/role-permissions.md` 和原专业 renderer 核对。此次仅补产品规格与追溯资料，未修改运行代码；未运行原型构建、浏览器或真实服务测试，也未作用户审批或正式门禁通过声明。

## 覆盖结果

- 保留平台分工的 28 个 FUNC 稳定 ID；与业务片段合并后共 43 个 FUNC。
- 原专业 222 个 operation key 全部逐项提供承载 PAGE、明确触发、输入与状态资格、结果、错误、权限及 LOCAL/FIELD/CHECK 引用，不把原未实现控件升级成可用能力。
- 平台片段包含 119 个独立 LOCAL、119 个产品 CHECK、245 个 FIELD、41 个 PAGE 映射及 71 个原 ACTION 映射。
- 与业务片段交叉检查，未发现同 `entity + key` 重复定义；134 个原 AC 均有当前正文，43 个 FUNC、46 个原 PAGE（43 当前、3 替代来源）均保留身份。原 4 个被替代页面 ACTION 保留在来源历史中。
- 片段执行了 JSON 结构审阅：FIELD/LOCAL/CHECK ID 唯一、局部字段引用精确并集、派生依赖及验收引用存在、222 原 key 不重复。以上是规格完整性检查，不能解释为业务运行或生产接口验证。

## 发现并修正的语义问题

1. 统一五种生产角色和五个顶栏。坐席保持电话能力，独立资源范围保持功能资格；没有从同品牌、页面入口或原型演示身份推授生产权。
2. 租户基础资料维护与创建、品牌／总部门店身份、门店编码、企业资源关联、商业标记、模块开通逐项分权；有本租户 `tenant.update` 权的管理员可以维护允许的本租户基础资料。创建租户与品牌关联同次提交，明确失败不留孤立对象，未知核对原请求。AC-2095、2096 已纳入相应检查。
3. 原 `retained-source-ai-scene-type-*` 是标签场景目录操作，而非具体 AI 业务场景或业务类型 CRUD。新增独立 AI-TAXONOMY 说明和 6 个实际标签场景／标签供应商目录字段，明确运营无标签配置权限，具体场景使用及选择已有配置不要求标签维护权。
4. AI 标签按选中执行段的 supplier／tenant／type／tagScene／category／brand／revision 七元组和标签 ID 子集校验。准确映射可供人工确认路径判断；未匹配保原始值，不首项回退，不写业务字段，不因回执自动推进。
5. 黑名单沿原分组＋号码唯一入口；超管仅查看。人工拒联在成功话后保存后入库，AI 拒联必须明确人工确认；解除只限本租户管理员填写原因，只解除准确来源。天润同步按准确企业＋号码及 type/useRange，不用远端分组标识；本地与远端终态分开。
6. AI 服务账户／流水五角色按范围只读；套餐、充值、调账、同请求核对及固定 8 列服务汇总导出只限超管。补齐原套餐数量、价格精度、入账分钟、时分有效期、偏离原因及调整方向／对象／方式／单位。
7. 录音播放、暂停和定位按对象读权，不依赖编辑权。电话保护只看本人会话，有限收尾不重新启用停用账号；管理员配置呼入规则不需本人坐席。
8. 补齐真实队列、分机、号码池、AliCti 配置及预外呼／IVR任务原子字段。呼入规则真实去向仅语音导航／联系电话／分机；规则名称创建选填、保存后只读。专业任务接听团队选择与新业务“分配跟进人”分开；未实现原 AI 控制、导出等保持明确不可用。
9. 原客户任务“待继续跟进／已完成”与新四节点运行终态分开。每轮开始读取并展示最新定义／有效值，保存沿本轮已展示依据；保存不临时替换 schema 或吸入未展示新资料，不安全并发保输入并提示核对／重载。实际拨打／接听人填写，不用责任跟进人代替。
10. REPORT-DATA 已按七个 Cloud renderer、三个 AI renderer补齐真实列、粒度、单位、归期、分母、空与零及明细标识。Cloud 接通率只用确认结果作分母、0 秒是有效样本、缺失时长不填 0；累计供应商、平台名单与周期通话分开。AI 通话保原 connected/roster 与 (connected+missed)/dial 公式；AI 计费保客户接通逐通分钟向上取整，客户平均时长未实现的原列明确为“—”。源缺失不沿静态 renderer 默认值伪装成可靠零。
11. PRO-FIELD-DEF 已明确 id、label、type、businessKey、options、enabled 及接口取数成员的类型、长度、枚举、必需条件、选项唯一性、引用保护，引用现有 FIELD-FLOW 原子定义作为同源专业入口视图，不复制旧租户字段库。导入编码必填不会被原专业选填口径豁免，不提供格式配置。
12. 同 ID 的全局规则在 canonical source 与 plan 中应保持同正文；已提醒根组装统一 GR-CONTACT。运行创建即固定方案的措辞已建议统一为“尚未创建的新运行读取当前路由”，不能将未拨号解释为尚未开始运行。
