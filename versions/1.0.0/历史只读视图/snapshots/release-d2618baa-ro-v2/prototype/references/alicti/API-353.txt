获取呼入路由设置信息接口 接口说明： API URL 接口请求地址： https://api-{region}.alicti.cn/interface/{version}/ivrRouter/get 地址参数说明： {region}为alicti平台区域，{region}=1 表示华东1区，{region}=2 表示华北2区，{region}=5 表示华东5区，{region}=6 表示华北6区 {version}为接口版本，当前{version}=v10 接口请求方式：GET/POST 相关参数 参数 类型 要求 描述 备注 validateType Int 必选 验证类型 说明： validateType=1：使用部门编号(departmentId)进行验证； validateType=2：使用呼叫中心编号(enterpriseId)进行验证； departmentId String 必选 部门编号 说明：validateType=1时，此参数为必选参数，例如：departmentId=BM0000001 enterpriseId Int 必选 呼叫中心编号 说明：validateType=2时，此参数为必选参数，例如：enterpriseId=7000101 timestamp Long 必选 当前时间戳 说明：取当前linux时间戳，精确到s，时间戳有效期为30分钟 sign String 必选 验证值 说明： validateType=1时，MD5({departmentId}+{timestamp}+{部门token值})； validateType=2时，MD5({enterpriseId}+{timestamp}+{部门token值})； 格式要求：32位全小写 id Int 必选 呼入路由id 接口请求示例： https://api-{region}.alicti.cn/interface/v10/ivrRouter/get?validateType=1&departmentId=BM3000003&sign=fc0dac58690fb19fe56666378c4f9c26&timestamp=1505885556&id=230 接口返回 data定义： 字段 类型 描述 enterpriseIvrRouter EnterpriseIvrRouter 呼入路由设置 enterpriseTimeList List< EnterpriseTime > 时间条件规则对应的时间条件名称 返回示例： { "result": "0", "description": "成功", "data": { "enterpriseIvrRouter": { "id": "6079", "enterpriseId": "7122600", "name": "呼入路由1774822146723", "active": "2", "routerType": "1", "routerProperty": "9618", "description": "666", "priority": "5", "ruleTimeProperty": "", "ruleAreaProperty": "", "ruleTrunkProperty": "", "createTime": "2026-03-30 06:09:06" }, "enterpriseTimeList": null } }
