 
 更新队列 
 接口说明：本接口用于更新队列配置，支持部分更新：只需传递需要修改的字段，未传递的字段将保持原值不变。队列技能（queueSkills）若传递则全量替换原有技能，若不传递则不修改。 
 API URL 
接口请求地址： https://api-{region}.alicti.cn/interface/{version}/queue/update 
地址参数说明： 
{region}为alicti平台区域，{region}=1 表示华东1区，{region}=2 表示华北2区，{region}=5 表示华东5区，{region}=6 表示华北6区 
{version}为接口版本，当前{version}=v10 
接口请求方式：POST
