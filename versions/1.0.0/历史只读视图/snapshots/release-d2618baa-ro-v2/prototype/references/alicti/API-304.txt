座席操作

1 登录

CTILink.Agent.login(params, callback);

调用座席登录，首先要获取sessionKey，webSocketUrl，qids，enterpriseId和cno等信息，座席登录权限验证接口支持按照部门编号或呼叫中心编号获取这些登录信息。

参数params:

类型 | 
可选 | 
描述 |

String | 
必选 |

Int | 
必选 |

String | 
必选 | 
座席工号 |

String | 
可选 | 
webSocket地址 | 

qids | 
String | 
可选 | 
班长席使用，队列信息，呼叫中心编号+队列号，多个使用英文逗号","分隔 | 

bindTel | 
String | 
必选 | 
绑定电话 | 

bindType | 
Int | 
必选 | 
绑定电话类型，1：普通电话，2：分机，3：软电话 | 

loginStatus | 
Int | 
必选 | 
登录状态，1：置闲，2：置忙 | 

pauseDescription | 
String | 
可选 | 
置忙描述 |

String | 
可选 | 
座席工作模式
 0:预览与预测同时进行
 4:预览外呼模式
 5:预测外呼模式，多个使用英文逗号","分隔 |

必选 |

队列数据：

参数 | 
类型 | 
可选 | 
描述 |

QueueParam | 
可选 |

    //9001队列状态信息

    //呼叫列表数组
    var entries = detail.queueEntries;
 });
