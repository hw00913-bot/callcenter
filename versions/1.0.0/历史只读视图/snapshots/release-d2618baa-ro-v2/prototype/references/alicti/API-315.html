新增推送设置接口

接口说明

创建一条新的推送设置。目标配置支持两种方式：

  • 目标接口模式：传 targetUrlId，关联已存在的目标接口
  • 直配模式：直接传 url、method、contentType、timeout

如果两种方式同时传入，服务端优先以 targetUrlId 对应的目标接口配置为准。

  • 接口路径：/cc/create_push_action
  • 请求方式：POST
  • Content-Type：application/json
  • 鉴权方式：请参考接口鉴权

请求体参数

参数 类型 必填 说明
name String 是 推送设置名称，企业内唯一
targetUrlId Integer 否 目标接口 ID；与 url/method/contentType/timeout 二选一
url String 否 目标接口地址；未传 targetUrlId 时必填，必须以 http:// 或 https:// 开头
method Integer 否 请求方式；未传 targetUrlId 时必填，0=POST，1=GET
contentType Integer 否 内容类型；未传 targetUrlId 时必填，1=form，2=json
timeout Integer 否 超时时间；未传 targetUrlId 时必填，范围 1~10
type Integer 是 推送类型
retry Integer 否 重试次数，范围 0~3；仅在未传 retryStrategy 时生效
active Integer 否 是否启用，0=停用，1=启用；默认 1
intervalTime Integer 否 重试间隔时间，范围 0~60；仅在未传 retryStrategy 时生效
callType Integer 否 呼叫类型
pushAgent Integer 否 是否推送到座席前端，0=不推送，1=座席端推送，2=http推送+座席端推送
customScriptSwitch Integer 否 数据加工开关，0=关闭，1=开启；默认 0
customScriptId Integer 否 数据加工脚本 ID；通常在 customScriptSwitch=1 时传入
retryStrategy Object 否 重试策略对象；传入后优先于顶层 retry、intervalTime
delayedPush Object 否 延迟推送对象，字段为 delay
meetConditions Array 否 条件设置
params Array 否 推送参数
scriptInputParamList Array 否 脚本入参
pushParamList Array 否 脚本生成参数

子结构说明

retryStrategy：

参数 类型 必填 说明
retry Integer 否 重试次数
intervalTime Integer 否 重试间隔时间，单位秒

delayedPush：

参数 类型 必填 说明
delay Integer 否 延迟推送秒数，范围 0~900

meetConditions[]：

参数 类型 必填 说明
conditionRelationship Array 否 组内条件关系，例如 ["and"]
meetGroup Array 否 条件明细列表

meetGroup[]：

参数 类型 必填 说明
condition String 否 条件字段
ruleName String 否 比较规则
ruleValue String 否 比较值

params[]：

参数 类型 必填 说明
encryptionRuleId Integer 否 加密规则 ID；无加密可传 -1
paramName String 否 参数描述名称
paramVar String 否 推送变量值
pushParamName String 否 推送参数名
paramType String 否 参数类型；未传时默认使用 2

scriptInputParamList[]：

参数 类型 必填 说明
paramDesc String 否 脚本入参描述
paramName String 否 脚本入参名称
type Integer 否 脚本入参类型
paramVariable String 否 脚本入参变量值

pushParamList[]：

参数 类型 必填 说明
desc String 否 脚本生成参数描述
name String 否 脚本生成参数名称
type Integer 否 脚本生成参数类型

常见校验

  • 同一企业下 name 不能重复。
  • targetUrlId 与 url/method/contentType/timeout 至少需要提供一种方式。
  • 若传入 targetUrlId，该目标接口必须存在且属于当前企业。
