删除呼入路由设置接口 接口说明 通过本接口，第三方平台可以删除单个呼入路由设置配置 API URL 接口请求地址： https://api-{region}.alicti.cn/interface/{version}/ivrRouter/delete 地址参数说明： {region}为alicti平台区域，{region}=1 表示华东1区，{region}=2 表示华北2区，{region}=5 表示华东5区，{region}=6 表示华北6区 {version}为接口版本，当前{version}=v10 接口请求方式： GET/POST 请求参数 参数 类型 要求 描述 备注 validateType Int 必选 验证类型 说明： validateType=1：使用部门编号(departmentId)进行验证； validateType=2：使用呼叫中心编号(enterpriseId)进行验证； departmentId String 必选 部门编号 说明：validateType=1时，此参数为必选参数，例如：departmentId=BM0000001 enterpriseId Int 必选 呼叫中心编号 说明：validateType=2时，此参数为必选参数，例如：enterpriseId=7000101 timestamp Long 必选 当前时间戳 说明：取当前linux时间戳，精确到s，时间戳有效期为30分钟 sign String 必选 验证值 说明： validateType=1时，MD5({departmentId}+{timestamp}+{部门token值})； validateType=2时，MD5({enterpriseId}+{timestamp}+{部门token值})； 格式要求：32位全小写 id Int 可选 呼入路由id id和name二选一，优先选择id name String 可选 呼入路由名称 id和name二选一，优先选择id，要删除的呼入路由名称为空时不可使用name 注意 只能删除处于停用状态下的呼入路由设置 接口请求示例 https://api-{region}.alicti.cn/interface/v10/ivrRouter/delete?validateType=1&departmentId=BM3000003&sign=ea56297640e30db2ec4ee446596b5621&timestamp=1505811508&id=225 接口返回 JSON格式数据： 参数 类型 说明 result Int 0 成功, -1 失败 description String 返回结果描述 data JSON 返回数据JSON格式 description给出成功或失败时的文本描述： description 返回结果说明 验证失败，参数[{param}]不能为空 {param}为接口参数中必选字段 验证失败，参数[{param}]格式不正确 {param}为接口参数中格式有要求的字段 验证失败，参数[{param}]取值不正确 {param}为接口参数中有固定取值的字段 验证失败，参数[{param}]取值范围不正确 {param}为接口参数中有固定范围的字段 验证失败，超过频次限制 接口调用超过接口的访问频次限制 成功，{param} {param}为成功描述 失败，{param} {param}为失败描述 data定义： 无data定义 返回示例： { "result": "0", "description": "成功" }
