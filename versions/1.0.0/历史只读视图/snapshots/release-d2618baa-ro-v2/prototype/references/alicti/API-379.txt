 
 获取队列列表 
 接口说明： 
 API URL 
接口请求地址： https://api-{region}.alicti.cn/interface/{version}/queue/list 
地址参数说明： 
{region}为alicti平台区域，{region}=1 表示华东1区，{region}=2 表示华北2区，{region}=5 表示华东5区，{region}=6 表示华北6区 
{version}为接口版本，当前{version}=v10 
接口请求方式：GET/POST 
 相关参数 
 字段 
 类型 
 要求 
 描述 
 备注 
 validateType 
 Int 
 必选 
 验证类型 
 说明： validateType=1：使用部门编号(departmentId)进行验证； validateType=2：使用呼叫中心编号(enterpriseId)进行验证； 
 departmentId 
 String 
 必选 
 部门编号 
 说明：validateType=1时，此参数为必选参数，例如：departmentId=BM0000001 
 enterpriseId 
 Int 
 必选 
 呼叫中心编号 
 说明：validateType=2时，此参数为必选参数，例如：enterpriseId=7000101 
 timestamp 
 Long 
 必选 
 当前时间戳 
 说明：取当前linux时间戳，精确到s，时间戳有效期为30分钟 
 sign 
 String 
 必选 
 验证值 
 说明： validateType=1时，MD5({departmentId}+{timestamp}+{部门token值})； validateType=2时，MD5({enterpriseId}+{timestamp}+{部门token值})； 格式要求：32位全小写 
 limit 
 Int 
 可选 
 条数 
 正整数，大于0，最大不能超过500， 默认为500 
 offset 
 Int 
 可选 
 第几条开始 
 正整数 大于等于0 默认为0 
 qno 
 String 
 可选 
 队列号 
 description 
 String 
 可选 
 描述 
 order 
 Int 
 可选 
 排序方式,按照创建时间排序 
 0正序 1倒序 
 startTime 
 String 
 可选 
 创建时间起始时间点 
 取值说明："2019-10-11 00:00:00" 
 endTime 
 String 
 可选 
 创建时间终止时间点 
 取值说明："2019-10-11 23:59:59" 
 接口请求示例： 
 https://api-{region}.alicti.cn/interface/v10/queue/list?validateType=2&departmentId=BM3000000&timestamp=1484649817
&enterpriseId=7000001&sign=7052c0c538344f2e018ebf2baec3d090&limit=20&offset=0
