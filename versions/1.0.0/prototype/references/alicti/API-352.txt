{version}为接口版本，当前{version}=v10 接口请求方式：GET/POST 相关参数 参数 类型 要求 描述 备注 validateType Int 必选 验证类型 说明： validateType=1：使用部门编号(departmentId)进行验证； validateType=2：使用呼叫中心编号(enterpriseId)进行验证； departmentId String 必选 部门编号 说明：validateType=1时，此参数为必选参数，例如：departmentId=BM0000001 enterpriseId Int 必选 呼叫中心编号 说明：validateType=2时，此参数为必选参数，例如：enterpriseId=7000101 timestamp Long 必选 当前时间戳 说明：取当前linux时间戳，精确到s，时间戳有效期为30分钟 sign String 必选 验证值 说明： validateType=1时，MD5({departmentId}+{timestamp}+{部门token值})； validateType=2时，MD5({enterpriseId}+{timestamp}+{部门token值})； 格式要求：32位全小写 接口请求示例：
