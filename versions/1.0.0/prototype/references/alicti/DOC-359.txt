EnterpriseTime数据类型定义： 字段 类型 描述 id Int 时间条件id enterpriseId Int 呼叫中心编号 name String 时间条件名称 、同一呼叫中心下不能重复 type Int 时间条件类型 1:按照星期配置 2:按照固定时间配置 fromDay String 起始日期 格式为：yyyy-MM-dd、type=1时为空串 fromDay不能大于toDay toDay String 终止日期 格式为：yyyy-MM-dd、type=1时为空串 fromDay不能大于toDay dayOfWeek String 星期 周一：2、周二：3、周三：4、周四：5、周五：6、周六：7、周日：1、使用","进行分割、type=2时为空串 startTime String 开始时间 格式为 HH:mm startTime不能大于endTime endTime String 结束时间 格式为 HH:mm startTime不能大于endTime priority Int 优先级、同一呼叫中心下不能重复，值从1开始，值越小优先级越高 createTime Date 创建时间，格式为： yyyy-MM-dd HH:mm:ss
