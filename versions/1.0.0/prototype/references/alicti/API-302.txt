座席前端登录鉴权

接口说明

agent工具条登陆权限验证，获取sessionKey

API URL

接口请求地址：

https://api-{region}.alicti.cn/interface/{version}/agentLogin/authenticateJsonp

地址参数说明：

{region}为alicti平台区域，{region}=1 表示华东1区，{region}=2 表示华北2区，{region}=5 表示华东5区，{region}=6 表示华北6区

{version}为接口版本，当前{version}=v10

接口请求方式：

GET/POST

请求参数

参数 | 
类型 | 
要求 | 
描述 | 
备注 | 

validateType | 
Int | 
必选 | 
验证类型 | 
取值1，2； 取值说明：
validateType=1时使用部门编号(departmentId)进行验证；
validateType=2时使用呼叫中心编号(enterpriseId)进行验证； | 

departmentId | 
String | 
必选 | 
部门编号 | 
说明：validateType=1时，此参数为必选参数，例如：departmentId=BM0000001； | 

crmId | 
String | 
必选 | 
员工编号 | 
说明：validateType=1时，此参数为必选参数，例如：crmId=crm1001； | 

enterpriseId | 
Int | 
必选 | 
呼叫中心编号 | 
说明：validateType=2时，此参数为必选参数，例如：enterpriseId=7000101； | 

cno | 
Int | 
必选 | 
座席工号 | 
说明：validateType=2时，此参数为必选参数，3-10位数字 | 

timestamp | 
Int | 
必选 | 
当前时间戳 | 
说明：取当前linux时间戳，精确到s，时间戳有效期为30分钟 | 

sign | 
String | 
必选 | 
验证值 | 
说明： 
validateType=1时，sign=MD5({departmentId}+{timestamp}+{部门token值})； 
validateType=2时，sign=MD5({enterpriseId}+{timestamp}+{部门token值})； 
格式要求：32位全小写 | 

pwd | 
String | 
可选 | 
员工密码 | 
如果pwd值不为空，则使用密码验证,pwd=MD5(pwd)
sign值未生效 | 

接口请求示例

https://api-{region}.alicti.cn/interface/v10/agentLogin/authenticateJsonp?validateType=1&departmentId=BM3000000&crmId=10098&pwd=afdd0b4ad2ec172c586e2150770fbf9e
&timestamp=1481199531&sign=f23d54af193b71e5cb3bbc1a5e777136
