字段：

- 坐席总数/上线/空闲/忙碌/话后/未上线
- 当前供应商账号线路/账号/坐席/任务异常/数据异常
- 居中坐席详情第一段：所属租户/坐席身份、当前服务状态和接收新任务资格
- 居中坐席详情第二段：可核实的当前进行中通话；未取得明细时提示待更新
- 居中坐席详情第三段：近期历史每页 5 条、原 callId、接通/时长与详情入口

操作：

- **ACTION-10201 · 查看分区指标**：来源功能 FUNC-255、FUNC-256；来源场景 SC-105；权限 按当前供应商账号/租户及角色查看与下钻，不因工作台可见扩大操作权限
- **ACTION-10202 · 下钻任务、坐席或资源**：来源功能 FUNC-255、FUNC-256、FUNC-110、FUNC-230、FUNC-217、FUNC-270、FUNC-265、FUNC-214；来源场景 SC-105、SC-104、SC-005；权限 按当前供应商账号/租户及角色复核坐席和原通话归属；普通运营坐席详情只读且无停用入口，仅有权租户管理员/超管可进入原停用确认

原型验收点：

- 云域分为两个工作台菜单；运营工作台中任务和坐席分区、类型和进度明确；坐席工作台客户联系在左、通话成效在右，原人工外呼旧地址仅兼容跳转。
- 两个工作台不新增角色或扩大权限；无有效关联不给拨号资格，已关联但停用/开通中提示原因。运营工作台只读概览，运营在任务模块保留既有任务权限；资源与客户分配限管理员。
- 从运营工作台打开居中坐席详情，当前状态、当前通话和近期历史通话分开；历史可分页并进入原通话详情。当前明细未取得时明确提示，不以历史通话冒充当前通话。
- 普通运营在坐席详情只读；有权管理员复用原坐席停用确认，取消不改变状态；停用停止接收新任务但允许当前通话完成，不新增监听、强插或强挂。
- 继承账号或手机号登录；多租户在登录时选择，换租户退出重登；双能力租户选择业务域；普通用户不切供应商账号
- 停用租户、未授权业务域和越供应商账号访问须拒绝；演示切换不作为正式认证
- 关联系统仅保留无数据、无配置和无关联动作的空态入口；旧接入与授权地址不恢复实际业务能力。
- 同一 callId 在通话记录、客户档案、批次结果、坐席工作台与云域报表保持一致；区分人工、预外呼、IVR、呼入及本地模拟来源。详情按独立可用状态展示录音工具条与分角色通话文本。
- 待确认不算未接通、不进入已确认接通率分母；校准历史通话不覆盖另一通话和当前跟进状态；不生成外部结果投递，不改变 AI 原有报表口径。统计细则复用 US-020，不另建一套口径。
- 有可用音频时支持播放、暂停、进度定位、倍速、音量和下载；有文本时支持搜索，可用时间戳片段可定位音频。音频/文本独立缺失时分别反馈。
- 仅指定通话展示明确标注的合成语音和对应文本样例；现场模拟或历史缺失通话不自动配媒体，不把样例时长当原通话时长；纯 IVR 不提供虚构人工录音。
- 关闭、换页、退出或授权失效停止播放并释放资源；缺失、过期、加载失败明确反馈并保护下载权限。本地交互通过不等于真实录音或转写对接通过。
- 由管理员独立控制电话能力生命周期，在不打断进行中通话的前提下完成状态变更并永久保留历史。
- 权限或资源条件不满足时明确拦截，不跨租户执行，不伪造成功；具体异常在本场景S3/S4核对。
