查询任务呼叫记录列表接口
接口说明
通过本接口，可以查询外呼任务的呼叫记录列表，包括客户接听状态、机器人接待情况、转人工情况等详细信息。
API URL
接口请求地址：
https://api-{region}.alicti.cn/cc/list_cdr_auto_task
地址参数说明：
{region}为alicti平台区域，{region}=1 表示华东1区，{region}=2 表示华北2区，{region}=5 表示华东5区，{region}=6 表示华北6区
接口请求方式：
GET
