更新呼入路由设置接口

  • 接口说明：

  • API URL
    接口请求地址： https://api-{region}.alicti.cn/interface/{version}/ivrRouter/update

    地址参数说明：
    {region}为alicti平台区域，{region}=1 表示华东1区，{region}=2 表示华北2区，{region}=5 表示华东5区，{region}=6 表示华北6区
    {version}为接口版本，当前{version}=v10

    接口请求方式：GET/POST

  • 相关参数

参数 类型 要求 描述 备注
validateType Int 必选 验证类型 说明：
validateType=1：使用部门编号(departmentId)进行验证；
validateType=2：使用呼叫中心编号(enterpriseId)进行验证；
departmentId String 必选 部门编号 说明：validateType=1时，此参数为必选参数，例如：departmentId=BM0000001
enterpriseId Int 必选 呼叫中心编号 说明：validateType=2时，此参数为必选参数，例如：enterpriseId=7000101
timestamp Long 必选 当前时间戳 说明：取当前linux时间戳，精确到s，时间戳有效期为30分钟
sign String 必选 验证值 说明：
validateType=1时，MD5({departmentId}+{timestamp}+{部门token值})；
validateType=2时，MD5({enterpriseId}+{timestamp}+{部门token值})；
格式要求：32位全小写
id Int 可选 呼入路由id id和name二选一，优先选择id
name String 可选 呼入路由名称 id和name二选一，优先选择id，要修改的呼入路由名称为空时不可使用name
routerType Int 可选 路由目的 1：转接语音导航、2：转电话号码、3转分机
ivrId Int 可选 语音导航id 更新ivr时，routerType必选，并且routerType值为1，可通过获取IVR列表接口获取语音导航id
tel String 可选 电话号码 更新tel时，routerType必选，并且routerType值为2
exten String 可选 分机号 更新exten时，routerType必选，并且routerType值为3 可通过获取分机列表获取分机号
description String 可选 路由说明
active Int 可选 是否启用 1：启用、2：停用 默认为2
priority 　Int 可选 路由优先级 优先级，值越小优先级越高，同一呼叫中心下不能重复
ruleAreaProperty 　String 可选 来电地区规则 来电地区规则，传来电号码，号码前缀或地区区号，多个用分号;分隔 例如： 010;0218700
ruleTimeProperty 　String 可选 时间条件规则 时间条件规则，传时间条件id，多个用分号;分隔 例如： 1;2;3 时间条件id可从获取时间条件设置列表接口获取
ruleTrunkProperty String 可选 　中继号码规则　 中继号码规则，传中继号码（不含区号），多个用分号;分隔 例如： 87120766 中继号码可从获取中继号码列表中获取

注意

可以通过更新active字段来改变语音导航是否使用

接口请求示例：

https://api-{region}.alicti.cn/interface/v10/ivrRouter/update?validateType=1&departmentId=BM3000003&sign=fc0dac58690fb19fe56666378c4f9c26&timestamp=1505885556&routerType=1&ivrId=10328&description=test&active=1&priority=16&ruleTimeProperty=118&id=230

字段 类型 描述

enterpriseTimeList List<EnterpriseTime> 时间条件规则对应的时间条件名称
