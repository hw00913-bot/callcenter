查询客户来电记录列表接口
接口说明
针对呼叫中心客户来电记录的数据列表。通过客户来电记录API，企业能够深入分析和洞察客户需求，使管理者迅速把握服务要点，对服务质量进行精准评估与持续改进。这一工具不仅助力企业高效追踪与管理客户来电，优化业务流程，提升工作效率，更有助于企业敏锐捕捉客户需求、市场趋势及潜在问题，进而做出迅速而精准的决策调整。
API URL
接口请求地址：
https://api-{region}.alicti.cn/cc/list_cdr_ib
地址参数说明：
{region}为alicti平台区域，{region}=1 表示华东1区，{region}=2 表示华北2区，{region}=5 表示华东5区，{region}=6 表示华北6区
