座席批量新增
接口说明
批量新增一个座席,单次批量创建不能超过100个
API URL
接口请求地址：
https://api-{region}.alicti.cn/interface/{version}/agent/batchCreate
地址参数说明：
{region}为alicti平台区域，{region}=1 表示华东1区，{region}=2 表示华北2区，{region}=5 表示华东5区，{region}=6 表示华北6区
{version}为接口版本，当前{version}=v10
接口请求方式：
GET/POST
相关参数
参数
类型
要求
描述
备注
validateType
Int
必选
验证类型
说明：
validateType=1：使用部门编号(departmentId)进行验证；
validateType=2：使用呼叫中心编号(enterpriseId)进行验证；
departmentId
String
必选
部门编号
说明：validateType=1时，此参数为必选参数，例如：departmentId=BM0000001
enterpriseId
Int
必选
呼叫中心编号
说明：validateType=2时，此参数为必选参数，例如：enterpriseId=7000101
timestamp
Long
必选
当前时间戳
说明：取当前linux时间戳，精确到s，时间戳有效期为30分钟
sign
String
必选
验证值
说明：
validateType=1时，MD5({departmentId}+{timestamp}+{部门token值})；
validateType=2时，MD5({enterpriseId}+{timestamp}+{部门token值})；
格式要求：32位全小写
cno
String
必选
开始座席工号
正整数，取值3-10位数字
endCno
String
必选
结束座席工号
正整数，取值3-10位数字，单次批量创建不能超过100个
name
String
必选
座席姓名
需进行UTF-8格式的URLEncode编码
areaCode
String
必选
座席所属区号
区号格式
active
Int
可选
是否激活
取值0或1，取值说明 0：不激活，1激活，默认激活
power
Int
可选
座席权限
取值1或0，取值说明 1：班长席，0：普通座席，默认为0 普通座席
callPower
Int
可选
呼叫权限
取值说明 0：无限制，1：国内长途，2：国内本市，3：内部呼叫，默认无限制

单位秒数，默认10秒

JSON
可选
外显属性
取值：{"isMatchCapital":0,"areaCodeRule":1}；obClidType=4时，isMatchCapital表示是否匹配省会号码，1是 0否，areaCodeRule表示区号匹配规则，1座席区号 2客户号码区号
ibRecord
Int

skillIds
String

所选的技能id
可选择多个，多个之间使用英文标点逗号间隔.例如:"1,2,3"；传入skillIds时，需要同时传入skillLevels
skillLevels
String
可选
所选的技能的等级
值越小技能越高，多个间用英文标点逗号间隔。(与技能id相对应) 例如:"5,1,1"表示技能id为1的等级是5; 技能id为2的等级是1; 技能id为3的等级是1.

isQualityCheck

webrtcUrlType
Int
可选
webrtc软电话返回地址
