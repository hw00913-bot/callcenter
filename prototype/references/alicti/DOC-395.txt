班长席监控

1 三方

CTILink.Monitor.threeway(params, callback);

参数params:

参数
类型
可选
描述

threewayedCno
String
必选
被三方的座席工号

返回给callback方法的参数：

参数
类型
可选
描述

type
String
必选
type=response

reqType
String
必选
reqType=threeway

code
Int
必选
0：成功，-1：失败

msg
String
必选
msg=ok

 示例：
 var params = {};
 params.threewayedCno = '2000';

 CTILink.Agent.threeway(params);
