座席详细信息列表获取

接口说明

查询座席列表

API URL

接口请求地址：

https://api-{region}.alicti.cn/interface/{version}/agent/query

地址参数说明：

{region}为alicti平台区域，{region}=1 表示华东1区，{region}=2 表示华北2区，{region}=5 表示华东5区，{region}=6 表示华北6区

{version}为接口版本，当前{version}=v10

接口请求方式：

GET/POST

相关参数

参数 | 
类型 | 
要求 | 
描述 | 
备注 | 

validateType | 
Int | 
必选 | 
验证类型 | 
说明：
validateType=1：使用部门编号(departmentId)进行验证；
validateType=2：使用呼叫中心编号(enterpriseId)进行验证； | 

departmentId | 
String | 
必选 | 
部门编号 | 
说明：validateType=1时，此参数为必选参数，例如：departmentId=BM0000001 | 

enterpriseId | 
Int | 
必选 | 
呼叫中心编号 | 
说明：validateType=2时，此参数为必选参数，例如：enterpriseId=7000101 | 

timestamp | 
Long | 
必选 | 
当前时间戳 | 
说明：取当前linux时间戳，精确到s，时间戳有效期为30分钟 | 

sign | 
String | 
必选 | 
验证值 | 
说明：
validateType=1时，MD5({departmentId}+{timestamp}+{部门token值})；
validateType=2时，MD5({enterpriseId}+{timestamp}+{部门token值})；
格式要求：32位全小写 | 

qno | 
String | 
可选 | 
队列号 | 
当qno不为空时，查询指定队列的所有座席记录 | 

cnos | 
String | 
可选 | 
座席号 | 
多个座席号以英文逗号分隔 最多支持500个座席 | 

start | 
Int | 
可选 | 
从第几条开始 | 
正整数，大于等于0，默认0 | 

limit | 
Int | 
可选 | 
查询条数 | 
正整数，大于0，最大不能超过1000，默认10 | 

active | 
Int | 
可选 | 
是否启用 | 
正整数，只能是0或者1，0是停用，1是启用 | 

status | 
Int | 
可选 | 
是否在线 | 
正整数，只能是0或者1，0是离线，1是在线 | 

order | 
Int | 
可选 | 
排序方式,按照创建时间排序 | 
0正序 1倒序 | 

webrtcUrlType | 
Int | 
可选 | 
webrtc软电话返回地址 | 
取值说明：0：企业默认 1：公网域名 2：专线域名 3：公网IP 4：专线IP | 

startTime | 
String | 
可选 | 
创建时间起始时间点 | 
取值说明："2019-10-11 00:00:00" | 

endTime | 
String | 
可选 | 
创建时间终止时间点 | 
取值说明："2019-10-11 23:59:59" | 

returnQueue | 
Int | 
可选 | 
是否返回绑定座席的队列信息 | 
0:不返回  1:需要返回  默认值:1 | 

name | 
String | 
可选 | 
通过座席名称检索 | 
取值说明：前后缀模糊匹配 | 

comment | 
String | 
可选 | 
通过座席备注信息检索 | 
取值说明：前缀模糊匹配 | 

接口请求示例

https://api-{region}.alicti.cn/interface/v10/agent/query?validateType=1&departmentId=BM3000003&timestamp=1491371625&sign=8c7b7d94c0f1cde09333bb0583e2f3d5
&limit=3&order=0&webrtcUrlType=0
