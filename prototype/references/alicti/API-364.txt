座席队列工作统计报表接口
接口说明
获取座席队列工作统计报表数据
API URL
接口请求地址：
https://api-{region}.alicti.cn/interface/{version}/agentQueueReport/agentQueueWorkload
地址参数说明：
{region}为alicti平台区域，{region}=1 表示华东1区，{region}=2 表示华北2区，{region}=5 表示华东5区，{region}=6 表示华北6区
{version}为接口版本，当前{version}=v10
接口请求方式：
GET/POST
请求参数
参数
类型
要求
描述
备注
validateType
Int
必选
验证类型
说明：
validateType=1：使用部门编号(departmentId)进行验证；
validateType=2：使用呼叫中心编号(enterpriseId)进行验证；
departmentId
String
必选
部门编号
说明：validateType=1时，此参数为必选参数，例如：departmentId=BM0000001
enterpriseId
Int
必选
呼叫中心编号
说明：validateType=2时，此参数为必选参数，例如：enterpriseId=7000101
timestamp
Long
必选
当前时间戳
说明：取当前linux时间戳，精确到s，时间戳有效期为30分钟
sign
String
必选
验证值
说明：
validateType=1时，MD5({departmentId}+{timestamp}+{部门token值})；
validateType=2时，MD5({enterpriseId}+{timestamp}+{部门token值})；
格式要求：32位全小写
statisticMethod
Int
必选
统计方法
说明：
0：分时
1：分日
2：汇总
timeRangeType
Int
必选
报表类型
说明：统计报表类型，
1：日报表
2：周报表
3：月报表
4：自定义时间
startTime
String
必选
开始时间
说明：统计日期的开始时间，格式：yyyy-MM-dd
endTime
String
必选
结束时间
说明：统计日期的结束时间，格式：yyyy-MM-dd
cnos
String
可选
座席号
说明：根据座席工号查询指定座席的工作量统计
支持按照多个座席工号进行查询，多个座席工号之间使用英文逗号","分隔，默认查询账户下所有座席的工作量统计
start
Int
可选
查询起始位置
取值：大于等于0，默认0
limit
Int
可选
查询条数
取值：最大不能超过1000，默认10
接口请求示例
   http://api-{region}.alicti.cn/interface/v10/agentQueueReport/agentQueueWorkload?validateType=2&enterpriseId=6000001&timestamp=1640251107&sign=77e8630797e2d6457733372b5fa707b9&cnos=00001,10001&timeRangeType=3&startTime=2021-11-17&endTime=2021-11-17&statisticMethod=1&start=0&limit=3
