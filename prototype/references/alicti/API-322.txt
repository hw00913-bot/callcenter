导入ivr信息接口

接口说明

通过本接口，第三方平台可以导入ivr信息

API URL

接口请求地址：

https://api-{region}.alicti.cn/interface/{version}/ivrProfile/import

地址参数说明：

{region}为alicti平台区域，{region}=1 表示华东1区，{region}=2 表示华北2区，{region}=5 表示华东5区，{region}=6 表示华北6区

{version}为接口版本，当前{version}=v10

接口请求方式：

POST

请求参数

参数 | 
类型 | 
要求 | 
描述 | 
备注 | 

validateType | 
Int | 
必选 | 
验证类型 | 
说明：
validateType=1：使用部门编号(departmentId)进行验证；
validateType=2：使用呼叫中心编号(enterpriseId)进行验证； | 

departmentId | 
String | 
必选 | 
部门编号 | 
说明：validateType=1时，此参数为必选参数，例如：departmentId=BM0000001 | 

enterpriseId | 
Int | 
必选 | 
呼叫中心编号 | 
说明：validateType=2时，此参数为必选参数，例如：enterpriseId=7000101 | 

timestamp | 
Long | 
必选 | 
当前时间戳 | 
说明：取当前linux时间戳，精确到s，时间戳有效期为30分钟 | 

sign | 
String | 
必选 | 
验证值 | 
说明：
validateType=1时，MD5({departmentId}+{timestamp}+{部门token值})；
validateType=2时，MD5({enterpriseId}+{timestamp}+{部门token值})；
格式要求：32位全小写 | 

file | 
file | 
必选 | 
语音导航信息文件 | 
上传文件最大为10M,可通过导出ivr信息接口获取，文件名称格式为： 语音导航名+时间戳（yyyyMMddHHmmss）.txt 例如： 默认语音导航20171011172523.txt | 

接口请求示例

请求方式为POST
https://api-{region}.alicti.cn/interface/v10/ivrProfile/export?validateType=1&departmentId=BM3000003&sign=a2673250407c70f3d8bc9e6694d44cdf&timestamp=1507703514&ivrId=1

RequestBody：

file=默认语音导航20171011172523.txt

接口返回

JSON格式数据：

参数 | 
类型 | 
说明 | 

result | 
Int | 
0 成功, -1 失败 | 

data | 
Json | 
导入成功, 返回对应的IVR ID和name信息 | 

description | 
String | 
返回结果描述 | 

description给出成功或失败时的文本描述：

description | 
返回结果说明 | 

验证失败，参数[{param}]不能为空 | 
{param}为接口参数中必选字段 | 

验证失败，参数[{param}]格式不正确 | 
{param}为接口参数中格式有要求的字段 | 

验证失败，参数[{param}]取值不正确 | 
{param}为接口参数中有固定取值的字段 | 

验证失败，参数[{param}]取值范围不正确 | 
{param}为接口参数中有固定范围的字段 | 

验证失败，超过频次限制 | 
接口调用超过接口的访问频次限制 | 

成功，{param} | 
{param}为成功描述 | 

失败，{param} | 
{param}为失败描述 | 

返回示例：

{
"result": "0",
"data": "{\"ivrId\":\"12597\",\"name\":\"test 导入返回ID\"}",
"description": "导入成功"
}
