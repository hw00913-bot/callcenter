BUSINESS OWNER

DCC

决定新业务导入／重导、各行本次 priority 及真实计次，传入请求级 requestId 和可选逐行 isNewBatch。

同一租户、原供应商任务和线索固定手机号；true 开独立主批，false／缺省按同组主批的稳定创建顺序关联最近已保存主批，无主时建立首主。DCC 决定恢复条件与精准删除，接收每次接口结果并汇总真实计次。

PLATFORM

云呼叫中心

先鉴权并将缺省 isNewBatch 归一为 false，按完整请求做 requestId 幂等；仅新 ID 逐有效行保存新记录／批次及稳定 root 映射。

按 fileId／实际批次／通话或稳定事件精确关联并交付结果；手工独立拆批仅平台查看。采用本次 priority，原时间仅审计，无每日查询衰减或旧值强制继承。

SUPPLIER

AliCti

负责供应商任务、号码导入、实际呼叫调度、主叫选择与供应商结果。

真实调度和事件能力待核。供应商导航可能自动降级，不承诺本期平台绝对换主叫。

DCC → 平台后台按应用凭证与 tenantId 交换合成业务身份；新业务请求带本次 priority 和可选 isNewBatch，同归一内容重传返回原逐行映射。应用仅鉴权及来源追踪
平台 → AliCti新有效行按同组固定 phone 保存主／子批映射后导入；异内容重传拒绝整次重复，不重拆或重提交。技术重传不重新选择后来新主。任务归租户，不绑定应用
AliCti → 平台按精确 fileId／实际 batch／call 或稳定事件接收导入失败分片与每次结果；保留已保存 root，未知／冲突待核，重复及 SIP 晚更新不新增呼叫。未知或冲突待核
平台 → DCC接口任务逐行回执及每次结果保留 request／行／组／batch／root 定位；固定后台端合成交付，补送仅修复交付，不重导或重删。后台固定接收地址边界

应用管理权与租户业务身份分开

仅超管可以进入应用列表、新增、详情、修改和删除；租户管理员的菜单、直达与直接管理模型调用均拒绝。

同一租户可授权多个应用。租户业务身份不授予管理权，来源应用不构成任务归属或操作限制；普通运营既有导入和失败下载权限继续保留。

仅使用合成数据

供应商鉴权与 DCC 指定租户身份独立，不混用凭证。此原型不提供可用密钥或 token，不把未核端点编造成真实请求。

供应商行为、精确事件字段、真实回调及下载成功信号的证据限制保留。业务已确认不等于真实 API 已 verified。
