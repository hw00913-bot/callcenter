查询预测外呼通话记录列表接口

接口说明

通过本接口，可以查询预测外呼通话记录列表，包括客户接听状态、座席接听情况、任务信息、IVR 信息、通话结果等详细信息。

API URL

接口请求地址：

https://api-{region}.alicti.cn/cc/list_cdr_predictive_call

地址参数说明：

{region}为alicti平台区域，{region}=1 表示华东1区，{region}=2 表示华北2区，{region}=5 表示华东5区，{region}=6 表示华北6区

接口请求方式：

GET
