# AliCti 云联络中心原型与说明文档

本原型只展示 AliCti 云联络中心的客户、坐席、预外呼、自动外呼、人工外呼、呼入和运营管理功能。原始需求资料与历史变更记录单独留存，不作为当前菜单和开发范围。

生成代码时以[开发阅读指引](docs/development.html)和现行功能说明为准。`memory/`、`inputs/` 及旧回归证据只用于追溯；其中过时页面和功能不能重新实现。当前功能、页面清单在 `documentation/input/functions.json`、`documentation/input/pages.json`。供应商接口中的“AI转人工”仅是预测任务的通话流转选项，不代表独立产品模块。

当前文档版本 `2026-09-29-multiple-caller-navigation-1`。D-086 明确同一 AliCti 账号可登记多个外显导航，创建任务时选择一个且可配合多个号码池；D-083 的单一默认导航假设仅作历史，预测任务座席阈值规则继续适用。D-085 业务分类直接关联独立字段库，D-084 班长事件预览与全部事件分页继续适用。

## 当前使用路径

- AliCti 账号：超级管理员登记供应商提供的 enterpriseId，并关联总部或门店；每个账号只关联0或1个业务租户，内置超级租户不计入。账号 ID 与品牌保存后固定，不设服务区域。本地登记不代表供应商开户或接入成功。
- 号码：系统管理 → 号码管理，从当前 AliCti 账号查询并导入已有号码，确认方向并默认归属该账号唯一有效业务租户，无租户时不能导入。号码不关联技能或坐席，不再维护独立线路。供应商状态、本地使用开关、用途与租户授权分别校验；停用不影响已发起的通话，400 号码仅用于呼入。
- 分机：系统管理 → 分机管理，独立创建、导入、维护软电话资源，归属账号唯一业务租户。坐席维护只从本账号、本租户、已启用且未占用的软电话目录选择，不可随意填写。保留分机字符串与前导零；登录前复查目录、绑定和占用。资源 `type=2` 与工具条 `bindType=3` 分别解释；密码不持久保存。
- 坐席：新增填写姓名、工号和区号，不再填写联系手机号；技能可暂不分配，随后在坐席详情配置。有效的管理员坐席和运营坐席均可承接授权客户。业务启用状态与官方话务状态分开，页面不显示冗余技能数量或同步状态。
- 技能和队列：坐席与技能下分别维护技能、队列和外呼组，不设服务类型字典或技能服务类型字段。租户管理员可维护本租户队列，一个队列可多选本租户技能；每个技能最多关联一个队列是本地约束。队列详情只读，配置和技能关联分开，坐席成员在技能内维护。
- 技能变更：等级为 1～10。在线仅追加新技能时保存待提交；修改既有等级、移除或正式全量提交仍需下线，管理员手动提交，不由下线动作自动提交。
- 队列配置：维护等待接听、语音播报与高级设置；固定播报启用须填周期和文件，位置播报启用须填至少 2 人阈值。新增提交完整必填配置，编辑仅发送变化字段；本期不开放 maxPauseAgent 和下一位提示配置。
- 外呼组与预测分配：预外呼选择“指定坐席”或“外呼组”，分别映射 `callGroupType=1/cnos` 和 `callGroupType=2/agentGroup`；不通过技能团队推导指定坐席。外呼组与技能、接听队列各自独立，一席一外呼组；转组及任务启动复查资源占用。任务运行互斥是本地产品约束，不是供应商调度承诺。
- 电话工具条：本人有有效坐席时显示顶部电话栏，集中登录、退出、置忙、置闲、拨号、接听、静音、挂断和延长整理。每次普通登录在同一面板当次选择工作模式（预览与预测同时/预览外呼/预测外呼），状态默认置闲、可改为置忙，然后直接提交；登录后可在工具条切换模式，置忙时可切换，振铃、通话及话后整理中不可切换。普通退出固定完全下线并保留接听分机绑定，不提供解绑选项，也不清空本地分机配置；通话中或业务记录未保存时阻止退出，失败和未知结果不提前显示离线。不提供拒接、管理上线或设备类型切换。本人登录不选技能或外显号码；人工外呼由平台自动选择本租户可用外显号码，无可用资源时阻止拨号。
- 客户记录：点击联系客户先在页面中央确认呼叫，拨号和振铃期间仍显示中央呼叫弹窗；坐席接通后同一通话自动切换为中央填写弹窗，未接通而结束则进入话后结果确认。通话中可填写，切换菜单或手动收起保留本标签草稿，可从电话工具条重开。通话结束后确认保存，业务成功且无未完成通话时自动请求置闲；确认成功才继续接待。置闲失败保留已保存记录，未知先核对，不重复提交业务。
- 班长监控：本租户管理员即使未关联本人坐席或未上线，也可查看本租户今日已结束外呼统计、授权坐席当前状态和已有事件记录；日志页签倒序预览最近5条，全部事件在分页二级页只读查看。队列实况与置忙、置闲、下线管理仍须关联有效班长坐席、本人上线、供应商班长资格及本租户授权队列确认。
- 时间条件：系统管理 → 时间条件，维护星期或日期、连续或间隔、时间范围及优先级。优先级必填正整数，同一 AliCti 账号内唯一；新增为空，手工填写，编辑回填原值，不自动分配。租户管理员维护本租户条件，超管维护授权账号范围，不配置同账号多租户共享。任务多选可呼叫与禁呼条件，支持预约开始和结束；引用校验保留，页面不显示使用位置，不提供名称改名或启停，也不自建本地调度。
- 业务分类：客户管理仅保留业务分类菜单，在该页内维护分类和独立字段库。分类直接以有序 `fields` 数组引用字段，数组位置决定顺序，逐项设置显示和必填；不同分类可共用字段定义并独立配置。分类可不选字段，线索分类须直接包含六项预置统计字段。字段及单选/多选选项的业务编码均选填，仅作本地映射。草稿允许不完整，最终保存才校验；导入选启用分类，通话按当前分类字段填写，正式值同步通话详情及按业务分类和单据分组的客户档案。
- 外呼任务：预外呼列表支持直接导入客户，自动外呼通过导入与分配添加；导入不自动启动。任务从当前enterpriseId已登记导航中显式选择一个，可选填多个本租户号码池及手工优先级，客户接听等待默认30秒。预测任务最小可用座席数默认10、范围1–10；低于阈值自动暂停，仅设置定时开始且因座席不足暂停的任务在人数恢复达阈值时自动启动。自动外呼没有该字段。重呼开启后，下一步和确认创建校验号码状态、次数、间隔和计时依据；未填完整仍可保存草稿、关闭或返回，保留空值。时间条件在草稿、模板、复制、创建和启动/继续时按当前规则复查。再次联系沿用原任务配置，不打开新任务向导。
- 客户档案：列表不固定展示“线索 / 意向”，档案和通话按所属业务分类读取自定义字段；导入与分配记录保留业务信息，不再设置“查看批次”入口。档案中的未知通话结果显示“结果未知”，不新增状态枚举。
- 任务设置：预外呼与自动外呼在创建、确认、查看管理和原任务编辑中使用本任务保存的名称、描述、供应商业务标签及通用设置；实际改动才按原任务编号差量更新，回查成功后刷新当前设置与快照。自动外呼的语音流程名称优先读取本任务冻结快照，既有任务缺少客户接听等待时间时显示“未记录”；已建自动任务的语音流程更改保持只读，待 CF-17 确认。任务列表不展示“执行配置”和“后续重呼”。
- 通话详情：人工外呼、预外呼、自动外呼、呼入分别使用对应话单接口的接听结果、工号、时间和时长。接口来源或其中字段缺失、不可用时，不拿本地模拟值补齐接口事实；真实 0 秒保留。纯本地演示记录按本地来源展示。号码识别、接口重试轮次及是否最后一次以实际返回为准，不据此推断下一次呼叫。仅当账号、租户、呼叫类型和任务标识一致时，折叠展示关联任务设置；只读查看不带任务管理操作。队列和实际语音流程读取该通话返回值。
- 本任务再次联系：从非终态预外呼任务的“待再次联系”入口选择客户，在原任务新增名单批次和执行条目，保留原通话及业务信息。同任务防重复，不混合多个任务；已结束任务不可再次安排。新预测任务 `autoComplete=0`，名单耗尽后暂停，继续前按原流程核对任务状态；自动外呼默认 `autoComplete=1`。

本项目不建设历史字段配置版本或迁移旧业务模型；演示存储仅对既有 JSON 无损压缩，保留原记录内容以缓解容量不足，不删除历史通话。预置线索统计字段保留原有类型和统计语义，其他自定义业务分类不自动计入线索成效。官方原始快照和供应商澄清分别留存，现行采用规则以本版正式文档为准。

## 当前任务外显配置与座席阈值

D-086：每个enterpriseId可登记多个AliCti线下提供的外显导航。两类新任务在当前账号目录中显式选择一个，提交`customerClidsCategory=5`和单个`customerClidsGroup`；可从当前租户AliCti列表选择多个号码池，每项传`name`及可选整数`priority`。`customerTimeout`默认30秒、范围5–60秒。历史任务保留所选导航和号码池快照，通话实际外显号码以供应商话单为准。D-083单一默认导航假设已被本决定替代。

账号默认导航标识变更不回填已建任务。启动或继续时若任务保存标识与当前账号默认值不同，先从原任务编辑以API-404 `task/update`提交新标识，并用DOC-334 `task/get`核对同一`taskId`及可回读值成功；编辑期间默认值变化则拒绝过期提交、保留输入并重新打开核对。任务中心运行概览折叠的“演示座席人数变化”仅对本地演示预外呼运行/暂停任务显示，输入观察人数只模拟自动暂停和定时任务恢复，不读取实时人数或执行真实供应商任务操作。

预测任务`minAvailableAgentCount`默认10、范围1–10，任务内可用座席数低于阈值时自动暂停。只有`autoStart=1`定时开始且确因座席不足自动暂停的任务，人数恢复到不少于阈值后才自动启动；手工暂停、号码停用保护暂停和结束不自动恢复。自动外呼不显示或提交该字段。API-311/API-404明确阈值、定时字段和不足自动暂停；自动恢复与每账号默认导航唯一性是用户转述供应商技术口径，真实执行与回查分别待CF-18/CF-15联调。静态原型只模拟状态流转。

API-311/API-404没有任务级指定号码字段；API-312的`task/importTaskTel.taskTelList[].clid`仅在逐客户名单行显式提供时可选，不由任务或批次自动生成。D-070多导航目录仅保留在历史变更记录，当前以D-083为准。
