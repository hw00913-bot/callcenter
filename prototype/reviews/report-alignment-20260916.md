# 数据报表专项对齐 · 2026-09-16

本轮按用户确认，以同一供应商账号、同一客户品牌下的完整线索编码统计。当前改造范围为原型和专项验证记录；正式说明、附表、流程及开发包未更新。

## 已落地

| 报表 | 采用的数据与本次调整 |
|---|---|
| 线索成效（新增） | 平台导入线索 + 明确关联的通话 + 当次业务信息。相同编码跨批次合并；不同编码即使手机号相同也分别统计；无编码单独保留。 |
| 通话总览 | 官方人工、预测、自动任务及呼入话单；秒级时间转换，客户接听时长与双方通话时长分列，未结束记录不计入周期。 |
| 客户跟进 | 平台名单分配/跟进情况，以导入批次为口径；与线索去重统计分开。 |
| 外呼任务 | 官方任务报表累计号码、累计呼叫、累计重呼；平台已处理名单和周期通话量各自保留，不混为完成数。 |
| 坐席成效 | 使用明确工号关联和真实双方时长，保留工号前导零；呼入首呼目标及流转名单不直接当作实际接听分段。 |
| 呼入服务 | 区分系统应答、客户接通、人工接通；展示官方首队列等待、队列中放弃和队列中溢出，不把溢出改称超时。 |
| 服务技能 | 使用队列与本地技能的明确映射，不按坐席当前技能倒推历史，不强行按顺序配对坐席和队列流转。 |

线索成效支持线索量、分配、联系、接通、待跟进、跟进完成、到店/试驾意向、计划到店统计；支持等级、意向和门店筛选，六项业务信息随结果导出，明细右侧展开，可继续查看通话、客户档案和关联任务。联系覆盖率与线索接通率均以当前筛选线索总量为分母。意向和计划不表示实际到店、试驾或成交。

按首次可见导入日期选择线索，再展示截至当前的累计联系和最近已填写业务信息。批次、任务和坐席用于选择命中的线索，不截断这些线索的其他可见历史。权限先于聚合，切换门店/品牌后重新限定范围。

## 官方接口与边界

- `/interface/v10/outboundReport/predictiveObReport`：预测及自动任务累计报表，模型含 taskType=1/2；calledCount 包含重呼。
- `/interface/v10/outboundReport/predictiveDailyObReport`：日报契约已校验并实现纯适配；answerMinutes 为分钟，totalStatistic 不与明细重复求和。
- `/interface/v10/outboundReport/predictiveAgentObReport`：坐席报表契约已校验并实现纯适配；状态时长不替代话单双方时长。
- `/interface/v10/queueReport`：队列报表契约已校验并实现纯适配。telEnterCount/telAnswerCount 的中文说明与例子存在冲突，本轮原样保留，不自行交换含义或重算其相关比率。
- `/cc/list_cdr_auto_task`：自动任务话单，采用 customerBridgeDuration，机器人信息不当作人工接听。
- `/cc/list_cdr_ib_agent`：官方另有坐席接听分段记录。当前原型未合并分段数据，无法证明归属的呼入不分摊到坐席/技能报表；不宣称完整复刻供应商原生报表。

现有坐席/技能报表仍是授权范围内的已加载话单聚合。日报、坐席和队列原生汇总适配没有混入这些聚合指标。新建或历史任务缺少明确供应商报表样本时，累计值留空，不拿本地名单数补充。

本轮读取并保存了24份当前官方页面，详细来源、模型字段和说明差异见 `../memory/evidence/report-alignment-20260916/contract-review.json`。模拟数据与查询返回均来自本地 mock，没有真实供应商业务请求，也不代表生产联调完成。
