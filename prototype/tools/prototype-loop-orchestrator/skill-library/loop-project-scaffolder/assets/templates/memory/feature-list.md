## Consumption Rules

- S6 拆分、S7 实现和 S8 验证必须引用稳定功能编号；只有本轮明确请求标注时，S9 标注产物才引用这些编号。
- 新版 FUNC 描述“业务对象＋单一主操作＋可验收结果”，不等同于 SC、模块、页面、按钮、字段或接口列表。保留对象和主操作；同一场景中的多个独立操作不能合并为管理包，多个实现任务也不产生多个 FUNC。历史粒度保持只读，条目数不是标准功能点数或价格。
- 本表之后保留每项包含／排除范围、规则、异常、依赖、假设、拆分依据与变更前后差异；导入模式由适配器物化，历史基线缺失时说明缺口，不自行补造。
