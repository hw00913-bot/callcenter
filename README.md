# 云呼叫中台原型

智能外呼与云联络中心的桌面端交互原型。使用 HTML、CSS 和原生 JavaScript，无需安装前端依赖或构建。

## 本地运行

在仓库根目录运行（需要 Python 3）：

```sh
python3 -m http.server 18765 --bind 127.0.0.1
```

打开 [本地原型](http://127.0.0.1:18765/DEMO_PROTYPE/index.html)。请使用 HTTP 服务访问，不要直接以 `file://` 打开，导航会加载本地配置。服务以仓库根目录为起点，确保图集引用的接口说明也能访问；若端口已占用，可更换端口。

登录页展开“演示工具”，选择预置演示账号，再按正常流程选择租户和业务域。演示账号及密码只用于本地原型，不是真实认证服务。

## 当前能力

- 智能外呼原型及云联络中心业务域。
- 账号、租户、坐席、技能、线路与号码管理。
- 运营工作台和坐席工作台。
- 客户导入、分配、按手机号归档及联系记录。
- 人工外呼、预外呼、IVR 和呼入场景的本地演示。
- 原型内业务流程、系统交互时序和关联系统视图。

客户导入支持 CSV 或 Excel 粘贴，列顺序为：

```text
客户称呼,客户号码,联系备注,外部单据标识
模拟客户,13800000001,确认试驾时间,LEAD-0001
```

联系备注与外部单据标识选填，兼容原三列格式。外部单据标识可记录线索编码、售后工单号等，随分配和模拟通话保留；不会因此发起外部单据查询或回写。去重与归档仍以原手机号规则为准。

## 回归测试

需要 Node.js（支持 `node:` 模块及 `structuredClone`）。在仓库根目录运行：

```sh
node qa/check-customer-external-document.cjs
node qa/check-customer-tasks.cjs
node qa/check-customer-directory.cjs
node qa/check-task-customer-pool.cjs
node qa/check-customer-demo.cjs
node qa/check-demo-accounts.cjs
```

这些测试调用实际原型逻辑，但 DOM、存储及定时器为测试替身，不代表浏览器验收或阿里云真实接口联调。

## 范围与安全

- 本仓库为交互原型，不是生产系统；不拨打真实电话，不进行真实充值，也不连接真实认证或阿里云服务。
- 业务演示数据主要存储在浏览器本地。请勿填入真实客户资料、生产密码或服务密钥；不同浏览器、地址和端口的演示数据可能不互通。
- 原始会议/分析材料、旧归档、重复压缩包、本机工作流工具及状态文件不随代码提交。图集引用的接口核验矩阵作为运行说明依赖保留。
- 原型仍在迭代，图集及接口矩阵不保证已与每次页面增量完全同步；未验证项不等同于厂商支持承诺。
- 最新外部单据标识专项已通过本地回归；当前浏览器点击/视觉验收受工具连接问题影响，尚未完成。
