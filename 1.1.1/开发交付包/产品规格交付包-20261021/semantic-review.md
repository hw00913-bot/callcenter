## 关键业务含义复核

**字典及权限。** 超管只维护名称、预置能力、租户集合、启停。名称 trim 后必填、最多 60 字、全局英文忽略大小写唯一；同能力可有多个独立条目。空租户集合是无人获授权。条目改名不改稳定引用；已有字段/业务/归档/未完成通话保留引用，或无法核对引用时锁定取数能力，提交时重查。启用、停用、授权和撤权是可独立发生的操作，全局流程不要求依次全部执行。菜单第三 Tab 仅超管可维护；其他角色仍受本租户和原对象权限限制。

**当前车系与门店。** 当前意向车系来自 Mapping 接口，是唯一可搜索单选，无上游条件、无自由创建。原计划到店门店为普通文本，与更换/清空车系无依赖；本期不启用接口门店查选。客服只见业务控件，主机、鉴权、底层映射不转给运营配置。官方 `relation_id` 字符串暂作为 code；媒体 ID 与状态分别保留，不混作 DCC 编码或补状态枚举。文档媒体 10/状态 1 是实施假定，真实覆盖范围留研发联调核实。

**通用依赖。** 普通接口字段可配置是否使用一个直接上游，并明确所取返回属性、下游参数名和条件必需性；支持无环链。必需边要求分类加入且显示上游；可选缺上游/隐藏/未填时才省参，已填无效、属性/类型或参数异常不能当空放宽。查询条件必需与客服填写必填各自设置。变化传递使旧请求/确认失效；完整新结果才判旧值匹配，待重选重匹配或来源恢复均须人工确认。此通用机制不套到本期原门店文本。

**本通保护及保存。** 未选业务类型时也在开始时固定可用目录及整版定义，通话和话后保存用同一版；后台新增必填、排序、显示、类型、选项、依赖和分类逻辑删除不替换健康本通配置。账号和接口授权仍实时校验。来源不可用保显示但不作有效值，选填可明确清除，必填沿本通规则。一次查询异常不能一概判原值失配或禁存，已有有效依据仍按原规则逐项判断。电话结束操作不因字段查询错误被禁用。准确未接通条件继承 v1.1.0；未知、呼入、仅坐席未接不笼统豁免，已填合法 0/false 仍保留并校验。

**原导入、同通及历史。** 导入只读，不因填写/保存回写；仅明确确认且官方 code 精确匹配时带入车系，不按同名或媒体 ID 猜测，不自动写门店文本。旧请求不得覆盖其他通话/租户/配置或后续编辑。保存成功才形成当次名称、编码及来源快照；详情只读当时值，档案沿原汇总，不新造跨通车系与门店配对或空文本清除汇总规则。

**三类删除。** 字段/接口确认未使用后才物理删除，预置字段同规则；确认提交重查，失败/取消/并发变化保原对象。分类采用逻辑删除，历史或已有业务引用只作影响说明，不禁止退出新业务。归档只保该分类全部实际 refs 及必要依赖定义，不复制整个租户库存；旧任务、当前通话/话后和历史继续，不能仅凭任意已删 ID 冒充旧任务。归档继续保护字段/接口。没有恢复、归档清理、数据迁移 UI，显式空库和删除结果不自动补默认。

## 来源差异与未决责任

来源保留完整变更历史。旧 PAGE-008 的“管理员维护候选/默认本地不外查”及部分旧边界“接口车系不受外部资格约束”，按更新的 AC-109/112、BR-024/026/029 采用 Mapping 查询与实时授权，旧段落仅审计。历史值和暂缓的 API-016/DCC 门店、旧物理候选不转成本期实现范围；当前所需字典/字段业务含义由当前规则单独覆盖。1,887 项来源清单逐项有处置，其中历史/排除记录 1,223 项，当前覆盖 664 项，无未处置来源项；计数不等于 1,887 个新增需求。

ISSUE-11113 在来源仍为 accepted_risk，ISSUE-11105 仍为 open。产品包处置中的 out_of_scope 只指本阶段不执行真实接口和生产草稿技术验证，未把本期 Mapping 功能移除，也未声称问题已解决。研发须同版补主机/鉴权/权限、真实响应和编码/过滤范围、重复冲突及错误约定，补本通草稿归属/保存恢复/成功后清理的一致性；影响业务的发现须返回产品确认。来源旧草稿阶段限制保留追溯，当前交付授权依据为用户本次产品规格交付指令及当前冻结基线。

产品阶段不要求的七类工程资料全部如实待补：scaffold、stack、backend、data、api、coding、verification。仓库、团队技术栈、生产模块/数据/API物理映射、精确文件任务和可执行测试命令均未虚构。没有初始存量迁移，不等于允许删除上线后产生的历史或当前通话依据。
