# UI 规范说明

**READY_FOR_ENGINEERING_DESIGN — 产品可交接，工程设计需补齐**

[返回阅读入口](README.md) · [按功能阅读](features/README.md)

UI 呈现引用业务字段和局部逻辑，不重新定义业务规则；本说明没有执行视觉或交互测试。

## UI 范围

模式：specified

复用五处既有页面与业务分类同页三Tab，桌面操作优先，不新增独立字段填写/草稿/车系服务页面。

依据：
- planning/page-index.json
- outputs/menu-and-page-planning-reference.md

## 设计依据

- 当前v1.1.0底座及v1.1.1已核验原型的深蓝侧栏、白色卡片、蓝色主按钮、右侧编辑抽屉与通话记录同款Tab。
- 冻结需求PAGE006～010与当前确认SRC167/171/177/179；原型位置为1.1.1/prototype/index.html，仅设计参考而非生产代码库。

## 全局布局

- 业务分类/自定义字段/取数接口字典同页呈现，第三Tab按超管权限显示；编辑/使用位置沿原抽屉，列表筛选分页不丢。
- 工作台以紧凑接口下拉加原文本字段填写；本次填写/导入只读并排Tab，原通话、备注及处置操作保持可见。

## 文字规范

- 沿现有系统字体：-apple-system、BlinkMacSystemFont、PingFang SC、Microsoft YaHei、sans-serif；正文及控件沿既有14px体系，辅助信息与标题用原层级。

## 颜色规范

- 沿现有主操作蓝#1677ff、深蓝导航及白色卡片；错误/危险用既有红色语义，禁用采用原灰色；不另建品牌主题。

## 间距规范

- 沿原8/16/24间距体系与组件内边距，表单标签与输入对齐，弹层标题和底部操作固定可见；不为本需求压缩客服可操作区域。

## 可访问性

- 每个可输入字段有可见标签；必填与条件适用时机可读，锁定原因用文本说明，不只依赖颜色。
- Tab有唯一选中状态；键盘可达、弹层焦点沿原机制限制并在关闭后返回；错误定位到已显露的填写字段。

## 响应式行为

- 本期沿已有桌面1440/1920评审目标；窄窗容器按原滚动规则处理，保证表单操作和通话控制可达。
- 不新增移动端业务流程验收；业务/时序图沿原桌面宽屏、缩放及横向滚动阅读。

## 组件规范

<a id="UI-TABS"></a>

### UI-TABS 同款页签

变体：
- 分类/字段/字典
- 本次填写/导入只读

状态：
- 选中
- 未选中
- 无权隐藏

交互：
- 与通话记录同款分页样式，选中唯一；切换保留同一上下文编辑，新通话默认填写。

<a id="UI-TABLE"></a>

### UI-TABLE 配置/引用列表

变体：
- 配置列表
- 具体使用位置
- 字段引用排序

状态：
- 正常
- 加载
- 空
- 异常
- 无权

交互：
- 保留筛选与分页，使用位置只读，不以引用库存冒充业务填写。

<a id="UI-INPUT"></a>

### UI-INPUT 原文本及名称输入

变体：
- 接口名称60字
- 原普通字段文本

状态：
- 可编辑
- 只读
- 无效
- 禁用

交互：
- 显示标签与明确行内错误，trim名称且保存时校验；原门店文本不联动。

<a id="UI-SELECT"></a>

### UI-SELECT 配置单选

变体：
- 取数能力
- 条目
- 属性
- 条件必需性

状态：
- 可选
- 锁定
- 无可用选项

交互：
- 只选已声明范围；锁定说明原因，不默删参数扩大范围。

<a id="UI-CHECK"></a>

### UI-CHECK 勾选配置

变体：
- 租户多选
- 分类显示/必填

状态：
- 勾选
- 未勾选
- 不可编辑

交互：
- 租户空集合不表示全部，分类必填与查询条件必需分别设置。

<a id="UI-DRAWER"></a>

### UI-DRAWER 既有编辑抽屉

变体：
- 接口编辑
- 字段编辑
- 分类编辑
- 引用详情

状态：
- 打开
- 提交
- 异常保留

交互：
- 顶部返回/关闭、底部保存取消；未保存退出沿原防丢稿反馈，不清其他页面输入。

<a id="UI-CONFIRM"></a>

### UI-CONFIRM 删除/状态确认

变体：
- 未用物理删除
- 分类逻辑删除
- 启停

状态：
- 确认对话框已打开
- 核对中
- 冲突
- 成功

交互：
- 删除确认前显示用途与影响，提交重查；分类已有业务只作影响说明。

<a id="UI-QUERY"></a>

### UI-QUERY 可搜索接口单选

变体：
- 本次Mapping车系
- 其他接口字段

状态：
- 未加载
- 加载
- 完整候选
- 成功空集
- 异常
- 来源不可用

交互：
- 主表单紧凑下拉，按名称/官方编码查找，不自由创建；完整结果才可新选。

<a id="UI-FEEDBACK"></a>

### UI-FEEDBACK 状态/行内提示

变体：
- 配置错误
- 保存异常
- 查询异常
- 成功反馈

状态：
- 说明
- 警告
- 错误
- 成功

交互：
- 异常保留输入并定位，不把查询异常写成空结果，不禁用电话控制。

<a id="UI-READONLY"></a>

### UI-READONLY 只读信息

变体：
- 导入原始
- 同通快照
- 归档影响

状态：
- 有值
- 未提供
- 无权

交互：
- 按当时快照显示；缺项明确，无权不露出其他租户数据，不增加历史编辑。

<a id="UI-DEPENDENCY"></a>

### UI-DEPENDENCY 通用条件映射区

变体：
- 无条件
- 一个上游

状态：
- 关闭
- 开启合法
- 缺来源
- 不兼容

交互：
- 开关后按声明配置属性与入参；可选缺来源不强制加入分类，本次车系固定无上游。

<a id="UI-CALLBAR"></a>

### UI-CALLBAR 原通话及结果操作

变体：
- 通话中
- 话后

状态：
- 进行中
- 可结束
- 处理中

交互：
- 保持既有通话/备注/结果入口；接口或配置问题不阻止电话结束操作。
