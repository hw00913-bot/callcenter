# AliCti 原型字段级对齐复核

版本：2026-09-24-business-category-fields-1。读取 101 份官方正文/字段定义；逐项复核 217 项原型字段映射，附 2536 条带接口/方法上下文的字段契约。

已修正 87 项；已对齐 72 项；本项目不开放 2 项；平台字段 55 项；待确认 1 项。

当前原型只覆盖 AliCti 云联络中心与平台自有能力。工号类型按D-014统一String；D-015采用RASR文本与预览门控，CF-02关闭；D-016采用本地重呼开关与官方IVR列表选流，执行计数交由阿里；D-017暂停不提交pauseDuration，继续先查询确认暂停再启动并复查，已结束不重开；D-020采用用户转述阿里反馈，预测与自动外呼均支持按号码状态重呼，开启均必填；关闭省略相关重呼字段与templateName按不启用处理，为当前项目采用。FA-046已修正、CF-03关闭；常规接入验证不作为功能待确认。D-021（SRC-053）为用户产品确认：暂停后可以继续，结束后不再执行后续首次呼叫及尚未执行的重呼；迟到结果只回补原记录与统计，不重开任务或触发重呼。CF-04已按D-047用户转述供应商答复关闭：暂停或结束后已发起通话正常进行并生成正常话单；不强制挂断、不改写通话结果。官方原文快照保留；完整契约条目不等于已实现字段或联调通过。 本轮统一更新：D-085：客户管理仍只保留业务分类菜单；取消独立业务模板实体，业务分类以有序fields数组直接引用本租户独立字段库，项内仅fieldId、enabled、required，数组位置决定显示顺序。分类可零字段，线索分类必须直接含六项预置统计字段；不同分类可引用同一字段并各自配置显示与必填。导入、通话记录、客户档案和线索统计按当前分类字段读取，字段及选项选填businessKey只作本地映射，不进入AliCti请求。原型无需旧模板数据迁移或兼容。D-074/D-077三层关系保留为历史；D-084坐席事件边界与其他现行决定继续适用。
