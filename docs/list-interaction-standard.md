# 列表与筛选交互规范

来源：SRC-022，列表与筛选统一使用固定控件、横向标签、换行间距和“重置、查询”顺序。

## 当前云呼叫页面规范

- 列表必须有序号，列宽64px；从1开始，分页连续，筛选或重置回第一页。已有序号不重复插入，空态合并完整列数。
- 筛选区域占满所属内容区域宽度；统一20px内边距、16px纵向间距、20px横向间距。字段数量多时自然换行，不通过拉长输入框填充空白。
- 标签与控件横向排列：标签按文字实际宽度显示，紧贴控件并保持8px间距，控件200px、高32px。筛选项整体宽度随标签自然变化，不固定标签宽度或筛选项总宽度。标签13px常规字重；控件圆角6px。
- 重置在左，查询在右，按钮间距8px、高32px；原查询、重置处理及权限不变。业务系统切换属于上下文选择，继续即时切换；授权搜索继续保留勾选。
- 表头高44px，表格正文上下内边距12px；操作区使用公共toolbar和table-actions。
- 手机窄屏字段按行排列，控件使用剩余空间，不固定溢出。
- 应用范围是云联络中心及其账号租户管理、授权弹窗。

## 实现与验收

公共PlatformUI.table负责默认序号，分页调用方传rowOffset，必要非列表可用numbered:false。公共样式限定body[data-domain="CLOUD_CONTACT_CENTER"]，不修改表单详情布局。页面原数据、权限、业务流程保留。

组件测试验证序号、分页、空态、原查询重置及角色回归；实际浏览器尺寸和页面视觉仍待验，不能用源码尺寸当作浏览器测量结果。

## 客户、任务与通话列表精简（D-063～D-066）

- 客户列表不固定展示“线索 / 意向”，业务信息在档案与通话中按所属业务分类的自定义字段展示。导入与分配记录保留业务列，移除“查看批次”操作及其操作列。
- 预外呼和自动外呼列表不展示内部“执行配置”、配置版本或“后续重呼”推断。重呼条件、次数及间隔仍在任务设置中维护；本任务再次联系入口保持原任务范围。
- 创建确认与任务详情使用同一套信息摘要；详情只读取本任务已保存和冻结的设置，不从当前共享模板或技能成员补出内容，缺失值显示“未记录”。
- 通话列表、任务内通话列表及查看详情使用同一话单取值口径。人工外呼、预外呼、自动外呼和呼入分别读取对应接口；时间、工号、接听结果和时长不以本地模拟值覆盖接口事实。已有接口来源却缺字段或原文不可用时不回退；没有接口来源的纯本地演示记录仍按本地来源展示。
- 通话详情使用“通话结果 / 详细信息”页签，关联任务设置默认折叠且只读；任务身份不一致时不显示其他任务设置或再次联系入口。缺失时长显示“未记录”，真实 0 秒保留；档案中的未知结果显示“结果未知”，不是新增接口状态。
- 二级详情使用右侧抽屉，左上返回、右上关闭；查看内容不嵌套新增、编辑和其他管理流程。
