## 当前可演示内容

- 应用接入支持列表、新增、详情、修改、精确删除、多个租户关联及回调地址；仅超管管理。身份须显式指定获授权租户，未配置回调地址不接收接口导入；凭据和身份都是本地合成。
- 接口明确预外呼／人工外呼：前者指定任务ID并沿任务坐席组，后者坐席工号选填，缺省接收但不分配，有值校验本租户唯一有效坐席，显式错误拒绝该行。新接口客户业务跟进初始未同步，不凭分配推定待联系。线索编码、手机号、优先级、请求级业务类型及业务批次保留；业务批次可重复，requestId单独防重复导入。
- 所有来源应用沿准确原应用、租户、记录及回调地址处理结果。通话结束且处理结果为“已完成沟通”、保存成功后，冻结本次通话、业务批次、原六项来源资料和已填业务字段／选项编码；缺码保待完善，补送不重新拨号。手工界面无应用来源的记录在平台内处理。
- 人工拨号后及预外呼坐席振铃时即可填写；阶段切换保留草稿，未接通需选择通话状态，人工记录与客观线路结果分开。继续跟进由当前坐席后续人工联系；原预测任务仍运行或状态未知时不放行再次人工拨号。
- 导入与分配统一查看人工与预外呼接口批次，原app/tenant/request和任务不变；同业务批次号复用不合并不同请求。分配、通话和业务跟进分开；未同步不误计待联系或跟进完成。无工号不入个人列表，有权本人可明确确认平台联系安排。
- DCC同一AliCti的外部人工拨号以本地合成桥演示，按准确原记录和callId关联；本通实际工号不反写原分配，客观接通不推业务完成，任一通在途/未知资料不放行新拨打。真实实例映射、报文及来源版本协议仍待核。
- 客户档案按当前企业、租户、号码只读归集原导入记录及准确通话，不复制业务账本或改变回调归属。
- 手工导入保持三步弹窗、线索类单一编码和选填字段后置；任务行统一“查看任务／编辑／导入客户”，直接导入不叠开任务看板。
- 本地定时到点重验条件再首启；已明确受理后开放手动启动。失败三类120秒、八类人工共享首次外2次，未知占用不盲发；秒挂显式禁止平台补提交。接通事实与秒挂分类分别统计，不推造供应商终态。
- 实际导出CSV；下载取消／失败及普通下载保留失败记录；受支持的另存为路径只在写入、关闭及准确回读后清理对应版本。

## 本地启动

直接双击本目录 [index.html](index.html)，或从 [项目统一入口](../../index.html) 选择版本，无需启动服务。全部数据均为合成演示，不发真实供应商或业务系统请求。浏览器关闭时，本地时钟不执行；生产调度、并发、崩溃恢复和供应商停呼排他需要后端与真实联调。
