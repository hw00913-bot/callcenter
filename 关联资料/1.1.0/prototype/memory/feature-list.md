## 功能范围与验收明细

粒度规则版本：business-operation@2

### FUNC-001 · 修改应用

- 业务过程边界：
  - 业务对象：既有应用及其租户授权配置
  - 单一主操作：修改应用
  - 系统与交付责任边界：本平台业务规则及明确标注合成模拟；DCC/供应商真实服务与内部调度不在本轮实现范围。
  - 业务发起方：超管
  - 触发事件：从应用列表或详情进入修改并提交时
  - 主要业务目的：既有应用名称和可访问租户更新，appId及创建时演示密钥保持
