## 6. 业务流程

### FLOW-001 · 导入、结果分流与原始链闭环

关联场景：SC-001、SC-002、SC-003、SC-004

可视化：[在 HTML 图集中查看 FLOW-001](business-scenario-atlas.html#FLOW-001)

1. 创建任务提交时锁定接口/手工方式，校验tenant/task，应用仅鉴权与追踪
2. 逐行校验并保存单号批次自动提交；同步数量准确记录，result0不等逐条全成功；待提交高优先级先/同级FIFO，已提交不重排，仅同任务，不同任务独立
3. 53失败推送分片回查企业/任务/供应商fileId/原始号码到本地批次和leadCode，重复不新增迟到不丢；接口任务回传导入阶段失败，手工只查看，不计呼叫不自重导
4. 供应商每次事件/话单回查任务批次线索手机号；无话单失败独立保存、秒挂按真实条件识别
5. 接口任务每次结果回传后台固定DCC地址，手工任务仅平台查看；重复/晚更新不制造新呼叫
6. DCC决定是否/何时重新导入；平台不创建重导计划或额度
7. 保留原导入北京时间自然日priority衰减，可信未拨/未接通才降级，精准删除成功停降级

### FLOW-002 · 失败导出与业务记录保护

关联场景：SC-001

可视化：[在 HTML 图集中查看 FLOW-002](business-scenario-atlas.html#FLOW-002)

1. 本地校验失败、供应商同步/异步导入失败分类进入既有失败下载入口；呼叫失败独立记录
2. 按已知失败分片展示收齐或不完整/待核，不推定整个导入终态
3. 生成本次失败快照和导出文件；点击/生成不等成功下载
4. 可信成功下载只清本次快照明细和文件；中断/失败保留
5. 保留必要关联、去重、分片及DCC交付状态；迟到新失败可再次下载，已导出重复不再生成
