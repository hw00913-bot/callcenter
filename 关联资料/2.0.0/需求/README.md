## 本轮已经确认并回写的规则

顶层为**坐席工作台／呼叫中心／报表中心／公共能力**。四项是导航区域；AI与云呼叫仍独立开通，成员、专业资源、摘要、报表明细、导出与财务分别授权。取消独立运营概览，AI概览与使用情况归AI用量与服务，独有片段按原权限承接。

沿AI生产身份基准先验证账号。业务单租户直接进入，多租户首次选择，后续恢复上次仍合法租户；纯平台/专业/公共身份按原合法范围进入，不强制业务租户。没有新增首页。首次仅对原综合概览、无明确本人作业/监管默认且同时有导入分配和云报表权限的人群，优先进入导入与分配；不扩大为历史位置失效后的统一优先级。

**电话边界沿用原云呼叫范围**：同租户Cloud原页面之间（含Cloud报表）保留原电话条及原检查；进入AI（含AI报表）、公共能力或切换租户前，先完成本人通话、必要话后并确认离线。仅监管他人、本人无会话者不按他人状态受阻。返回不自动上线或拨号，后台已受理任务仍沿原规则。

公共账号、租户、分类基础目录、黑名单各只有一个主维护入口；AI专项名单按原范围/期限保留。原AI场景/标签、Cloud字段配置、供应商资源、电话坐席和财务保持专业业务边界。可复用的原页面及交互直接复用，仅修改已确认整合冲突。

本轮实际确认：**分类停用仅限制新选择、新关联**，已有AI场景保留原关联并可按原专业规则继续建任务；已受理任务及历史保留（SRC-2058）。**历史名单按证据和有效状态分流**：当前有效且有明确拒联证据的经对账承接公共拒联，专项维持原范围/期限，已解除或到期不复活，含义不明保留原约束待核（SRC-2059）。只确认政策，没有执行真实迁移；两项不再重复询问。

44个来源PAGE和105个ACTION保留追溯；当前承载41处，另3个历史来源不作为当前菜单。旧AI拦截转公共名单的AI范围视图。页面数、菜单数、操作草案数均不是新增开发数量或报价。
