# D联络云 v2.0.0

本目录是 AI 外呼与云呼叫整合的本地模拟原型，当前处于原型 Loop S7。统一框架、多租户登录及切换保护、原 AI 任务与导入、云呼叫坐席作业及客户档案、监管、品牌与租户管理、独立模块开通已有业务 HTTP 走查记录。账号与成员、分模块授权、已有坐席关联和停用后的当前通话收尾已有本轮业务走查记录。公共分类、AI 原业务场景与标签配置、云呼叫原字段配置，以及本批公共黑名单、AI 来源核实和人工拒联登记已完成本地业务主路径走查；其余页面按执行步骤推进，尚未完成全局验收。

用户已于 2026-10-19 批准本轮本地静态 Mock 例外及启动提案，记录见 [本轮授权](inputs/local-mock-approval-20261019.json)。这不代表 G3 冻结或生产上线批准；真实权限、接口与供应商执行证据的待核事项继续保留。

直接双击 [项目统一入口](../../index.html) 或本目录 [index.html](index.html) 打开，无需启动服务。云呼叫原型现位于 [原型/1.1.0](../1.1.0/index.html)，v1.1.1 专项位于 [接口字段联动](../1.1.1-接口字段联动/index.html)。本次目录整理保留原业务实现、冻结输入和批准记录。

本地文件直接打开的最终浏览器验收仍待完成，当前 HTTP 交互验收不能替代该项；无需为此自行启动服务。

品牌归属和模块开通均不自动赋予其他租户业务权限。账号与成员管理已提供可点击页面，并有本轮业务走查记录。任务接入正在单步走查：AI 已有“本租户停用／全局停用经办人 → 其他已有权人员处理同一批名单 → 只读人员回读”的实际页面证据；预外呼、IVR 及其异常分支继续核验，不把同名示例任务作为共享证明。

`pages/ai`、`pages/cloud` 是本版本的模块资源，请从上述统一入口进入，不需分别打开。原 AI 的 Excel 读取和失败记录固定样例导出限制已保留在验收边界中，不代表生产能力被删除。

具体进度见 [执行步骤](memory/execution-steps.md) 与 [验证日志](memory/verification-log.md)，待核事项见 [memory/open-items.md](memory/open-items.md)。阶段状态由 `python3 tools/loop_run.py status .` 查看。

本批公共分类只维护一份当前租户目录。AI 的具体场景关联沿原“标签管理 → 场景配置”；云呼叫沿原字段库、填写配置和预览。新增公共分类可在云呼叫原表单首次配置专属业务编码及填写字段；公共名称/启停也供原导入选择使用，历史记录保留。

已经由你修改过的人员授权会保留；新增演示人员及未改过的明确示例按本批需要补载，不清空原成员资料。可由有权成员管理员在“账号与成员”中明确授予 AI 管理员或云呼叫租户管理员角色；已保存相同角色但缺新权限时，先明确移除该模块授权再重新授予。此操作不自动上线电话，不重置任务或历史数据。

本批已补齐保存结果未知后的“重新核对”：保留当前填写内容，先读取当前有权范围的实际配置，再由用户另行提交；核对动作不自动保存，也不代表上一次未知操作已成功。已知保存失败继续使用原显式重试。

本批可从“公共能力 → 黑名单”查看同号多来源、原专项分组和导入、逐平台同步记录，并按独立授权新增或解除本条公共拒联。在 AI 通话记录详情核实后可进入公共登记，再返回准确来源；人工拒联只有原话后保存成功才登记。已保存但登记失败或未知时，沿原保存入口核对并只续办登记，已保存字段保持只读；成员被停用时也仅允许准确当前通话必要收尾。本条解除保留其他有效来源，专项移除不等于公共解除，平台未知不显示为已全部放行。

本轮可从“呼叫中心 → 预外呼／IVR外呼”查看原任务列表、创建向导、详情、名单及原控制；AI 保留原任务卡片、导入与单条移除。任务业务资料在同租户有权人员之间共享，筛选、未提交草稿和本人电话状态分别保留。可用上述 A、B、只读账号在同一租户查看实际操作后的同一任务；账号停用仍从有权管理员的原管理入口办理，不自动转交任务或增加 B 的权限。

四类外呼的公共禁呼、原失败补提交及任务共享仍在 Step 08 浏览器走查中。供应商自动重呼沿原配置，人工补提交沿原失败条件；本地演示结果不表示真实供应商执行。当前记录覆盖本地 HTTP 业务主路径与代表交互，部分组合以精确模型和独立界面证据补充，不表示每个原按钮或供应商组合均已穷举。完整 2.0.0、直接文件最终验收和生产接入尚待后续完成，正式单步结论以验证日志为准。
