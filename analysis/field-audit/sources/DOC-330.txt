查询技能列表

接口说明：

API URL

接口请求地址： https://api-{region}.alicti.cn/interface/{version}/skill/list 

地址参数说明：

{region}为alicti平台区域，{region}=1 表示华东1区，{region}=2 表示华北2区，{region}=5 表示华东5区，{region}=6 表示华北6区

{version}为接口版本，当前{version}=v10 

接口请求方式：GET/POST

https://api-{region}.alicti.cn/interface/v10/skill/list?validateType=1&departmentId=BM3000003&timestamp=1491372644
