查询外呼记录列表接口

接口说明

针对呼叫中心外呼记录的数据列表。外呼记录新接口中，对关键数据计算规则进行了优化，包括响铃前等待时长、外呼等待时长、呼叫结果和客户接听时间等，同时还新增了挂断方和呼叫失败原因等字段。这些新增的字段为座席和管理员提供了更全面的外呼情况分析，显著提升了数据分析的准确性和有效性，进一步使得外呼记录的管理更加便捷高效。

API URL

接口请求地址：

https://api-{region}.alicti.cn/cc/list_cdr_ob

地址参数说明：

{region}为alicti平台区域，{region}=1 表示华东1区，{region}=2 表示华北2区，{region}=5 表示华东5区，{region}=6 表示华北6区

接口请求方式：
