## 1. 本轮范围

共 28 个本期用户故事、26 个本期业务场景；保留 6 个已退役场景编号用于追溯。现有 US/AC/SC 编号不重排，本轮只细化 7 个故事、6 个现有场景，没有新增独立业务场景。

| 范围 | 本次评估应保持的业务目的 | 场景 |
|---|---|---|
| 登录、业务域、租户与账号 | 继承账号/手机号登录，多租户登录时选择；明确实例、租户及角色边界 | SC-001、002、201 |
| 坐席与技能 | 账号与坐席同范围一对一关联；开通、技能、启停/恢复及历史保留各自职责明确 | SC-003、005、006、007、101 |
| 线路号码与呼入配置 | 线路/号码来源、实例归属、租户使用授权和业务隔离分开；共享呼入先确定租户 | SC-008、009、011 |
| 客户导入、分配、档案 | 三类业务编码、批次独立、手机号归档；人工分坐席，预外呼/IVR分任务；支持合资格项全选 | SC-203、204、205 |

| 人工外呼与呼入 | 本人坐席工作台、上线前检查、联系弹窗、通话与话后闭环；呼入排队及兜底隔离 | SC-102、103、017、018 |
| 运营工作台 | 超管关注实例，管理员关注任务/坐席，运营查看授权概览；任务与坐席各自下钻 | SC-105 |
| 结果、媒体与报表 | 同次通话一致归集与校准、录音文本独立可用；六类云域报表和真实本地CSV | SC-019、104、020 |

优先级沿用既有 P0/P1 划分，本轮不重定交付顺序，也不以场景数量计算工期。完整清单见[业务场景清单](business-scenario-list.md)。

## 2. 本轮消除的旧新冲突

| 对象 | 旧材料 | 本轮收拢口径 |
|---|---|---|
| 新客户批次 | 外部单据标识全部选填 | 新三类必填对应编码；只有历史未分类保留选填兼容。取消车辆召回继续有效 |
| 来源归属 | 仅通用外部单据文本 | 类型与编码随原批次、客户行及本次通话保存；不是手机号总档案唯一属性，不接外部系统 |
| 通话详情 | 录音播放/下载只有提示 | 指定合成样例已支持播放器、文本和下载；真实录音/ASR未对接，不能宣称全量媒体可用 |
| 报表 | 旧泛化报表与提示式导出 | 六类云域报表、同源筛选/下钻与CSV；客户批次累计、任务累计和周期成效明确分开 |
| 坐席下钻 | 当前状态与历史通话混杂 | 当前/历史分开，明细待更新明确提示；运营只读，管理员复用原停用，不新增强制介入 |
| 审计导出 / RAM 导入 | 容易与已完成能力一起表述 | 仍属保留规划或未实现入口；不借报表CSV成功将它们标为完成 |

## 3. 明确排除

- 外部业务系统接入、外部账号同步/关联、外部结果投递、PhoneBar；关联系统只留空态。
- 车辆召回及其专用 VIN 等关联规则；业务类型只保留线索、售后、活动及旧未分类兼容。
- 通用呼叫方案和人工命名配置；人工使用技能与号码，预外呼/IVR用任务规则，呼入独立配置。
- 监听、强插、强挂等未确认能力；查看坐席和停用不等于这些能力。
- 无数据依据的成交/到店/售后解决/活动转化率、历史在线时长与利用率。
- 新接口自带但当前未要求的能力；不因供应商更换自动扩大范围。
