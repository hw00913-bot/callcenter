<h2>查询座席接听记录列表接口</h2>
<ul>
<li>接口说明<br>
针对呼叫中心座席接听电话记录的数据列表。通过这个接口，可以查看座席在一定时间范围内的所有接听记录，了解座席的工作情况、效率、服务质量等。帮助呼叫中心管理者、质量监督人员或客户了解座席的接听情况，以便进行工作评估、问题追踪或服务质量改进。</li>
<li>API URL<br>
接口请求地址：<br>
<a href="https://api-%7Bregion%7D.alicti.cn/cc/list_cdr_ib_agent" rel="nofollow">https://api-{region}.alicti.cn/cc/list_cdr_ib_agent</a><br>
地址参数说明：<br>
{region}为alicti平台区域，{region}=1 表示华东1区，{region}=2 表示华北2区，{region}=5 表示华东5区，{region}=6 表示华北6区<br>
接口请求方式：<br>
GET</li>
