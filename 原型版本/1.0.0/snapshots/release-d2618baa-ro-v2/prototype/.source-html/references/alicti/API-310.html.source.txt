<h2>号码列表分页查询接口</h2>
<ul>
<li>
<p>接口说明：分页查询企业号码列表，支持多条件筛选（号码类型、外显类型、号码状态等）</p>
</li>
<li>
<p>API URL<br>
接口请求地址：<a href="https://api-%7Bregion%7D.alicti.cn/interface/%7Bversion%7D/enterpriseHotline/listPage" rel="nofollow">https://api-{region}.alicti.cn/interface/{version}/enterpriseHotline/listPage</a><br>
地址参数说明：<br>
{region}为alicti平台区域，{region}=1 表示华东1区，{region}=2 表示华北2区，{region}=5 表示华东5区，{region}=6 表示华北6区<br>
{version}为接口版本，当前{version}=v10 <br><br>
接口请求方式：POST</p>
</li>
<li>
<p>相关参数</p>
</li>
</ul>
<markdown-accessiblity-table><table role="table">
<thead>
<tr>
<th>参数</th>
<th>类型</th>
<th>要求</th>
<th>描述</th>
<th>备注</th>
</tr>
</thead>

<tr>
<td>validateType</td>
<td>Int</td>
<td>必选</td>
<td>验证类型</td>
<td>说明：<br>validateType=1：使用部门编号(departmentId)进行验证；<br>validateType=2：使用呼叫中心编号(enterpriseId)进行验证；</td>
</tr>
<tr>
<td>departmentId</td>
<td>String</td>
<td>必选</td>
<td>部门编号</td>
<td>说明：validateType=1时，此参数为必选参数，例如：departmentId=BM0000001</td>
</tr>
<tr>
<td>enterpriseId</td>
<td>Int</td>
<td>必选</td>
<td>呼叫中心编号</td>
<td>说明：validateType=2时，此参数为必选参数，例如：enterpriseId=7000101</td>
</tr>
<tr>
<td>timestamp</td>
<td>Long</td>
<td>必选</td>

</tr>
<tr>
<td>sign</td>
<td>String</td>
<td>必选</td>
<td>验证值</td>
<td>说明：<br>validateType=1时，MD5({departmentId}+{timestamp}+{部门token值})；<br>validateType=2时，MD5({enterpriseId}+{timestamp}+{部门token值})；<br>格式要求：32位全小写</td>
</tr>
<tr>
<td>numberType</td>
<td>Array</td>
<td>可选</td>
<td>号码类型（支持多选）</td>

</tr>

<td>clidType</td>
<td>Array</td>
<td>可选</td>
<td>外显类型（支持多选）</td>

</tr>
<tr>
<td>status</td>
<td>Integer</td>
<td>可选</td>

<td>取值：1-启用；0-停用</td>
</tr>
<tr>
<td>number</td>
<td>String</td>

<td>号码</td>
<td>精确匹配号码</td>
</tr>
<tr>
<td>areaCode</td>
<td>String</td>
<td>可选</td>
<td>区号</td>
<td>精确匹配区号</td>
</tr>
<tr>
<td>trunkGroupKey</td>
<td>String</td>
<td>可选</td>
<td>中继组编码</td>
<td>精确匹配中继组编码</td>
</tr>
<tr>
<td>label</td>
<td>String</td>
<td>可选</td>
<td>号码标签</td>
<td>精确匹配标签</td>
</tr>
<tr>
<td>startTime</td>
