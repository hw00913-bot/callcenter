TaskProperty数据类型定义：
本文档定义了外呼任务的数据结构和字段说明。

基本信息

字段 类型 描述
id Int 外呼任务Id
enterpriseId Int 企业编号
name String 任务名称
description String 任务描述
type Int 任务类型，1.预测外呼任务 2.自动外呼任务

任务设置

字段 类型 描述
autoStart Int 定时开始，0.关闭 1.开启
autoStartDay String 定时开始日期，格式：yyyy-MM-dd，如：2017-02-11
autoStartTime String 定时开始时间，格式：HH:mm:ss，如：08:00:00
autoStop Int 定时完成，0.关闭 1.开启
autoStopDay String 定时完成日期，格式：yyyy-MM-dd，如：2017-02-11
autoStopTime String 定时完成时间，格式：HH:mm:ss，如：17:00:00
forceEndFlag Int 定时完成时强制结束任务。
开启配置后，当任务到定时完成时间时无论任务中的号码是否已经呼完，均将任务状态设置为结束。适用于对数据有呼叫时间限制的场景。
注：任务在结束状态时无法再次启动。
autoTaskType Int 呼叫方式，0.连续呼叫 1.间隔呼叫
autoTriggerTimeStrategy String 间隔呼叫时间段，呼叫的时间段配置。参数格式：时间条件编号。支持多个，多个使用英文","逗号隔开，如：9,22。
autoComplete Int 自动完成，0.关闭 1.开启
retryStrategyTimeType Int 重试策略时间类型，1.基于首次呼叫时间 2.基于上次呼叫时间
retryStrategy String 重试策略，「基础模式」
数据结构为Json格式{"retry":2,"strategy":[{"round":1,"time":"1-1-1"},{"round":2,"time":"2-2-2"}]}
格式说明：retry是重试次数，round是第几次重试，time是第几次重试间隔的时间：1-1-1，第一个1是天，第二个1是小时，第三个1是分钟
「高级模式」
高级模式需要开启「号码状态识别」服务后。目前只支持「自动外呼」任务模式。
数据结构为JsonArray格式 [{"condition":{"sipCause":[710,719]},"retry":1,"sort":1,"strategy":[{"round":1,"time":"0-0-10"}]},{"condition":{"sipCause":[800]},"retry":1,"sort":2,"strategy":[{"round":2,"time":"0-0-10"}]}]
格式说明：condition是重试条件，sort是重试条件的顺序，其余字段与基础模式一致
retryStrategyOnlyToday Int 重试仅当天生效，0.关闭 1.开启，删除待重试的数据和待呼叫的数据 2.开启，删除待重试的数据 3.开启，删除待呼叫的数据
callPriorityStrategy String 呼叫顺序
数据结构为Json格式{"strategy":[{"sort":1,"type":"retryCall", "desc":0},{"sort":2,"type":"firstCall","orderType":0}]}
格式说明：sort是重试号码和未呼叫号码的呼叫顺序
type：retryCall重试号码、firstCall未呼叫号码
当type=retryCall，desc：0.优先呼叫待重呼轮次数值较小的号码，即轮次靠前（如第1轮、第2轮）的号码先被呼叫 1.优先呼叫待重呼轮次数值较大的号码，即轮次靠后（如第5轮、第4轮）的号码先被呼叫
当type=firstCall时，orderType：随机呼叫，0顺序(优先级) 1随机 2顺序(导入时间)
quotiety Double 骚扰率，支持小数，精确到小数点两位

客户侧设置

字段 类型 描述
customerClidsCategory Int 客户侧外显号码类型，5 外显导航
customerClidsGroup String 外显导航标识
clidPoolList Array 外显导航接口传入号码池列表，格式：
[{"name":"号码池A","priority":1},{"name":"号码池B","priority":2},{"name":"号码池C","priority":3}]
字段说明：
name：号码池名称，priority：号码池优先级（Integer类型）（可选），数值越小优先级越高，例如priority=1 的号码会优先于 priority=2 的号码被选中
customerTimeout Int 客户超时时间，单位秒

座席侧设置

字段 类型 描述
callRouteStrategy Int 呼叫流转模式， 1.直连座席 2.AI转人工
直连座席模式：客户接听后直接分配座席，无空闲座席可溢出语音导航（需配置语音导航），保障高优先级客户直连体验
AI转人工：客户接入后，优先进入语音导航中配置的智能体机器人，按交互结果决定是否转接座席，提升自动化覆盖率，降低人工成本
ivrId Int 语音导航Id
预测外呼使用场景：直连座席模式下如果客户接听后未在特定时间内（默认2秒）找到可用座席，通话将溢出到语音导航继续排队找座席。同时支持在呼转座席，座席未接听时也溢出到语音导航，需要开启企业配置生效。AI转人工模式下，呼叫先转到语音导航
自动外呼使用场景：客户接听后，转到的语音导航
callGroupType Int 指定座席方式，1.座席工号列表 2.外呼组
cnos String 座席工号列表
agentGroup String 外呼组号
callStrategy Int 座席分配规则，1.随机 2.顺序 3.座席未进线最大时（从上一次呼叫结束到当前的总时长） 4.座席状态[空闲]最长时长（座席最近一次切换为空闲状态的持续时长）
agentTimeout Int 座席超时时间，单位秒
wrapup Int 座席整理时间，单位秒
maxWaitTime Int 座席最大等待时间，单位秒
minAvailableAgentCount Int 最小可用座席数
callLimitStrategy String 座席当日接听数限制，JsonArray格式[{"cnos":["2000","2001"],"limit":"5"}]

高级设置

字段 类型 描述
concurrency Int 最大并发限制
userFields String 任务自定义字段，JsonArray格式[{"key1":"value1"},{"key2":"value2"}]
callVariables String 座席通道变量，JsonArray格式[{"key1":"value1"},{"key2":"value2"}]
businessTagNames String 业务标签名称，英文逗号分隔；持久化与查询以此为准
businessTagIds String 已废弃：不再写入；历史任务可能仍有值，读取时以 businessTagNames 为准
timeStrategy String 禁止呼叫时间限制，在特定的时间段内禁止呼叫。参数格式：时间条件编号。支持多个，多个使用英文","逗号隔开，如：9,22。
predictAdjust Int 超呼率
customerMoh String 客户侧等待音
customerVoice String 客户侧提示音
answerRate Int 初始化预计客户接通率
warmUpDuration Int 任务预热时间，单位秒
isRewarm Int 暂停后重新预热，0.关闭，1开启

任务状态

字段 类型 描述
status Int 任务状态，0.初始 1.运行中 2.暂停 3.结束
statusTriggerType Int 任务状态变更类型，0.系统变更 1.人为变更
statusDescription String 任务状态描述
createTime Date 任务创建时间 ，格式为： yyyy-MM-dd HH:mm:ss
startTime String 任务开始时间
overTime String 任务结束时间
pauseTime String 任务暂停时间点
pauseDuration Int 任务暂停时长(针对自动启动时间段) 单位分钟

已废弃字段

字段 类型 描述
taskFields String 已废弃。任务级呼叫属性 json格式{"key1":"value1","key2":"value2"}，仅做呼叫控制用，不放通道变量
callbackUrl String 已废弃。给企业推送任务状态的URL地址
curlRetryTimes Int 已废弃。推送重试次数 最大5次
agentUtilization Int 已废弃。座席利用率
clidGroup String 已废弃。热线号码组
standbyCnos String 已废弃
isRandom Int 随机呼叫，0.关闭 1.开启
customerClids String 客户侧外显号码列表
customerClidType Int 客户侧外显规则，1.随机 2.按区号
clidProperty String 外显规则，Json格式，外显号码选择规则：默认区号，是否匹配省会等；如：{"defaultAreaCode":"010", "isMatchCapital":"1"}
customerClidWeightFlag Int 外显号码比例配置开关，0.关闭 1.开启
customerClidWeight String 外显号码比例配置内容，JsonArray格式[{"number":"123,345","weight":"5"},{"number":"567,789","weight":"5"}]
customerClidsGroup String 客户侧外显号码池名称或外显导航标
