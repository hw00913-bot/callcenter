队列报表
接口说明
获取队列报表数据
API URL
接口请求地址：
https://api-{region}.alicti.cn/interface/{version}/queueReport
地址参数说明：
{region}为alicti平台区域，{region}=1 表示华东1区，{region}=2 表示华北2区，{region}=5 表示华东5区，{region}=6 表示华北6区
{version}为接口版本，当前{version}=v10
接口请求方式：
GET/POST
报表接口单独设置访问频次限制
请求参数
参数
类型
要求
描述
备注
validateType
Int
必选
验证类型
说明：
validateType=1：使用部门编号(departmentId)进行验证；
validateType=2：使用呼叫中心编号(enterpriseId)进行验证；
departmentId
String
必选
部门编号
说明：validateType=1时，此参数为必选参数，例如：departmentId=BM0000001
enterpriseId
Int
必选
呼叫中心编号
说明：validateType=2时，此参数为必选参数，例如：enterpriseId=7000101
timestamp
Long
必选
当前时间戳
说明：取当前linux时间戳，精确到s，时间戳有效期为30分钟
sign
String
必选
验证值
说明：
validateType=1时，MD5({departmentId}+{timestamp}+{部门token值})；
validateType=2时，MD5({enterpriseId}+{timestamp}+{部门token值})；
格式要求：32位全小写
timeRangeType
Int
必选
报表类型
说明：统计报表类型，
1：日报表
2：周报表
3：月报表
4：自定义时间
statisticMethod
Int
必选
统计方法
说明： 0:分时 1：分日 2：汇总 8：分半时
startTime
String
必选
开始时间
说明：统计日期的开始时间，格式：yyyy-MM-dd
endTime
String
可选
结束时间
当timeRangeType值为4时必选  说明：统计日期的结束时间，格式：yyyy-MM-dd
qnos
String
可选
队列号
说明：根据队列号查询指定队列报表数据
支持按照多个队列号进行查询，多个队列号之间使用英文逗号","分隔，默认查询账户下所有队列的数据
startHour
Int
可选
统计时段开始时间
取值：0~23,默认值为0，即0点。取值为实际时间小时数。例如4点，则取值为4
endHour
Int
可选
统计时段结束时间
取值：1~24,默认值为24
start
Int
可选
查询起始位置
取值：大于等于0，默认0
limit
Int
可选
查询条数
取值：最大不能超过1000，默认10
接口请求示例
    http://api-dev.alicti.cn/interface/v10/queueReport?validateType=1&departmentId=BM3000003&sign=341a2ac5af0d6c245c4242e1c96d97a9&timestamp=1511948019&timeRangeType=3&statisticMethod=1&startTime=2017-08-01&qnos=0505,8848
接口返回
JSON格式数据
参数
类型
说明
result
Int
0 成功, -1 失败
description
String
返回结果描述
data
JSON
返回数据JSON格式
description给出成功或失败时的文本描述：
description
返回结果说明
验证失败，参数[{param}]不能为空
{param}为接口参数中必选字段
验证失败，参数[{param}]格式不正确
{param}为接口参数中格式有要求的字段
验证失败，参数[{param}]取值不正确
{param}为接口参数中有固定取值的字段
验证失败，参数[param]取值范围不正确
{param}为接口参数中有固定范围的字段
验证失败，超过频次限制
接口调用超过接口的访问频次限制
查询成功，{param}
{param}为成功描述
查询失败，{param}
{param}为失败描述

字段
类型
描述
pageSize
String
每页记录数
totalCount
String
总记录数
totalPageCount
String
总页数
list
List<StatisticQueueHour>
