Agent数据类型定义：

字段 | 
类型 | 
描述 | 

id | 
Int | 
座席id | 

enterpriseId | 
Int | 
企业编号 | 

cno | 
String | 
座席工号 | 

name | 
String | 
座席姓名 | 

areaCode | 
String | 
区号格式 | 

active | 
Int | 
是否启用，0：停用，1：启用，默认启用 | 

agentType | 
Int | 
座席类型，1：电话座席，2：电脑座席，默认电话座席 | 

callPower | 
Int | 
呼叫权限，0：无限制，1：国内长途，2：国内本市，3：内部呼叫，默认无限制 | 

power | 
Int | 
1：班长席，0：普通座席，默认普通座席 | 

wrapup | 
Int | 
整理时间，秒数，默认10秒 | 

isOb | 
Int | 
是否允许外呼，0：不允许，1：可以，默认允许 | 

obClid | 
String | 
外显号码 | 

obClidType | 
Int | 
外显规则 1：企业默认 2：随机 3：按区号 4：动态外显 | 

obClidProperty | 
String | 
外显规则属性，JSON格式 | 

ibRecord | 
Int | 
呼入是否录音，0：不录用，1：录音，默认录音 | 

obRecord | 
Int | 
外呼是否录音，0：不录音，1：录音，默认录音 | 

status | 
Int | 
座席状态，0:离线，1：在线 | 

isAsr | 
Int | 
是否开启ASR转写：0：不开启，1：开启，默认不开启 | 

bindTel | 
String | 
座席绑定电话 | 

bindTelType | 
Int | 
电话类型，1:固话 2:手机 3:分机 4:软电话 | 

isAxbCall | 
String | 
是否允许axb外呼，默认1开启 0关闭 | 

asrCallType | 
String | 
允许语音识别的通话类型，1:呼入 4：预览外呼 9：主叫外呼 5：预测外呼 2：webcall | 

webrtcUrlType | 
String | 
webrtc软电话返回地址，0：企业默认 1：公网域名 2：专线域名 3：公网IP 4：专线IP | 

comment | 
String | 
备注 | 

permitObPreviewTime | 
String | 
可外呼时间段用,号分割 | 

property | 
String | 
座席主动挂机配置Json Str 格式数据 unLink 是否允许主动挂断, 0:关, 1:开，prohibitDuration禁止时长 | 

isObRemember | 
String | 
外呼主叫记忆 1：开启 0：关闭 | 

loginTime | 
String | 
坐席最后一次登陆的时间 | 

queueList | 
Array | 
坐席所属队列 | 

updateTime | 
String | 
更新时间，格式: yyyy-MM-dd HH:mm:ss | 

createTime | 
String | 
创建时间，格式: yyyy-MM-dd HH:mm:ss |
