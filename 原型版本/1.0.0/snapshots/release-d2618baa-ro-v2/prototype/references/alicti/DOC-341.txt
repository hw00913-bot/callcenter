座席批量新增

接口说明

批量新增一个座席,单次批量创建不能超过100个

API URL

接口请求地址：

https://api-{region}.alicti.cn/interface/{version}/agent/batchCreate

地址参数说明：

{region}为alicti平台区域，{region}=1 表示华东1区，{region}=2 表示华北2区，{region}=5 表示华东5区，{region}=6 表示华北6区

{version}为接口版本，当前{version}=v10

接口请求方式：

GET/POST
